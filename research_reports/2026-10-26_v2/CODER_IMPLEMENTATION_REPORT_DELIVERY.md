# CODER IMPLEMENTATION REPORT — observational delivery

Scope: approved `DESIGN_NUMERICAL_DELIVERY_ADDENDUM.md` sections5/7 only. New files are `delivery.py` and `verify_delivery.py`. Campaign/CLI/artifacts remain packageC-owned; original fixture APIs remain available through identical imports from C-owned `fixture_export.py`. No algorithm, solver, training schedule, selected policy or tolerance changed.

API: `collect_delivery(bundle, predictions, formations, diagnostics, config, output_root=None, benchmark=False) -> dict`. It returns JSON-safe measured/not-measured observations and writes `delivery/<dataset>/seed<seed>/COSTS_PARAMETERS_AND_INFERENCE.json` plus `training_costs.csv`. A stage-summary call records costs/parameters with timings explicitly NOT_MEASURED. Only `benchmark=True` performs observational inference measurement.

The raw-X compiler supports native, B_refit, selected direct/effort/ETA heads, GROUP_CAL, full source/target/random features, PILOT_LOGIT, formed delta banks, spectral/RRR frozen projections and the selected probability gate. It copies only needed downstream tensors outside timing, preserving original objects. The compiled object then releases references to the research bundle/prediction/banks. OFF needs native+B_refit and retains no source hidden/output components.

FULL standardization is folded exactly algebraically: hidden weights `w/std`, intercept correction `-dot(w/std,mean)`, after the actual ReLU. Formed output scale and reader coefficients are folded into the frozen output readout after ReLU. Spectral/RRR projections receive the same folding opportunity. Hidden inference is evaluated per whole target subset before group indexing, matching the unfused path's FP32 operation shape. A first verification attempt exposed a9.41e-6 shape-dependent FP32 discrepancy when hidden activations were separately evaluated per group; that implementation was corrected before deployment, without changing tolerance or coefficients.

Benchmark contract: fixed first4096 distinct natural Q_explore raw rows, no labels; CPU FP32 input and final CPU probability transfer included. Native/hidden/direct operations use FP32 on the resident native device; fused linear policy uses FP64. Construction is outside timing. Compare against both the retained unfused raw-X formula and retained batch probabilities, requiring unchanged maximum probability error<=1e-6 before any timing. Then exactly3 warmups and10 measured repetitions, CUDA synchronization around each, individual times/mean/median/std/min/max/rows-per-second, compile cost and CUDA resident/compiled/peak allocations recorded. Missing metadata, non-frozen modes or failed parity produce explicit NOT_MEASURED reasons. No cached-H/Z timing is reported as full inference.

Cost metadata reads actual native epoch records, source/local-pilot pass logs, inclusive prefix wall time, B OOF/refit `base_seconds`, combined `direct_seconds`, method reader/gate elapsed time, distinct RRR starts and unique formation terminal slot costs. Cumulative pass elapsed clocks are not summed. Inherited K1 slots add zero new training cost. The direct family is explicitly combined; unavailable per-arm allocations are not invented. Inclusive prefix cost and its subcomponents are labeled to prevent double counting; repeated log observations remain visible as replay cost.

Parameter accounting separates deployed total/native once, frozen full heads, hidden-only weights, analytical reader variables, actual derived fused scalars, normalization/threshold buffers, per-target/task active additions, trainable method additions, required frozen pretrained additions, inherited formed functions and discarded B/reader fitted parameter instances. Stage parameter-instance counts are explicitly distinct from independent capacity. OFF's compiled count equals B_refit's count. Extra unused source pilot output parameters are absent from fused FULL storage and forward; their real pretraining time remains in the cost log.
