## 5. Algorithm

Let θₜ be the ordered online S_DENSE parameter values before step t, φₜ the current private parameters, and Lₚ the mean `softplus(-(positive_logit-negative_logit))` for the one drawn pair set. Define gₜ=∇θLₚ(θₜ,φₜ), g⁻ₜ=∇θLₚ(θₜ₋₁,φₜ), ĝₜ=gₜ+γ(gₜ−g⁻ₜ). Both gradients use the same full batch tensor, pair indices, task, pre-forward buffers and RNG. The first snapshot equals θ₁, so use g⁻₁=g₁ exactly. Capture θₜ before the update and publish that capture after the successful source step, including a successful no-event step. Resume across epoch boundaries with this snapshot.

For a valid event let α=.05(w/q). Run the stock v3 mixed loss backward for all parameters and retain its actual computed gradients. At the existing HistoryOptimizer pre-step hook, B2 replaces only the shared contribution using `p.grad.add_(ĝ − g, alpha=α)` in FP32 and replaces each element of the raw gradient list passed into A21 with ĝ. Keep a zero-correction path that skips editing the gradients. For each shared parameter the unchanged optimizer forms mixed=adjusted_grad+WD·p, subtracts αĝ for the first moment's base and uses mixed² for the second moment. Thus the base is algebraically the original BCE+WD base, up to FP32 roundoff, while the second moment follows A21's mixed formula using the corrected shared input. A21 advances k once per event, updates Q=.99Q+.01(w/q)ĝ, and adds .05Q/(1−.99ᵏ) to the bias-corrected numerator on event steps. Private Adam receives the exact stock mixed gradients for that step. The reported loss is the stock current mixed loss. Source Adam and EMA each execute once.

A no-event step leaves the pair clock and Q unchanged and omits Q injection. A valid zero-gradient event advances the clock and decays Q, with zero input when ĝ=0. A raw zero with a nonzero old-state gradient remains a valid event and may yield a nonzero correction. Missing required shared gradients or nonfinite current, old or corrected gradients invalidate the step. The source optimizer owns private `None` handling. ## 11. Falsification

By dataset/readout, a B2−B1 paired selected Validation mean below +.001 or any cell mean below −.001 fails the practical ranking hypothesis for that comparison and closes advancement there. A LogLoss-only gain is evidence about calibration. If B1 improves on B0 and B2 fails against B1, advancement applies only to the parent comparison. Near-zero correction following a passing nondegenerate implementation fixture informs the mechanism analysis. A source, storage, runtime or implementation failure leaves the affected comparison unevaluated.
