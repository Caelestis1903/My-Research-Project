## Supervision and recovery

The current foreground scheduler starts attached mechanical children and samples both devices independently. Strictly measured GPU memory/power <85% and host RAM <90% are necessary. A measured full-process residency must fit the measured usable capacity. The scheduler refreshes the incoming physical fit requirement from observed NVML process values. The current card's allocation acknowledgment reconciles the specific worker PID. Source subprocesses run without detachment. stdout/stderr is captured in per-job logs. A stage-specific PAUSE file or this study's USER_STOPPED file stops admission and completes the current epoch before pausing. SIGINT/SIGTERM pauses the foreground scheduler safely. The global lifecycle is the finite 11-22 runbook.

Every epoch carries model/buffers and mode, optimizer/full private moments, EMA, generator/permutation/cursor, RNG, cumulative counts, source/data/group/job identities, selected models and Validation. Each packet is sent directly to the live guardian via memory IPC, read back and hashed before the corresponding scalar epoch receipt is published. An epoch acknowledges its final cursor and resumes at the next independent randperm. The final operation separately verifies compacted selected states, then writes COMPLETE_VERIFIED.json. Accepted scalars survive loss of a storage owner. A complete job is skipped on ordinary retry. Paused jobs resume from their exact last RAM state. A replacement owner requires a fresh source/data/engineering/owner check and a recorded recovery classification. The output directory includes the owner generation to avoid overwriting a prior physical attempt.

After a worker failure, inspect the stage PAUSE and its failure.json and supervisor admission/exit log. Resolve the measured technical issue, clear the stage PAUSE, then run the same approved stage again under a fresh foreground runner. No failed partial epoch receives scientific completion credit. Scalar records from accepted epochs can be reconstructed from the RAM packet if publication was interrupted after RAM commit.
