# 机制整合、旧自适应失败解释与下一阶段决策

状态：**DESIGN_ONLY**。本文件规定执行后的判断方法；当前只接受01中的已有事实，不预先填入任何新机制胜者。主要比较对象为实际固定EMA F与同轨迹online O。

## 1. 先形成结论，再说明其证据层次

报告每项结论采用“当前结论 → 核心证据 → 适用范围 → 研究决定”。允许结论为共同机制、条件性机制、交互机制或某项不承担主要作用。对已经闭合的链条直接接受，不因为尚未解释每个参数就把判断退回未知。

每条主机制必须给出以下可核验链：

1. **来源定位**：哪个组、哪个step窗口、哪个阶段的实际参数修正X；
2. **因果作用**：加入/删除X后的真实预测与六格AUC，交互背景清楚；
3. **函数路径**：同一contrast的完整接口、expert内容/路由/私有输出或tower作用；
4. **排序闭合**：哪些真实pair被纠正/破坏，margin怎样跨零，净贡献怎样形成AUC；
5. **训练来源**：这些修正与原轨迹窗口的实际训练目标、验证排序变化怎样对应；
6. **操作意义**：是否存在训练可见、能跨seed/时间指导实际动作的简单信息。

第1–4项闭合即可形成主要功能性机制结论。第5项可停在证据支持的具体训练问题层次，例如近期更新的训练目标/验证排序不一致；不强行归因噪声或负迁移。第6项没有阳性，不会抹去第1–5项的发现，只会改变算法研究投入。

## 2. Q1–Q5 的最终必答模板

### Q1：固定EMA主要通过什么获得排序收益？

填写两个数据集Clean的主结论，再列Gaussian边界：主要组、主要历史窗口、阶段、对应纠正/破坏总量、主要交互。必须给五seed配对原值与均值，不只报最大cell。

使用以下分类而非强行百分比分账：

| 类别 | 可以接受的证据形态 |
|---|---|
| 单类充分且必要性较强 | 单独加入重现大部分净收益，删除有明显损失，关键pair重现 |
| 多类协同 | 单独作用较小、组合作用大；score/margin和真实接口交互明确 |
| 有利/有害抵消 | 某类增加纠正同时也增加破坏，完整F是净结果 |
| 阶段切换 | 同类修正早期损害、晚期受益，并有实际margin/目标变化对应 |
| 功能源明确但参数来源分散 | 多个组通过相同功能切口起作用，不需要继续逐坐标分割 |

“大部分”须附实际保留/删除数值、分母与符号。F−O接近零或跨seed变号时不用比率，直接报告绝对增量与两种背景，不写虚假的贡献百分比。

### Q2：这些修正为什么能改善AUC？

要求至少有一个已识别X进入同contrast的D2/D2b检验：例如 `theta0=F−X, theta1=F`，切口四态及选定融合项删除能够重现或破坏X带来的同pair纠正。最终句子应明确说出：哪个计算部分改变了正负样本分数差、哪些pair因而跨零、哪些代价同时出现。

历史预测组合若已经重现主要纠正，可以接受组合效应是主要解释；参数均值若有额外收益，则用接口和融合分解定位它。两个机制可以共同作用。只报告“共享参数最重要”“表示距离变小”“积分与AUC相关”不达标。

### Q3：EMA缓解了训练过程中的什么问题？

按实际证据选择最具体且不越界的表述：

| 发现 | 合法解释 | 不可自动升级为 |
|---|---|---|
| online窗口损坏验证排序，recent修正恢复；固定训练目标同期下降 | 近期实际更新中目标改善与验证排序改善不一致 | 已证明过拟合、梯度噪声或负迁移 |
| old贡献明显，精确历史预测组合保留相同纠正 | 当前单一参数状态遗失了历史预测中的有用组合信息 | 早期所有信息都好、长记忆必然好 |
| F有预测集成不能复现的收益，跨组/接口组合必要 | 参数平均形成了指定背景下的有利协同函数状态 | 普遍更平坦、所有非线性都增益 |
| 早期recent/old同类修正损害有利margin、晚期转正 | 历史组合价值与学习滞后存在阶段取舍 | 当前负向更新普遍有害 |
| 同状态Adam方向对照恢复真实受损pair | 特定状态的一阶历史/预调节方向对损坏有作用 | 已证明长期重置m/v能提升selected性能 |

若训练来源还存在两种会改变下一阶段选择的解释，优先用已经采集的有限对照区分。只有本文预留的H2匹配或Adam来源诊断可自动触发；不自动新增完整训练、优化器或超参网格。

### Q4：此前自适应为什么未获稳定额外收益？

将本轮机制与01的具体历史版本逐一对照，不用一个抽象失败原因涵盖所有方法。特别保留：旧B确实触发但功能增量极小；旧A虚拟K步目标与实际一步动作不同且导数保留gate detach；11/09有早晚外推反向与静态统一偏好；预测未来数值更准未必改变有价值动作。

对每个历史版本给 `mechanism_alignment / signal_transfer / action_coverage / actual_value / remaining_gap` 五列，并引用本轮对应表。没有旧Q/optimizer状态的地方标明无法补算，不为了补一列重跑旧网格。

### Q5：下一步选择A、B、C还是D？

用第5节决策表给出**一个主优先方向**，可附一个有明确触发条件的备选。不得把四个方向都无差别列为下一步。结果的条件差异用数据集/目标/阶段边界表达，不自动否定已经成立的机制。

## 3. H1/H2/H3 的证据裁定

### H1：旧指标与真实收益来源不匹配

较强支持需要同时看到：实际组/时间/功能干预锁定了收益源，而旧幅度/几何/阶段指标对该类净纠正或动作的留出表现弱，或者其原来预测的主要是阶段/幅度；更直接的训练可见功能效用在相同目标上有额外价值。若所有可见信号都弱，只能说当前信息不可稳定利用，不能把全部责任归于某一个旧指标。

### H2：信息有价值，但所测rho动作不能利用

完整主张须同时满足四环：

1. 机制动作相对F有可重复的真实额外作用，而不是只胜过一个退化控制；
2. 训练可见信号在留出seed/未来窗口取得相对简单静态动作的实际价值；
3. 对应rho菜单缺少同样价值，且不能只用样本内oracle大小作判断；
4. 如H2要成为选B的主要依据，完成03§6.1的相同时域、共同scope、相同参数半径对照；匹配后的机制动作自身仍应相对F有正作用，再判断它是否优于匹配rho方向。

两者都损害F、只是机制动作损害较小，不能支持“已有可用新方向”。零公共半径或小到函数分辨率不足记 `MATCHED_ASSAY_UNINFORMATIVE`。该结论始终限定本次有限操作类；不证明任意rho序列都表达不了。

### H3：固定F已捕获当前可利用的主要收益

当固定F的主要链条已解释，有限合理菜单的跨行侧额外空间和训练信号选择价值均小，可接受“在当前任务、状态和操作类内，自适应投入优先级低”。无需证明所有未来算法不可能有效，即可选择D。

若oracle空间明显而训练信号不能选择，状态是 `ROOM_WITHOUT_ACTIONABLE_SIGNAL`，不能标记H3的“空间很小”；但仍可以基于投入回报选择D，理由应是当前不可操作，而非F穷尽全部空间。

H1/H2/H3不要求互斥。最终报告用 `SUPPORTED / CONDITIONALLY_SUPPORTED / NOT_MAIN_EXPLANATION / OPEN_DECISION_RELEVANT / OPEN_LOW_PRIORITY`，每项必须附证据表和决策含义，不以泛化免责声明结束。

## 4. 桥接分析的固定输入定义：不给Codex留下算法设计空白

本节为新菜单下的**适配定义**，不冒用旧C_simple的48维机会级定义。其目的是区分信号、动作与静态偏好，不训练下一代闭环控制器。

### 4.1 行粒度与目标

对每个dataset×objective×menu单独拟合。每行是 `(seed, origin_epoch, action_id)`；F是零收益参照，不进入回归行。其他六个动作的固定顺序为 `all/action1, all/action2, S/action1, S/action2, N/action1, N/action2`。rho菜单的action1/2为fast/slow；机制菜单为drop_recent/drop_old，**两菜单独立拟合，不把recent冒名当fast**。

每个LOSO训练fold有4seed×3origins×6actions=72行，只有12个相关的时序单元，不能按72计算科学标准误。目标为下一预定窗口 `origin+5` 的 P_A 六格等权Macro AUC动作增量 `U_a−U_F`。P_B、V_A、V_B不用于拟合、标准化、阈值或动作选择。

两种固定ridge模型均为 pooled scalar regression，预测每个动作的未来macro效用；不分别拟合六个小模型，也不混入另一数据集或Gaussian条件。

### 4.2 恰好两套拟合特征与一个无拟合规则

| 名称 | 精确列 | 定义 |
|---|---|---|
| `C_design_adapted` | 6维action one-hot；`epoch/50` | 截距另设不惩罚；无dataset/seed one-hot，无未来阶段信息 |
| `C_simple_adapted` | 上述7列 + 下述8列 | 保留历史简单几何/函数幅度/梯度幅度/当前偏好的思路，聚合方式固定 |
| `C_carry_direct` | 不拟合 | 直接把P_A当前真实动作macro AUC增量当下一窗口预测；与当前直接选择等价 |

`C_simple_adapted`的8个追加列：

1. `log1p(RMS(R_G))`：G为该动作作用scope，F−O的组位移；
2. `log1p(RMS(delta_a))`：动作状态相对当前F的实际组位移；
3. `cos(R_G,delta_a)`：FP64固定坐标归约，零范数时值为0；
4. `is_zero_R`；
5. `is_zero_delta`；
6. `log1p(mean_cell_RMS_zdiff)`：P_A自然面板各cell的 `z_a−z_F` RMS，再六格等权平均；
7. `log1p(group_rank_gradient_RMS)`：在F的P_A rank面板上，六格等权softplus成对风险的完整功能导数，限制到G后的RMS；
8. `current_macro_auc_utility`：P_A rank面板六格等权真实AUC动作差，未支持cell的差仍为实际零，不重新按支持格归一化。

rank风险为每格所有256×256正负组合的平均 `softplus(z_negative-z_positive)`，再六格等权。每个pulse结束时只求一次完整参数梯度，归约到all/S/N得到第7列，梯度留RAM且不写online `.grad`。第8列与direct规则使用同一已存真实预测。缺类规则沿用固定面板；特征/目标缺失则该行标记不可估计，不增补行或用0伪造目标。

所有连续列只在本fold训练行上标准化，常量列置0；二值和one-hot保留原值。ridge为 `sum_squared_error + 1*sum(beta_nonintercept^2)`，不改成按样本平均后仍加1的另一个惩罚强度。使用确定性线性求解，无HPO。把列顺序、训练row hash、均值/标准差、缺失状态写入FEATURE_MANIFEST与BRIDGE_FOLDS。

### 4.3 动作选择与参照

每个origin用预测值在F及六动作中选最大；F预测收益固定0，所有非F预测≤0则选F。完全并列先F，再按冻结action_id。用于实际评价的收益来自**真实target状态的前向预测**，不是回归输出。

必须并列以下规则：F；其他四seed早期P_A平均效用选出的单一静态动作；`C_design_adapted`；`C_simple_adapted`；`C_carry_direct`；同面板oracle。静态动作也允许F。六格/LL/动作熵及相对静态动作的增量必须报告。

未来标签只属于已经完成的其他seed早期训练窗口；当前留出seed的target label/预测结果不得进入origin特征或选择。模型训练本身不接受任何这些动作反馈。

`MECHANISM_FINDINGS.json`每条必须包含：`question_id, claim_level, scope, intervention_ids, functional_contrast_id, pair_table_ids, effect_mean, seed_values, interaction, source_evidence, status, decision, limitation_that_changes_decision`。不能只输出一个GO/NO_GO字段。

## 8. 研究完成与诚实边界

达到以下条件即可完成本轮：五seed核心矩阵与数值闭合正确；主要收益源经过实际替换；至少将一个主要修正直接连接到完整函数变化和真实pair净纠正，或用同权历史预测组合形成充分的主要解释；训练来源给出证据支持的具体问题层次；H1/H2/H3能约束A/B/C/D的主选择。

若主要效应只能以组间整体交互解释，报告联合机制即可，不要求唯一参数贡献。若不同数据集机制不同，给两个条件性机制和一条相应研究决定，不强行概括统一叙事。

若D2b的第六态未能把已定位X与所选功能项连接起来，不得伪称完成该精细链；可以用D2完整切口的真实因果效应形成更宽但充分的功能解释，并明确expert级细节未定位。只有当这一缺口会改变A/B/C/D选择时才列为下一阶段关键任务。

所有“未来应改善”的陈述都是待设计任务，不是当前性能承诺。结束依据是已经获得足以指导研究的主要机制与明确决策，而不是解释所有微观更新或找到一个必然优于F的新算法。
