# 02｜多候选算法探索与替代设计

## 0. 统一记号

真实梯度与增强差分定义为：
[
g_t^r=\nabla_\theta L_r(\theta_t;B_t),\quad
\delta_{t,v}=\nabla_\theta L_a(\theta_t;\tilde B_{t,v})-g_t^r,
\quad \bar\delta_t=K^{-1}\sum_{v=1}^K\delta_{t,v}.
]
增强训练目标的混合梯度为 (g_t^{mix}=g_t^r+\lambda\bar\delta_t)。差分必须来自同一θ、同一原始batch，增强权重λ和原样本loss预算保持GA31定义。Adam保留当前一阶/二阶矩、bias correction、epsilon和coupled weight decay语义；候选不修改网络结构、域任务权重或采样比例。

## 1. 候选A：轨迹平均评价器（Polyak/EMA Shadow）

**机制与公式。** 在线参数由普通Adam更新，另维护仅用于验证和推理的影子参数：
[
\theta_{t+1}^{on}=Adam(\theta_t^{on},g_t^r),\quad
\phi_{t+1}=\rho\phi_t+(1-\rho)\theta_{t+1}^{on}.
]
默认φ_0=θ_0，每次真实Adam.step后更新一次；另测warmup=10%作为敏感性对照。φ永不复制回θ，不改变在线训练轨迹。

**证据。** 历史PolyakAdam(0.995)在旧MovieLens六seed平均配对AUC +0.004022，36/36 cell-seed正向；KuaiRand未复现同等收益。当前GA31-R3未维护参数EMA，因此必须在当前自然分布协议重验。

**增强角色。** 不需要增强；它是最简单轨迹滤波强基线，判断AUC瓶颈能否由模型参数时间平均解决。

**区别/退化。** 与Lookahead不同，shadow不反馈在线训练；ρ=0退化为在线模型。EMA与算术Polyak/SWA不是同一平均定义，必须标清递推和起始时刻。

**预期收益/失败。** 可能来自评价模型平滑、隐式集成或参数空间平均；不能直接说成降低梯度噪声。若轨迹长期漂移或跨参数盆地，EMA会滞后。只改善LogLoss、不改善selected macro AUC，不算目标收益。

**成本/创新。** 维护一个模型参数副本，额外训练forward/backward为0，逐epoch增加一次shadow validation。Polyak/EMA本身不是创新；价值是当前MDMT自然分布下复现旧结果并建立强基线。若P0足够，优先选P0而不是复杂算法。

## 2. 候选B：增强差分记忆注入（ADMI）

**机制。** 只对增强差分建立慢速记忆，真实梯度保留标准快速响应：
[
q_t=\rho_\delta q_{t-1}+(1-\rho_\delta)\bar\delta_t,
]
[
m_t=\beta_1m_{t-1}+(1-\beta_1)(g_t^r+\lambda q_t).
]
二阶矩默认基于当前混合梯度：
[
v_t=\beta_2v_{t-1}+(1-\beta_2)(g_t^r+\lambda\bar\delta_t)^2.
]
q_t是detach的梯度状态，不保留跨step计算图。每步仍只有一次Adam参数更新。

**问题依据。** KR固定参考batch短窗差分持续性5/5正向，ML持续性较弱。ANTI虽降低视图条件方差，却未超过IID2的selected AUC。ADMI检验的是跨step差分利用，不是继续降低视图配对方差。

**增强信息。** δ_t明确表示相对真实目标的增强增量，不是“梯度质量分数”。其价值由selected AUC而非cosine、SNR或单步BCE判断。

**与Adam的区别/退化。** ρδ=0时q_t=δ̄_t，退化为对当前混合梯度做标准Adam；λ=0时退化为普通Adam。ρδ=β1时，匹配初始状态和偏差修正后，增强分量EMA可与标准一阶矩中的增强项重合，必须数值验证，不能将同一EMA拆成两条冒充创新。ρδ≠β1才形成真正双时间尺度。

**预期收益。** 若增强差分的有益分量跨step持续而瞬时增强噪声较大，q_t可平滑注入方向，同时保持真实梯度快速响应。若差分是系统性有害偏差，滤波只会更稳定地保留有害方向。

**失败模式。** 自然minibatch间差分不可比；参数漂移使旧δ失效；q_t滞后；增强改变目标分布而记忆放大偏差。KR无selected收益且ML无收益时应停止，不以更长时间常数续命。

**最小实验/成本。** K=1，ρδ取0.90和0.99；与ρδ=0的相同增强Adam、无增强Adam、P0 shadow EMA比较。每step额外增强forward/backward各一次，额外状态一个参数张量，不增加optimizer.step。

**创新潜力。** “增强差分专属的跨step记忆”是可检验机制，但EMA本身不新。必须证明它比整体梯度EMA和固定参数EMA更有针对性，并取得selected AUC增量。

## 3. 候选C：可靠性调节的差分注入（RDI）

**机制。** 两个独立增强视图同时提供训练方向和同状态重复性观测：
[
\bar\delta_t=(\delta_{t,1}+\delta_{t,2})/2,\quad
\hat V_t=\|\delta_{t,1}-\delta_{t,2}\|^2/2,
]
[
\hat S_t=\|\bar\delta_t\|^2-\hat V_t/2,quad
r_t=EMA_\tau(\hat S_t),\quad n_t=EMA_\tau(\hat V_t),
]
[
a_t=clip\left(\frac{\max(r_t,0)}{\max(r_t,0)+n_t+\epsilon_s},0,a_{max}\right),
\quad g_t^{mix}=g_t^r+\lambda a_t\bar\delta_t.
]
r、n、a均detach，不训练独立收益预测器。

**问题依据。** 差分均值和方差随训练阶段变化，但稳定差分未必有益。RDI尝试区分“信息存在”和“是否注入”。当前没有证据证明S/V能预测长期AUC。

**区别/替代。** 与固定ADMI相比，RDI动态改变注入增益；与整体cosine门控不同，它估计同batch两个增强视图的重复性。但正S不等于正AUC。更简单替代是固定λ或预注册的阶段衰减λ_t；如果固定规则同样有效，控制器没有必要。

**失败模式/成本。** K=2的方差估计本身噪声较大；高维范数可能由少数坐标支配；a_t可能长期贴近0或a_max。仅在P1出现条件收益或明确阶段失配后执行。额外一个增强forward/backward，两个标量EMA状态。

**创新潜力。** 可能形成“增强既产生梯度，也提供在线不确定性观测”的联合方法，但必须超过同预算固定注入规则，否则只保留为诊断。

## 4. 候选D：真实梯度与增强差分双时间尺度

[
m_t^r=\beta_r m_{t-1}^r+(1-\beta_r)g_t^r,quad
q_t^\delta=\beta_\delta q_{t-1}^\delta+(1-\beta_\delta)\bar\delta_t,
]
[
u_t=\hat m_t^r+\lambda\hat q_t^\delta.
]
它将真实梯度和增强差分分别保存，解释更清楚，但多一个完整一阶矩张量。与ADMI属于同一机制族：当ADMI分开维护真实梯度EMA和差分EMA并相加时，两者数学等价。因此不单独增加训练臂，纳入ADMI实现和公式对照。AdEMAMix是整体梯度双EMA的强近邻，仅把慢EMA改名为增强差分EMA不够构成创新。

## 5. 候选E：增强差分驱动二阶矩

[
v_t=\beta_2v_{t-1}+(1-\beta_2)
[(g_t^r+\lambda\bar\delta_t)^2+\kappa\lambda^2\hat\sigma_{\delta,t}^2].
]
该方法让增强视图方差只影响分母，抑制不确定坐标的步长。风险在于条件视图方差不等于自然minibatch梯度方差，也不保证是参数更新风险的代理。它可能只是隐式降低部分坐标学习率。先比较普通β2/epsilon调整；只有P1显示方向有用但更新幅度失配时再考虑。当前暂缓。

## 6. 候选F：周期差分平均

[
q_t=W^{-1}\sum_{j=0}^{W-1}\bar\delta_{t-j},\quad
g_t^{mix}=g_t^r+\lambda q_t.
]
与EMA相比，它只保留最近W步并在窗口内等权。KR短窗持续性提供动机，但四步观察不足以选择W。PMA已有周期梯度平均近邻，ADMI的EMA状态更小、通常更平滑。先做离线递推对照，不独立训练。

## 7. 候选G：递归差分控制变量

一种递归估计形式为：
[
q_t=\bar\delta_t(\theta_t,B_t)+q_{t-1}
-\bar\delta_{t-1}(\theta_t,B_t).
]
它要求在当前参数θ_t和可比batch上重算上一时刻估计，或有可靠的跨步batch配对。当前探针固定参考batch，不能证明真实训练不同minibatch满足该条件；而且额外计算成本较高。MARS已研究预条件化与递归方差缩减的结合。暂缓，除非后续证明跨步差分漂移是主要误差来源。

## 8. 候选H：Lookahead慢权重反馈

在线fast权重每k步更新一次slow权重：
[
\phi_{j+1}=\phi_j+\alpha(\theta_{jk}-\phi_j),
\quad \theta_{(j+1)k}=\phi_{j+1}.
]
它会改变后续在线训练轨迹，与P0 shadow EMA有本质区别。Lookahead已有成熟工作和开源实现，不能把慢权重反馈称作新颖。它可作为P0成功后低成本对照，但不是第一批主算法。

## 9. 候选取舍

| 候选 | 不存在/未验证的假设 | 更简单替代 | 决策 |
|---|---|---|---|
| A 参数EMA | 旧协议收益能迁移到当前自然分布（未验证） | 在线Adam | 第一批必做，历史效应足以支持复验 |
| B ADMI | 跨步差分在真实minibatch上可利用（未验证） | 普通增强Adam、固定EMA | 第一批主候选，低成本直接检验 |
| C RDI | 两视图S/V能反映长期AUC效用（未验证） | 固定λ、固定阶段规则 | 条件进入 |
| D 双时间尺度 | 差分应有独立时间常数（未验证） | ADMI单差分EMA | 合并到B |
| E 二阶矩 | 视图方差能代表坐标更新风险（未验证） | 普通β2/epsilon | 暂缓 |
| F 周期平均 | 差分在固定窗口内近似平稳（未验证） | EMA | 暂缓，先离线比较 |
| G 递归校正 | 跨step梯度差分可比且可低成本重算（未验证） | ADMI | 暂缓 |
| H Lookahead | 参数回拉优于shadow评价（未验证） | P0 | 作为成熟对照，不主张创新 |

**明确排序：P0轨迹平均 > P1增强差分记忆 > P2可靠性调节。** 这不是按复杂度排序：P0有最强历史实证；P1最直接检验当前新证据；P2的控制信号尚无长期效用依据。
