# 2026-11-01｜梯度＋数据增强＋动量式优化：多方案探索

**状态：研究设计完成，未启动新训练。** 本目录基于 GA31-R3 最新实验（发布分支 26-11-01）和历史 PolyakAdam 证据，形成可交付 Codex 的有限实验合同。研究范围仅限梯度、数据增强、动量式优化和参数轨迹平均；不包含差异化共享、多原型或跨域读取。

## 当前结论

最值得研究的问题不是“怎样进一步降低增强视图方差”，而是：**增强产生的差分梯度中，是否存在可跨训练步利用的分量；如果存在，是否应通过梯度历史记忆或参数轨迹平均转化为 selected macro AUC 收益？**

现有证据支持三个不同判断：

1. ANTI2 在固定参数和 batch 上显著降低条件视图方差，但未超过同预算 IID2 的 selected AUC。方差下降不能单独作为算法目标。
2. KuaiRand 固定参考 batch 上的增强差分在相邻训练状态间呈短窗正向持续性（E10/E40均5/5 seed），但四步观测不能确定最佳时间尺度，也不能证明其能改善真实训练。
3. 历史 PolyakAdam(0.995) 在旧 MovieLens 协议六个 seed 上有 +0.004022 的配对 AUC，36/36 cell-seed正向；它值得在当前自然分布和冻结协议下重验，但旧协议结果不是当前预期收益。

## 候选排序

| 优先级 | 候选 | 机制 | 当前决策 |
|---|---|---|---|
| P0 | 轨迹平均评价器（Polyak/EMA） | 只改变评价/选模模型，不改变在线训练 | 第一批必做；历史证据最强、成本最低 |
| P1 | 增强差分记忆注入（ADMI） | 对增强差分单独做时间滤波，再注入Adam一阶矩 | 第一批主算法；直接检验持续差分是否可利用 |
| P2 | 可靠性调节的差分注入（RDI） | 用独立视图估计差分可重复性，调节注入增益 | 仅当P1有正向信号或明确失败机制时进入第二阶段 |
| 探索保留 | 双时间尺度梯度记忆 | 快速真实梯度＋慢速增强差分 | 与P1机制近邻，先作为P1固定滤波系数变体，不独立堆臂 |
| 暂缓 | 增强驱动二阶矩 | 让增强差分影响Adam的v状态 | 当前没有证据说明一阶矩之外的二阶矩修正有额外价值 |
| 暂缓 | 周期差分平均 | 在窗口内均匀平均差分而非EMA | 与P1做低成本数学/离线对照，不先训练独立方法 |
| 暂缓 | 差分递归控制变量（MARS/SARAH式） | 用跨步差分变化构造递归估计 | 需要可比梯度支持；当前短窗固定参考batch不足以证明真实batch可用 |
| 对照 | Lookahead式慢权重反馈 | 周期性将在线权重拉向慢权重 | 已有成熟近邻，先作为P0参数平均的训练反馈对照，不主张原创 |
