# 03｜优先方案算法与实现规范

## 1. 总体实现原则

只复用GA31-R3已冻结的fixed1模型、自然数据分布、loss预算、评价和seed协议。新代码建议放入 experiments/gradient_aug_momentum_20261101/，新报告放 research_reports/2026-11-01_momentum/，不修改GA31-R3代码和历史报告。数据/模型配置身份、代码SHA、环境版本、seed、row顺序哈希均写入manifest。

当前主干为fixed1 MDMTRec/M3oE、3域×2任务、4 shared experts；batch=40960、50epoch、FP32、Adam lr=.01、betas=(.9,.999)、eps=1e-8。ML工作基线使用L2-ML（loss scale=1, wd=1e-4），KR使用B-KR（loss scale=1, wd=1e-5）。自然数据分布和split继承GA31-R3。不得以旧MovieLens采样分布或旧损失缩放结果替代。

## 2. P0：轨迹平均评价器（Polyak/EMA Shadow）

### 2.1 精确定义

在线参数θ_t由原始Adam训练，shadow参数φ_t不参与forward训练，不接收梯度：
[
\phi_0=\theta_0,\qquad
\phi_t=\rho\phi_{t-1}+(1-\rho)\theta_t.
]
默认ρ=0.995，每个真实optimizer.step后更新一次。参数更新可用：
~~~
with torch.no_grad():
    for p_shadow, p_online in zip(shadow.parameters(), online.parameters()):
        p_shadow.mul_(rho).add_(p_online, alpha=1-rho)
~~~
Buffer不盲目EMA：如存在running statistics，默认复制当前在线buffer；LayerNorm affine参数属于Parameter，应参与EMA。初始化、更新次数和影子参数计数均写入metadata。

额外敏感性只允许ρ=0.99或warmup=10%二选一，不能同时铺开网格。默认复现历史ρ=.995全程更新。

### 2.2 验证、checkpoint和恢复

每epoch分别计算online与shadow的六格macro AUC、六格LogLoss和逐cell指标。online与shadow分别按相同规则选择自己的selected epoch：验证macro AUC严格提升才更新，平局选更早epoch，E0不参与选择。最终分别报告online-selected和shadow-selected，不能让shadow选点覆盖online选点。

checkpoint必须保存online model、Adam state、shadow state、epoch/step、shadow update count、Python/NumPy/Torch CPU/CUDA RNG、loader generator和数据顺序身份。恢复后继续在线训练，shadow只按后续在线step更新；不能从恢复时在线参数重新初始化shadow。

参数EMA不反馈训练，不增加backward或optimizer.step。每epoch额外一次shadow validation；参数内存约+1份模型参数。

## 3. P1：来源分离双时间尺度动量（SAD-Momentum）

### 3.1 精确定义

本轮选择“真实梯度快EMA + 增强差分独立EMA”的分源版本，不选择嵌套滤波版本。理由：分源状态有清晰语义，且βδ=β1时可精确退化为标准Adam的一阶矩；嵌套滤波会对差分连续滤波两次，容易把额外滞后误认为独立机制。

同一batch、同一θ下计算：
[
g_t^r=\nabla L_r(\theta_t;B_t),\quad
\delta_t=\nabla L_a(\theta_t;\tilde B_t)-g_t^r.
]
分别更新一阶状态：
[
m_t^r=\beta_1m_{t-1}^r+(1-\beta_1)(g_t^r+\omega\theta_t),
]
[
q_t^\delta=\beta_\delta q_{t-1}^\delta+(1-\beta_\delta)\delta_t.
]
偏差修正：
[
\hat m_t^r=m_t^r/(1-\beta_1^t),\quad
\hat q_t^\delta=q_t^\delta/(1-\beta_\delta^t).
]
实际一阶更新方向：
[
u_t=\hat m_t^r+\lambda\hat q_t^\delta.
]
二阶矩保留当前混合梯度的标准Adam形式：
[
h_t^v=g_t^r+\lambda\delta_t+\omega\theta_t,
\quad
v_t=\beta_2v_{t-1}+(1-\beta_2)(h_t^v)^2,
\quad \hat v_t=v_t/(1-\beta_2^t).
]
参数更新：
[
\theta_{t+1}=\theta_t-\eta\frac{u_t}{\sqrt{\hat v_t}+\epsilon}.
]

ωθ为coupled weight decay。真实梯度通道加入decay；差分δ不含decay，因为同状态真实/增强梯度差分中decay严格抵消；二阶矩通道使用混合梯度+decay。βδ=β1时，u_t严格等于对(g_real+λδ+decay)做同β一阶EMA并进行相同bias correction。βδ≠β1时才改变增强增量时间尺度。

### 3.2 退化与等价

- λ=0：退化为当前普通Adam。
- βδ=β1：一阶矩与标准Adam对混合梯度的EMA等价；相同初始状态、step计数、decay和bias correction下，参数更新应数值一致。
- βδ=0：qδ=δ_t，退化为普通增强Adam。
- βδ趋近1：差分历史更长，启动bias correction和滞后更敏感。
- 增强关闭或目标域无样本时δ=0；qδ按βδ自然衰减，不伪造梯度或推进增强RNG。

### 3.3 默认参数与有限敏感性

β1=.9、β2=.999、λ=.5沿GA31-R3固定；βδ默认=.99，唯一主敏感性=.9。两者分别代表约100步和10步量级的EMA时间尺度，不声称四步探针已精确估计最优值。不得搜索βδ=.95/.98/.995/.999网格。

P1第一阶段使用K=1单一Gaussian视图，κ=.1、目标域和字段规则沿GA31-R3。不能把ANTI2指定为必选增强。RNG独立隔离；loss原样本权重预算不变。


### 3.4 训练循环伪代码

~~~
initialize online model theta
initialize Adam-compatible v, counters
initialize m_real = 0, q_delta = 0
initialize optional shadow phi = theta

for each original batch B_t:
    g_real = gradient(original_loss(theta, B_t))
    if enhancement_enabled:
        view = make_view(B_t, independent_view_rng)
        g_aug = gradient(augmented_loss(theta, view, original_B_denominator))
        delta = g_aug - g_real
    else:
        delta = zero_gradient_like(g_real)

    m_real = beta1*m_real + (1-beta1)*(g_real + wd*theta)
    q_delta = beta_delta*q_delta + (1-beta_delta)*delta
    v = beta2*v + (1-beta2)*(g_real + lambda*delta + wd*theta)^2

    mhat_real = m_real / (1-beta1^t)
    qhat_delta = q_delta / (1-beta_delta^t)
    vhat = v / (1-beta2^t)

    theta -= lr*(mhat_real + lambda*qhat_delta)/(sqrt(vhat)+eps)

    if shadow_enabled:
        phi = rho*phi + (1-rho)*theta

    at epoch boundary: evaluate online and/or shadow
~~~

实现可用自定义Optimizer或训练循环内显式状态，但必须保证None梯度语义、每参数step计数和weight decay行为与当前Adam一致。不得在普通Adam后再调用第二次optimizer.step；不得in-place修改某一路梯度而污染另一状态通道。

### 3.5 计算图、梯度流和成本

每batch计算真实和增强两路梯度。优先使用torch.autograd.grad在同一参数状态分别计算；也可用一次合并loss backward，但必须证明其与两路梯度差分在原样本分母、目标域mask和None梯度上的等价。θ_t每batch只更新一次。

q_delta、m_real、v均为detach状态，不保留计算图。额外状态一个参数张量q_delta；显存增量约一个模型参数副本。额外视图增加一次增强forward/backward，但optimizer.step仍为一次。随机视图不改变标签、域ID、路由字段和dense特征。

### 3.6 关键诊断

1. βδ=β1精确退化单步测试：相同θ、batch、增强view和Adam状态，比较标准混合梯度Adam与SAD更新；检查参数、m/v、step和None语义。
2. 训练中报告q_delta范数、m_real范数、增强注入比 λ||qhat||/(||mhat_real||+ε)、逐epoch注入比和selected前后变化；按数据集和seed统计。
3. 固定参考batch上比较δ_t与q_t方向/范数变化，只作解释性诊断；是否有效由selected macro AUC决定。

## 4. P2：可靠性调节的差分注入（条件候选）

只有P1至少一个数据集有明确正向selected趋势，或P1稳定失败且注入比显示差分滞后/噪声过大，才进入P2。不得第一批同时叠加。

K=2独立视图：
[
\bar\delta_t=(\delta_{t,1}+\delta_{t,2})/2,\quad
\hat V_t=\|\delta_{t,1}-\delta_{t,2}\|^2/2,
\quad \hat S_t=\|\bar\delta_t\|^2-\hat V_t/2.
]
[
r_t=EMA_{\tau}(\hat S_t),\quad n_t=EMA_{\tau}(\hat V_t),
\quad a_t=clip\left(\frac{max(r_t,0)}{max(r_t,0)+n_t+\epsilon_s},0,a_{max}\right).
]
使用g_t^r+λa_tδ̄_t替代固定增益。默认τ=0.9，a_max=1；epsilon_s按开发集梯度能量尺度定义并冻结，不用test调节。S为负时原样记录，控制器gain置0是预先定义的截断，不得把负S删掉后报告为可靠性识别成功。

P2必须与固定λ=.25/.5/.75三条规则比较，且视图数和增强预算一致。必须报告a_t分布、贴近0/上界比例、r/n原始值、S负值比例和按epoch注入量。若a_t坍缩、固定规则匹配或selected AUC无增量，停止控制器路线。

## 5. 组件开关和实现验收

配置必须显式区分：
- use_shadow_ema：仅评价影子参数，不改变训练；
- use_augmented_view：增强训练方向；
- use_delta_momentum：独立差分EMA；
- use_reliability_gain：仅P2使用，依赖K=2；
- beta_delta、rho_shadow、lambda_aug、noise_scale。

必须实现的消融：普通Adam；Adam+shadow EMA；普通增强Adam（βδ=0）；SAD βδ=.9；SAD βδ=.99；SAD+shadow EMA。P2只在第二阶段进入，不能枚举所有开关笛卡尔积。

必要数值核验：
1. λ=0与普通Adam单步更新一致。
2. βδ=β1时SAD与混合梯度Adam单步更新一致。
3. βδ=0时SAD与当前增强Adam单步更新一致。
4. P0关闭时不分配shadow、不额外验证、不改变RNG。
5. P0开启不改变online参数、Adam state和训练batch顺序。
6. 断点恢复后shadow和q_delta状态、计数、RNG及后续轨迹与不中断执行匹配。
7. 同一batch两路梯度的None/unused参数语义保持一致，不能把None无差别改成显式零后提交Adam。

不得建立大量镜像测试；以上是影响公式选择的核心等价关系。
