# MDMT 条件监督重组与历史优化协同：v3 研究总览

日期：2026-11-02。性质：研究设计与 Codex 交付规范；没有运行正式 GPU 实验，没有新增性能结果。

## 1. 当前结论

最值得继续的方向是：**利用真实域×任务×联合标签边界，重组任务确实需要区分的监督信息；再使信息的采样概率进入历史更新，而不是只改变输入视图。**

本轮保留两个机制不同的主要候选：

- **PAIR-ECCM：条件监督重组＋采样频率校正的条件动量。** 真实 BCE 保留普通 Adam 一阶矩；成对监督按标签边界保存历史，并用实际采样概率校正历史更新。共享参数的更新分子确实改变，不只是动态加权当前梯度。
- **PAIR-CV：条件监督重组＋历史控制变量梯度。** 历史表用于构造条件无偏的当前梯度估计，随后使用普通 Adam。这条路线明确不声称修改 Adam 内部递推，是更保守的竞争方案。

必要简单替代为 **PAIR-Adam：同样的真实成对监督＋普通 Adam＋固定参数 EMA**。所有收益首先与无增强固定 EMA 比较，再与上述简单替代比较。若简单方法达到相同效果，直接选择简单方法。

字段条件重组作为设计备选，不进入本轮正式训练队列。没有把四个候选全部安排为大规模实验。

## 2. 两个问题如何统一

Q1 不再定义为“哪些梯度互相冲突”，而定义为：同域内，哪个任务的哪一类真实正负边界仍存在排序不足。例如 ML 的 10 样本对 task0 为正、对 task1 为负，因此分别需要与 00、11 比较。这是标签定义直接提供的监督结构，不是假设潜在需求网络能够自动学出来的结论。

Q2 利用同一个边界标识和采样概率。需求统计决定本步读取哪个边界；ECCM 用该概率校正边界历史的观察频率，避免把“采得多”直接变成“历史刷新得更快”；CV 则用同一标识从历史表减去旧参照、加回总体参照。完整信息链为：

`真实域和多任务标签 → 有效边界与排序不足 → 真实样本成对重组 → 参数梯度 → 条件历史更新/校正 → 在线参数 → 非反馈固定参数EMA`。

不制造新标签，不把其他任务标签作为模型输入，不做跨域强制对齐，不构造对抗输入，不改变 fixed1 网络。

## 3. 已接受事实与不重开的议题

开始本轮前，已优先读取 main 的 `EXP_AI_CONTEXT.md` 与 `experiments/Experimental_Global_Summary.md` 的最新权威裁定。main 基准为 `96d21fccff4e9304589e82527ec7a859e8c3f05c`。

小域不是困难域；固定非反馈参数 EMA 已有排序收益；统一 loss 尺度会影响 AUC；SAD/AIG-M 已经改过差分历史但未建立稳定增量；B2 的开发正信号未形成强基线优势；J/F/TG/AG 当前版本不晋级。以上均不作为本轮新发现或专门复验任务。

固定参数 EMA 与 Adam 动量是两个对象。EMA 的历史收益不计入新方法贡献。本轮也不恢复原型或差异化共享架构研究。

## 4. 最可能推翻复杂设计价值的解释

第一，全部收益只是新增成对排序监督带来的，历史设计没有独立价值。由 PAIR-Adam 判别。

第二，收益只来自给增强通道较长记忆，不需要域任务条件历史。由同一监督、同一采样、同一 beta 的 collapsed-history 对照判别。

第三，只需要改进当前梯度估计，不需要改 Adam 的一阶矩。由 PAIR-CV 判别。

这些是会改变算法选择的必要控制；不是重新验证 EMA、尺度效应或旧失败配置。

## 6. 本轮可以接受的结论范围

现在足以接受“这两条路线值得有界开发”的设计判断。尚没有证据称条件历史、成对监督或二者的协同已经提升推荐性能。下一阶段按预设门推进、选择简单替代或停止具体实现，不为解释所有现象无限扩展实验。
