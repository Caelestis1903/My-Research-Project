# 05 最终算法与代码接口规范

本文件与 02/03 为同一规格。冲突不得由实现者自由择一；修改必须在正式训练前形成有界修订记录。

## 1. 输入、底座与监督预算

输入为当前自然真实 batch 的 x、完整二元标签 y[B,2]、原始行号、domain_indicator、step、独立 RNG。输出为一次在线参数更新、一次非反馈固定 EMA 更新及可复现状态。

底座固定为 EMA02V2 源提交 `38a53bc1aa6e0c16c0b6d2b0e24e07018f91ab27` 的 fixed1 模型和 train-only 数据管线。它尚未作为实验代码合入当前 main，Codex 应按固定 SHA 获取所需依赖并建立本轮独立 vendor，不得从 main 根目录猜测同名 trainer 已是最新底座。

真实 BCE 严格沿用 `sum BCE/(B*T)`，尾批使用实际 B。新增 `lambda_pair*sum w_c R_c` 为显式辅助监督；不复制原行、不改自然 sampler、不缩放原 BCE、不增加 optimizer step。默认一条件每步、2048 pair、有放回抽样；没有条件时辅助项为零。

## 2. Raw logits 的安全取得

参考模型 `reference.py` 的 tower 输出在线 sigmoid 之前为 raw logits，索引为 t*D+d；原 gate 路径使用 `emb.detach()`。

本轮建议对六个 tower 注册只读 forward hook，保留本次训练图中的输出，再按真实域 mask 组合 [B,T] logits。hook 不返回替换输出，不 detach 缓存 logits，不改变 gate。一个真实 forward 同时得到原 probability 和 pair logits；结束立即移除 hook/引用。

**不得调用 v2 的 `probe_logits` 训练参数梯度**：该函数冻结模型参数并改变输入导数路径，仅适合过去的只读输入 probe。不得用 clamp(probability) 再 logit 代替真实 raw logits。

## 3. 参数作用范围

H 只覆盖以下全局共享 dense 参数：`shared_weight`、`shared_bias`，以及前缀 `skip_conn.`、`star_mlp.`、`expert.`。

`embedding.` 虽为共享参数，但本轮因稀疏访问和成本不建立 H，使用普通当前梯度 Adam。`slot_weight.`/`slot_bias.`、`domain_expert.`、`task_expert.`、`gate.`、`tower.` 也走普通当前梯度 Adam。它们仍接受实际合法 pair 的梯度，不能因为不建历史而全部冻结。

注意 MLP_N 内部层名包含 `domain_specific`，共享 expert 内部也使用该名字；**不能按字符串包含 domain_specific 就判为域专属**。按上述外层模块归属建立参数清单、互斥覆盖检查及 hash。

共享集合应在每个非空真实 batch 中有定义的真实梯度；若出现意外 None，先作为接线错误停在 Stage0/实现检查，不以补零改变源语义。其余参数严格保留 None 与显式零的区别；None 不推进该参数 step/wd/m/v，显式零按源 Adam 语义推进。

## 4. 三种更新模式

### 普通 PAIR-Adam

抽取 s 后，对 `L_real+lambda*(w_s/q_s)*R_s` 一次 backward，标准 Adam 更新全部参数。

### ECCM

先用 autograd.grad 获取 r_s 在共享集合上的梯度，retain_graph=True，再对同一联合 loss backward 获取普通当前混合梯度。通过减去已知 pair 当前项或单独缓冲取得共享 g_real，不能从已经加了 wd 的向量再次加 wd。

共享参数更新：

1. 用旧 D、当前标签计数确定 w/q，保存本次采样概率；所有有效条件 n_c += 1。
2. 用旧 H_s 和 r_s 做 `H_s += .01/q_s*(r_s-H_s)`。
3. `m_real=.9*m_real+.1*(g_real+wd*theta)`。
4. `v=.999*v+.001*(g_real+wd*theta+lambda*(w_s/q_s)*r_s)^2`。
5. 分子 `m_real/(1-.9^step)+lambda*sum_c w_c H_c/(1-.99^n_c)`，分母 `sqrt(v/(1-.999^step))+1e-8`，lr=.01。

H 的 n_c 是有效条件时钟，不是抽样计数；参数 m_real/v 的 step 维持源 Adam 的参数级 step。只有本轮指定的 dense 集合采用此分子，其余参数严格普通 Adam。可用一个自定义 optimizer 的分组 dispatch 实现；不得对同一参数做两次 step。

### CV

先读取旧 H，计算 `C=sum wH-(w_s/q_s)H_s`。联合 loss 的普通 backward 后，仅对共享 `.grad` 加 `lambda*C`，得到校正后的当前梯度；全部参数走普通 Adam，coupled wd 由 optimizer 加一次。然后用当前 r_s 更新 `H_s=.9 H_s+.1 r_s`。必须先读旧表再写新表。

CV 不使用 ECCM 的 active clock、betaA 偏差修正或 1/q 历史更新。不得把两种方法混为一个模糊的 memory_mode。

## 5. EMA、状态与更新顺序

每步统一顺序：清 grad → 真实 forward/raw logits → 由旧 D 取 q → pair loss/必要共享 autograd → 联合 backward → 对应历史/optimizer 更新 → 在线参数完成 → 固定参数 EMA → 更新 D → 写计数。

ECCM 的 H 在分子使用前更新；CV 的 H 在旧表构造完成且用于本次更新后才更新。所有 H、D 和统计 detach，不产生跨步图。EMA 从 theta0 初始化，ML rho=.9828205985452511，KR rho=.995；参数按 rho 平均，buffers 按源实现复制。EMA 不反馈抽样或训练，不增加教师视图。

checkpoint 包含模型、全部 optimizer 状态、H、active clocks、D、参数清单、独立 RNG、global step、epoch、选点状态、数据/source hash。恢复必须延续所有状态，不能只恢复参数。不同方法状态不可交叉加载。

## 6. 超参数与边界

共用 Adam lr=.01、betas=(.9,.999)、eps=1e-8、coupled wd：ML1e-4/KR1e-5；foreach/fused/amsgrad=False，FP32，AMP/TF32关闭。betaA=.99；CV历史beta=.9；D更新beta=.9；q三部分质量为 .25/.25/.5；需求offset=.05。只对 lambda_pair 做 {.05,.2} 有界开发，其他值不做多维笛卡尔搜索。

lambda=0 **整条历史/pair路径旁路**，直接调用源标准 Adam，应退化到 A0；再关闭评价 EMA 得到同一在线轨迹，而非额外训练臂。PAIR 普通模式并不退化成 Gaussian A1，A1 必须显式调用源 Gaussian 实现。

某域/类别缺席：对应 w=0、q不含该条件、H/n冻结，不从 validation/test 借样本、不跨域回填、不重新归一化其他域任务的目标权重。某步所有 pair 不存在时，ECCM 本步只读真实通道，未激活 H 保留但不注入；CV 本步辅助当前梯度为零，既有 Adam 动量仍按普通规则衰减。这不是宣称已有历史可瞬间等于从未增强的 A0。

显式零 r 正常更新历史；不根据范数/方向裁剪。非有限值按运行故障保存现场，不临时改超参挽救该 seed。单任务允许退化成域内二分类边界；超过两任务默认拒绝本轮配置，避免条件数及稳定界失效。

## 7. 随机性、成本与必要日志

RNG 分为初始化、loader、条件抽样、pair 索引；均由 dataset/seed/step/stream 派生，不能消费源 loader RNG。静态/动态模式使用相同均匀随机流，但不同 q 的结果可不同。

PAIR-Adam 通常一次真实 forward＋一次 backward；ECCM/CV 增加一次共享参数 autograd，复用同一图，没有额外合成样本 forward。collapsed-history 使用相同辅助 autograd 以匹配梯度接线路径。

H 额外持久显存为 4*K*P_S bytes；最多 ML12、KR24。即使用全部 P 作为宽松上界，也分别约37.1MB、155.0MB（十进制）；实际只含共享子集更少，但 scratch/activation 峰值须实测，不能把上述状态大小当峰值显存。没有新增可训练参数，没有声称零计算成本。

记录 w、q、w/q、D、active/selected clocks、alpha/q、H范数、实际更新范数、六格有效数、唯一原行数、pair数、forward/backward/optimizer/EMA计数、耗时、峰值显存。报告全部成本，不仅最后一次 backward。若显存不足，不静默缩 batch；停止当前执行并转简单替代或在新版本改规格。
