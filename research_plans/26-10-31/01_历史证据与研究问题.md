# 01｜历史证据审查与研究问题定义

**日期：2026-10-31｜状态：研究规划，执行语义已按 v2 同步；没有启动训练**

## 1. 当前研究判断

建议重启“梯度调节 + 数据增强 + 动量式优化”路线，但不应恢复旧版模块组合。最值得优先研究的问题是：

> 在保持 Sample 原样本、领域和任务权重预算的前提下，增强视图产生的梯度是否包含真实样本梯度之外、且能改善真实验证样本泛化的有效信息？如果包含，它应该以何种方式进入当前参数更新和 Adam 的历史状态？

这不是把三个旧模块简单叠加。增强改变输入与梯度分布；梯度调节决定增强梯度的进入比例和参数作用范围；动量优化决定当前梯度如何被累积、预条件化并影响后续更新。三者有明确计算链路，适合通过阶段性实验拆开。

## 2. Sample objective 的准确含义

令域 d 的人口比例为 p_d=n_d/N，域任务平均损失为
\[
\bar\ell_{d,t}(\theta)=\frac1{n_d}\sum_{i\in\mathcal D_d}\ell_{i,t}(\theta).
\]

项目 S6 的 Sample objective：
\[
\boxed{L_{\mathrm{Sample}}(\theta)=
\frac1T\sum_{t=1}^T\sum_{d=1}^D p_d\bar\ell_{d,t}(\theta)}
\]
实现中每样本域损失系数 w_d=1，自然串联打乱采样下有效域系数 a_d=p_d。Equal 则使用 w_d=1/(Dp_d)，使有效域系数为 1/D。原始 M3oE 的六项 group-mean BCE 求和、legacy_group_sum、Sample 和 Equal 不能仅凭名字互换。

若抽样分布从目标 p 改为 q，但仍要估计同一 Sample 目标，应使用重要性修正：
\[
L_{\mathrm{Sample}}=\frac1T\sum_t
\mathbb E_{d\sim q}\left[\frac{p_d}{q_d}\bar\ell_{d,t}\right].
\]
样本级采样则对应 p(i)/q(i)。改变 q 而不修正通常改变目标；正确修正 q 可保持目标期望，但改变梯度估计方差、重复曝光和有限训练轨迹。

统一乘性损失缩放 cL 不改变无正则化经验风险的最优点，但会改变实际优化过程。Adam 在理想化情况下对梯度整体缩放近似不敏感；实际仍受 epsilon、耦合 L2 weight decay、梯度裁剪、状态初始化、数值精度及训练早期影响。因此不能预设 0.1 缩放等价，也不能预设它必然提高 AUC。

## 3. 历史实验事实

### 3.1 Sample 的已知收益边界

experiments/Experimental_Stable_Findings.md 的 SF001/SF002：在已测自然数据比例、模型、四种子和选点协议内，Sample joint training 相对 single-domain reference 没有发现普遍 practical residual negative transfer（72 个汇总单元中 0 个达到稳定 practical NT 门槛）；Equal 在特定 selected 大域角色/目标 cell 出现可重复损害，而 Sample 没有出现同一门槛下的损害。

**决策：** 本轮不以“Sample 下小域必然被压制”或“必须重新平衡域梯度”为动机。Sample 不等于梯度方差最小化，也不保证增强梯度对验证分布有益；SF001 也不覆盖极端未测 ratio、所有目标域和所有参数路径。

### 3.2 同目标不等于同轨迹

N17 和自然 MovieLens 复核保留了同 Sample 目标下不同 q 会改变有限训练轨迹的观察，但没有支持“Adam 是所有采样差异的必要条件”。自然 MovieLens V2 中，Adam 的 SB−SN selected macro AUC 约 +0.000479（2/2），SGD 约 −0.004258（1/3），且 SGD selected 与 final 都是 E50；不能宣称普遍 q 优势。N17 正式统计主比较未通过预注册门槛。

**决策：** 将 q 看作改变随机梯度估计器与曝光过程的变量，而不是默认性能增强器。增强同样可能改变样本视图、梯度协方差和优化器看到的时间序列。本轮用归一化视图替换保持原样本总系数，不改变原始采样顺序；完整训练风险仍发生变化。降低方差本身不自动意味着 AUC 提升。

### 3.3 10-21 增强复现实验

重点文件：
- history_experiments/codex__m3oe-reproduction-2026-10-21/experiments/reproduction_20261021/DESIGN.md
- 同目录 DESIGN_STAGE2.md、REPORT.md、INTERPRETATION.md、protocol.py、stage2_protocol.py、analysis/

实验完成自然 MovieLens 与 KuaiRand、四种子、六臂共 48 次有效正式训练。D 不是完整历史 VUG/mask 复现，而是**specificity 权重 + 最小训练域复制一次 + 展平 embedding 高斯噪声**的上传代码版本。噪声作用于展平 embedding，包含 domain embedding；离散路由 ID 不变。历史检索没有找到可确认运行身份的完整 VUG、软标签、分阶段训练和自适应 mask 源码。

| 比较 | MovieLens | KuaiRand | 结论 |
|---|---:|---:|---|
| D−B macro AUC | +0.006303，4/4 正 | +0.008997，4/4 正但区间跨 0 | ML 组合收益强；KR 指标/域 trade-off 限制迁移 |
| D−B macro LogLoss | −0.015962，4/4 改善 | −0.008474，区间跨 0 | ML 概率质量改善可重复 |
| Dconst01−B macro AUC | +0.005676，4/4 正 | 约 +0.010539，波动大 | 常数权重套件也有收益 |
| G−D macro AUC | −0.003831，4/4 负 | −0.003302，2 正 2 负 | 旧调幅无稳定增量 |
| G−Gtau0 macro AUC | −0.003466，4/4 负 | −0.006484，4/4 负 | 匹配路径下 tau=0.5 调幅有害方向明确；KR 区间仍跨 0 |

D 同时改变样本权重、复制、噪声和总损失尺度，不能将组合收益归因于某一组件。Dconst01 表明动态 specificity 并非组合收益的必要条件，但仍包含复制、噪声和固定 0.1 权重。Gtau0 是匹配实现控制，判断调幅本身优先使用 G−Gtau0，而不是混合差异 G−D。

MovieLens 中 D 对三个域的 AUC 均为正；KuaiRand 中最大域 d1 两任务 AUC 均 4/4 下降，而小域 d2 上升。同一 D 方法的大小域模式不跨数据集稳定。自然 MovieLens 训练人口 800,167 行，三域 155,949 / 318,599 / 325,619；不能与早期人工采样人口混为一谈。

**决策：** 保留“增强组合在自然 MovieLens 有收益”这一经验事实；不接受“specificity 学到了样本价值”“复制稀缺域本身带来收益”“调幅强化了增强梯度”等未识别解释。首轮必须拆开增强、损失尺度和优化器状态入口。

### 3.4 动量历史证据

- S0：统一 EMA 已解释并超过特定分层动量方案的收益；反对“按共享度分配不同 β₁ 必然更好”。
- S5：KuaiRand natural / M3oE / Equal / tab1 / 四种子中，T−F selected target AUC 约 +0.0414/+0.0423（两任务均 4/4 正）。HT（TARGET history + FULL current）几乎恢复全部 T rescue；DH（FULL history + TARGET current）几乎没有恢复。指定条件下效果跟随 persistent Adam history carrier（m/v/step 组合），不能拆成 m 或 v 的独立因果效应，也不能外推到 Sample。
- S6：Sample 下两数据集 selected target contrasts 未达到 +0.003 practical gate；MovieLens late DH 是阶段条件现象。
- S8：完整 state、same-state、same-batch continuation 后，selected-anchor T/DH−F 约 +0.00006，远低于 practical threshold；MovieLens late rescue 属于已过拟合 checkpoint 的“少恶化”，未超过原始 F best；KuaiRand T 在 middle/late continuation 有损害。

**决策：** 动量历史是实际机制载体，但改变历史状态不等于提高 selected 泛化。S5 Equal 结果不能直接证明 Sample 下应给增强梯度独立维护 Adam moments。

### 3.5 旧动量和增强分支的剩余价值

PROJECT_ARCHITECTURE.md 记录 v1_momentum 的分层 β₁ + 域级课程，以及 v2_momentum 的 PolyakAdam、CAM、vGRA、LRMD 等。历史汇总曾报告 PolyakAdam(0.995) 在特定 MovieLens 六种子设置中约 +0.004022 配对收益，但 KuaiRand 未复现同等收益；CAM 有害，LRMD/vGRA 单种子收益未跨种子保持。旧结果属于较早人口和协议，只作为候选线索，不能直接当当前 Sample 方法性能基线。

旧 mask 分支记录的 VUG/DBO/三阶段增强高分存在配置身份和日志完整性限制；10-21 复现也未找到完整 VUG 身份。本轮不以旧 mask 最高分作为可复现证据。

## 4. 旧路线假设审查

| 旧假设/设计 | 判断 | 研究处理 |
|---|---|---|
| 小域梯度小，所以应放大 | 不成立为普遍前提；域大小不等于困难度或梯度范数 | 不再作为动机 |
| 全参数六格梯度范数对齐会改善共享 | 10-21 匹配路径对照负向；范数包含 private 参数，且不改单组方向 | 暂停 |
| 梯度冲突可以由正比例幅值缩放解决 | 数学上不成立：正比例缩放不改变两向量夹角符号 | 排除该解释 |
| 动态 specificity 权重必需 | Dconst01 也有增强套件收益 | 不把动态权重列为首轮必要模块 |
| 增强样本应与真实样本一样进入 Adam | 尚未检验；两类梯度可能具有不同偏差、方差和时间相关性 | 主研究问题 |
| 分层动量优于统一 EMA | S0 已有相反证据 | 统一 EMA/Adam 为强简单对照 |
| Sample 消除所有负迁移和优化问题 | 过度外推 | 只接受已测条件下的局部结论 |
| 减少梯度方差必然提高 AUC | 不成立；方差只是估计质量的一维 | 同时报方差、更新和真实验证表现 |

## 5. 研究问题地图

| 问题 | 核心未知 | 相互关系 | 优先级 |
|---|---|---|---|
| Q1 增强梯度增量价值 | 增强梯度是补充真实梯度、重复信息还是引入偏差？ | SAGU 主问题 | 最高 |
| Q2 真实/增强梯度进入 moments | 两类梯度是否应共享同一 m/v 历史？ | 依赖 Q1，连接优化器 | 高 |
| Q3 Sample 与增强曝光 | 如何保持基础人口权重，并明确增强带来的输入风险变化？ | q、p/q、复制 | 最高 |
| Q4 参数块差异 | 增强梯度对 shared、domain/task experts、tower 是否不同？ | 决定调节位置 | 高 |
| Q5 梯度与实际更新 | Adam 预条件化后，梯度质量排序是否仍成立？ | 决定监控量 | 高 |
| Q6 阶段与历史记忆 | 增强作用是改善泛化还是延迟过拟合？ | 选点与动量时间尺度 | 中高 |
| Q7 增强分布偏差 | 噪声/生成样本是否仍代表部署验证分布？ | Q1 的数据分布边界 | 高 |

首轮优先解决 Q1/Q3：先识别增强组合在 Sample 下是否有独立增量，再决定是否值得为增强梯度设计专属的梯度控制或优化器状态。Q2/Q4/Q5 用低成本机制探针辅助，不需要一开始就做全参数全时刻高开销诊断。
## 6. 执行语义修订说明（v2）

历史数字与结论未重写。03 已冻结 fixed1、自然无放回 shuffle、单 Adam 和 NR-Gauss-v1 的权重预算；增强会改变输入风险，不能再称严格保持完整 Sample 目标。普通 Adam 内耦合 L2 不随 loss_scale 缩放。四臂按增强效应、缩放效应和交互分别解释；I≈0 不代表缩放解释增强。相同 β、固定比例的双一阶 EMA 线性混合与混合梯度 EMA 等价，该等价性已写入 02，后续状态创新必须改变真正有效的变量。
