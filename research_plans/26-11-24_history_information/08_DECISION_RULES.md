# 08 — 阶段决策、方法收敛与Test冻结

## 1. 决策层级

| 层级 | 当前判断依据 | 本轮如何使用 |
| --- | --- | --- |
| 经验现象 | 固定EMA五seed收益、A21特定人口增量 | 直接作为研究起点 |
| 局部因果 | 同状态只换二阶处理/预条件顺序后的真实函数变化 | 指认运算后果与对照，不代替完整训练 |
| 机制解释 | 来源/阶段/参数支持与干预、完整控制一致 | 选择有证据的解释；允许几个机制共同成立 |
| 完整算法 | full50、五seed、Validation选点、冻结Test与逐格保护 | 决定独立方法、辅助组件或关闭候选 |

+0.003是最终强方法门，不能用于取消机制诊断或合理候选的第一轮完整训练。没有唯一解释也可以接受经验增量；存在已测失败则按其具体定义关闭路线。

## 2. S0与S1

S0要求数据/源码/PAIR/时钟/组的定义齐全、已有证据和候选零点可审计。技术未知明确列为`UNRESOLVED_IDENTITY`并只暂停依赖它的工作。

S1确认live参考步、shadow无反馈和关键代数关系。D1/D2可以支持、缩小或否定某项局部解释，**不取消S2四个候选配置**。一个观测值低于测量分辨率时，报告它的区间与量级，不再扩张局部锚点追求显著。

## 3. S2配置选择

所有S2配置完成两数据五seed50epoch后：

1. 每配置先按每seed完整Validation选出online、EMA各自最早最高AUC。
2. 每家族/数据以online五seed均值选择配置。优先满足对B0/B1/H0六格平均ΔAUC≥−.001的配置；没有符合者时仍登记最佳非零配置与损害，不隐藏失败。
3. 两配置Macro差在1e−4内优先较小参数。零点H0同表作为参照，非零不优于零点时记无独立增量。
4. 另检查固定同一配置的EMA增量。家族只要任一数据有安全的online增量，就冻结`selection_readout=online`及逐数据online参数；该家族只派发这一个代表的M/S/P。所有数据都没有安全online增量时，才允许以Validation EMA冻结一个`EMA_DEPENDENT`代表，`selection_readout=fixedEMA`。另行选出的EMA部署行可以报告，但不重复派发第二套控制。
5. 不看Test选择配置，不用E10/E50替代selected，不为重获良好结果更换seed。

### 3.1 进入完整控制阶段的条件

一个家族在至少一个数据、至少一种预注册读出上，相对B1与H0的五seed均值均超过`+1e−4`，且相对B0均值非负，即进入M/S/P控制。1e−4是本轮行动/简化分辨率，非显著性门。

若只有六格trade-off，仍可执行这三个控制定位其来源，但保留`TRADEOFF_CANDIDATE`身份。若上述均值均无增量，完整S2已足以关闭该家族；不再通过随机历史、调ρ、选晚期或按Test反号续命。

两数据的边界分别陈述。一处失败不把另一处已稳定的条件收益归零；一处成功也不替代另一处的真实结果。

## 4. M/S/P后收敛

| 结果 | 接受的判断 | 下一动作 |
| --- | --- | --- |
| C/S优于H0/B1，M接近或超过该代表，差在1e−4内 | 主要增量可由组级更新尺度解释 | 保留尺度解释与完整性能结果，结束该家族扩展；M不自动晋升Cstar |
| S接近或超过C | .99长辅助历史不是新增收益的必要组成 | S自身通过父参照、M/P和六格规则时，以S_C1/S_C2替代C进入Cstar，完整携带βP=.9；否则保留组件并结束扩展 |
| P接近或超过家族代表C/S | 该近邻适配足以覆盖新增表现 | 保留最佳P及全部结果为内部训练组件；结束该家族扩展，P不自动晋升Cstar。P_C1保留.99 Q，不能据此排除长核贡献 |
| C优于M/S/P，或替代S优于M/P，并通过父参照与六格规则 | 具体来源/历史使用关系有完整训练的独立价值 | 依06确定唯一Cstar及读出，再进入满足触发条件的扩展 |
| Macro正、单格低于−.001 | 排序收益伴具体格损害 | 报告条件候选；优先已有较小参数；本轮不增加新权重/自适应模块 |
| 全部控制后仍不胜B0/B1/H0 | 新机制未提供可行动增量 | 结束该定义，保留既有EMA与A21经验事实 |

这里“接近”按五seed配对均值1e−4分辨率描述，同时完整给出区间和逐seed方向；它不等同于已进行严格统计等效性检验。差值区间很宽时结论写为“当前完整矩阵未显示可分辨优势”，不宣称完全等价，也不机械增加seed。

完整增量的行动分辨率统一为均值差>1e−4；“覆盖”指C/S−控制≤1e−4，并报告配对区间。简化次序为：先完整运行S；S相对原C的两数据等权Validation平均差≥−1e−4，且两数据六格安全、至少一数据满足父参照增量门时，冻结S为跨数据统一代表，否则冻结C。随后只运行与该代表βP匹配的M及预定P，再判断覆盖。S在个别数据是否覆盖C分别报告；整体选择不自动证明每个数据都不需要长核。P_C1仍保持其预定.99核，S_C1−P_C1是完整方案比较，单独核效应由C1−S_C1判断。不可通过挑选控制读出逃避覆盖结论。

新增超参数已经以0/.5/1完成搜索。若较小值安全且有效，直接采用；若无安全值，方法记录trade-off并关闭扩展。阶段内不追加未定义的训练权重、Gaussian、EMA时间尺度或单格门控作为修复。

## 5. 条件模块的具体触发

- **C12：** 原始C1和C2在同一个数据、同一冻结读出均通过完整控制和六格规则，且没有S替代时，以各自已选参数做一次组合矩阵；两种家族读出不同或仅S合格时不触发。
- **N范围：** Cstar在至少一个数据对B1/H0及M/P均有>1e−4增量，对B0非负、六格保护通过；原C还须超出S，S代表不再要求超过自身。另一数据也必须满足六格保护，才扩展；用于定位同一算法在共享与专属支持上的作用。
- **HyperGate：** 同一clean Cstar满足上述独立增量/六格保护，进入强骨干迁移；候选无需先达到相对最强模型+.003才获得迁移机会。
- **Gaussian：** clean Cstar已经通过Cstar资格，且在fixedEMA上至少一数据对B1与H0均>1e−4、对B0非负，两数据对B0/B1/H0六格保护通过；GA31-R3原版本身份可用。按06四臂一次执行，均在新Test之前。

Cstar先从合格online代表选择；没有该代表才从EMA_DEPENDENT集合选择，跨家族不混合读出。只在online合格而EMA不增益的Cstar可执行N/HyperGate，Gaussian模块不触发。只在EMA背景合格的方法以组合优化组件继续，不能写成独立online收益。若Cstar=C12，其扩展门中的控制显式绑定`{M_C1,S_C1,P_C1,M_C2,S_C2,P_C2}`，要求同一数据/读出逐项增量>1e−4，并沿用两数据父参照六格保护；不引用不存在的M_C12/P_C12。已有亲本控制与组合完整增量支持晋级，但不构成C12本身的精确范数匹配因果结论。两数据只一处合格时仍用相同方法形式完成条件模块的两数据比较，明确成立范围。

## 6. Test权限与一次全局冻结

历史Test已经暴露。本轮可读取旧冻结数表并用其形成研究问题；新候选的参数、模块、指标与比较集合只从Train/Validation确定。

当前任务只交付规划，`TEST_POLICY.current_task_evaluation_allowed=false`。未来用户明确启动完整实验及冻结后Test评价时，记录授权来源和scope，一次覆盖本轮冻结集合，无需逐模型重复确认。如果未来任务限定Validation，则保存完整Validation报告和冻结清单，Test保持封存。

旧Cycle04/Cycle05的“用户停止后打开Test”规则属于已结束任务，不从其旧存活收据继承新任务权限。若执行环境仍受同一个ACTIVE研究scope约束，则按该scope等待明确研究停止、final freeze和selected RAM验收；不通过新study ID绕开实际访问控制。

`FINAL_FREEZE.json`必须包含：

- 源码提交/内容哈希、算法/数据/预处理/参数组manifest；
- 每个候选的家族、参数、读出、seed、selected epoch和模型哈希；
- 全部主要/辅助比较、发表基线、内部控制及六格保护对象；
- 条件模块的已完成/未触发状态；
- Test类型为`historically_exposed_holdout`、当前授权收据和实际RAM get/hash；
- `adaptive_changes_after_test=false`。

最终新Test集合预先限定为：B0/B1/H0；每家族、每数据在S2冻结的一个代表配置（即使该家族后续关闭，也保留其完整结论）；已触发的S/M/P、C12、N、HyperGate和Gaussian臂；固定发表模型名单。新机制轨迹同时保留online/fixedEMA两个selected读出，纯发表基线使用online。未选中的HPO网格点不新增Test评价，新Test只评价selected，不再做E10/E25/E50探索。关闭家族的Test反号只更新其泛化边界，不重开本轮训练。

打开Test后只完成冻结评估、分析与交付。新Test结果不触发同轮调参、重选算法或增设Gaussian。独立新日期人口或外部数据尚未提供时，直接说明现有Test的历史暴露状态；随机重划同一CSV不构成独立未暴露确认。这不阻止对现有协议形成研究决策。

## 7. 最终方法资格与研究去向

### 7.1 每个数据的强方法门

对该数据最强、人口与选点匹配的已发表M3oE/HyperGate/AutoIFS：五seed平均ΔMacro AUC≥+.003，且每格平均ΔAUC≥−.001。发表模型名单、每个模型的参数和Validation-selected epoch先冻结；正式门对这份固定名单中Test五seed均值最高者计算（不是逐seed取不同模型的最大值），等价于要求对名单内所有模型均达到Macro门。六格保护对该最强模型逐格核对，并完整展示对其余模型的差。固定名单的Test排序只决定报告中的最强参照，不反向改变候选或参数。

对B0、同PAIR B1、原H0以及相应读出的强内部参照，分别报告独立增量和逐格保护。Gaussian作为最终组成时，同时面对同Gaussian/同PAIR/同EMA的控制；不能把EMA贡献全部计为新历史贡献。LogLoss、Traffic和Pooled独立裁定，不覆盖Macro AUC结果。

### 7.2 研究决策标签

| 标签 | 意义 |
| --- | --- |
| METHOD_READY | 在目标数据达到强方法门，具有匹配控制之外的完整增量；跨数据都达标时标cross-dataset |
| CONDITIONAL_METHOD | 一个数据形成清晰方法收益，另一个边界明确；方法研究可继续，论文表述限定条件 |
| EMA_DEPENDENT_COMPONENT | online缺少独立收益，固定EMA背景有新增收益 |
| GENERAL_OPTIMIZER_COMPONENT | 近邻通用优化适配覆盖主要收益，保留为MDMT强训练组件 |
| AUXILIARY_ONLY | 稳定局部/辅助指标收益，但未形成本文主AUC方法贡献 |
| NO_ACTIONABLE_INCREMENT | 核心候选及触发控制完成后未超过强内部参照 |

MDMT问题导向来自正常共享训练中的真实多来源信号与六格收益/损害关系，不要求证明单任务绝无收益。只有共享参数受益这一事实，尚不足以单独说明MDMT专有机制；本轮用源条件、真实函数干预、范围和骨干证据把解释推进到可行动程度。

两个候选均关闭时，下一机会优先考虑“训练标签支持的历史正确排序关系是否被后续共享更新覆盖，以及同pair同曝光的关系保留是否有增量”。该方向改变历史信息对象，与已测全输出KD不同，后续需另行定义缓冲/支持/匹配控制；本轮不自动扩展其训练。
