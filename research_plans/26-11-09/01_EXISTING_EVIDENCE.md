# 01｜已有证据审计与结论继承

## 1. 直接接受的经验结论

### 1.1 固定 EMA 有效，但收益包含阶段取舍

11/07报告在同一 online 训练轨迹上比较 F 与 online，五seed selected Test Macro AUC净益：

| 数据集/训练目标 | F−online ΔMacro AUC | 配对SD | 正向seed | ΔLogLoss（正值为代价） |
|---|---:|---:|---:|---:|
| MovieLens Clean | +0.003848845 | 0.000374396 | 5/5 | +0.001248644 |
| MovieLens Gaussian D0 | +0.003856802 | 0.000645238 | 5/5 | +0.005334282 |
| KuaiRand Clean | +0.004616399 | 0.003048773 | 4/5 | −0.001225342 |
| KuaiRand Gaussian D0 | +0.007766927 | 0.004257500 | 5/5 | +0.000327687 |

晚期 epoch 31–50 的 F 相对理论平均年龄匹配旧 online，四组 Validation AUC差均为正；因此“EMA收益全部只是 checkpoint 延迟”不成立。早期 F 相对 online 有明显负收益，说明历史平均会延迟吸收持续有益变化。排序稳定与学习滞后共同影响效用；频率衰减本身不含标签，不能判断被抑制变化的正负价值。

### 1.2 收益异质性存在，但不自动导出任务专属 EMA

11/07六格 selected Test 的 F−online AUC均值在两数据集、两训练目标的六格均为正，但幅度不同。参数路径和任务条件也存在差异。其含义是“共享参数的历史读出收益并非均匀”，不是“每个任务必须独立维护一套共享参数”或“参数组收益可以相加”。

共享参数 S 同时进入多个域任务的前向计算。任务对 S 的历史吸收偏好可能不同，是 B/C 需要检验的依据；是否值得复制状态，必须由跨面板可预测性和完整模型收益决定。

### 1.3 指标比较给出的边界

11/07对 M0几何、M1预测函数幅度、M2有符号排序风险、M3直接反事实收益及 C_design/C_simple简单参照进行了比较：

- M2_full 对同刻训练排序风险变化的相关约为 0.9975–0.9991；但与独立 V_mech AUC 的相关明显下降。
- M3_direct 的 P_A/P_B跨面板相关约 0.44–0.72，动作一致率约 0.50–0.57；不能预设其可直接作为在线控制信号。
- M1函数幅度跨面板稳定，但没有方向，不能单独决定 Fast/Slow。
- C_design 在四个数据×目标条件的未来收益 MAE 均优于 M2/M3；复杂指标的独立动作价值有限。
- KuaiRand Gaussian、d0t1、S 的 M3_direct−C_simple额外收益约 +0.000048355，五seed离散度较大。该局部结果保留为低优先级，不累计嵌套scope为独立重复。

现有结果主要回答“指标当前如何描述收益、能否预测 e+5 pulse”。它没有直接完成“相邻窗口收益是否持续、持续性是否足以驱动闭环控制”的审计。这正是 A0 的新增问题。

### 1.4 11/05增强/历史控制不得重做

11/05 A/B/C已执行五seed。增强响应定向 EMA 的 D−F selected Test Macro AUC：ML约 +0.000000104、KR约 −0.000004946；实际路径分组/全局控制未建立稳定selected增量；历史漂移条件增强在 ML 多配置下未胜 F，KR C 未运行。不得将这些结论包装成“尚未验证的同类控制器”再重跑。

## 2. 训练协议身份

从 11/06规划与11/07报告继承：

- M3oE fixed1，embedding 16，FCN [512,256,256,64]，4 shared experts。
- FULLTRAIN_NATURAL80_10_10；train-only预处理；KuaiRand先划分再筛tab0/1/4；原始训练人口和行序不变。
- batch 40960；50 epoch；coupled Adam lr=.01、betas=(.9,.999)、eps=1e-8；ML wd=1e-4，KR wd=1e-5；FP32，AMP/TF32/clipping关闭。
- seeds 2022–2026是机制开发历史seed，不得再称作 A1 独立确认seed。
- A1建议新seed 2027–2031；每条在线轨迹50 epoch。A1只优先 KR Clean/Gaussian D0。C阶段再扩展 ML。
- 固定 EMA的 rho_F 依数据集继承：ML 0.9828205985452511（约2 epoch半衰期），KR 0.995（约2.8221 epoch半衰期）。Fast=rho_F²，Slow=sqrt(rho_F)。不能误用早期讨论中的 rho=.9，也不重新大规模搜索半衰期。

## 3. 数据、面板与统计身份

- P_A/P_B 是固定、互不重叠的训练行观测面板；不改变 loader、采样分布或真实训练人口。
- V_A/V_B 是验证集的固定行侧，作为信号迁移审计和最终 checkpoint 选择，不是独立 Test。
- 每个 seed 是唯一独立统计单位。epoch、cell、parameter group、pulse window、panel和scope均为重复测量/嵌套观测，不能虚增 n。
- 11/07 ACTION_DECISIONS.csv 多个scope存在嵌套，不能累计成独立证据。
- 正式 Test只在配置冻结后执行；已有Test仅作为历史证据，不是未来新实验的盲测。

## 4. 结论层级

| 层级 | 当前状态 | 可接受表述 |
|---|---|---|
| 固定 EMA排序收益 | 已成立 | 同轨迹、指定协议、五seed配对收益 |
| 阶段性滞后代价 | 已成立 | 早期滞后、晚期净收益 |
| 参数/任务收益异质性 | 已观察 | 分布存在差异 |
| 直接收益指标跨面板迁移 | 有限 | M3稳定性弱于简单参照 |
| e+5未来数值预测 | 已有结果 | C_design误差更低 |
| 相邻窗口收益持续性 | 待A0离线审计 | 不能由当前相关/MAE直接替代 |
| 闭环自适应 EMA超过F | 未测试 | 只能由B/C阶段验证 |

## 5. 研究决策

不再扩张 M0–M3 指标家族；A0优先使用已有 pulse metrics 与 PREDICTIVE_OOF/seed级表，重算时间持续性、跨面板一致性及未来窗口净益。若原始产物缺失或身份无法核验，应报告不可重算的具体字段，不得以报告摘要填充逐窗口数值。只在持续性或稳定静态任务偏好有依据时进入新增训练。
