## P8-AT: original task-state mechanism

Implement the published AdaTask-Adam update (Alg2/eq7) and verify numerical equivalence to the downloaded official `Adam_with_AdaTask` at its pinned commit. Keep existing M3OE prediction function, fixed fusion, Sample alpha, IID q, seed/split/batch/50epochs/selection identical. Two task losses each carry1/2, so their raw gradients sum to the existing Sample gradient. Shared-for-task parameters are all parameters except task/domain gates and towers (slots are shared between the two tasks). Gate/tower private parameters use ordinary Adam on total gradient. Task-specific moments and bias corrections for shared parameters, sum the two updates. This is one optimizer object, not two optimizer steps over live different theta.

Preserve total L2 objective: base Adam coupled WD=1e-5 is equivalent to gradient of wd/2||theta||²; allocate half this regularizer to each task gradient. The official code accepts weight_decay but does not apply it; this adaptation must be explicit. Validate shared updates against official step fed the same regularized gradients, and private updates against torch.Adam. Shared m/v state and gradient vectors must be evaluated at one theta before any update. Do not silently average updates to improve performance. Baseline lr=.01, no new tuning. Four seeds×SN/SB=8runs. Failed/nonfinite runs retained and investigated; null under an inadequate optimization regime is not full empirical noncoverage of AdaTask.

## P8-W: objective-change vs objective-equivalence

At the P6 finite pool, use deterministic, positive nonconstant feature-complexity weights from frozen initial embeddings: normalized attention entropy (fixed identity Q=K, standard positive entropy, std population), w=.1+.5*clip((entropy−mean)/(2std)+.5,.1,1). This is a **D3-inspired complexity weighting control**, not faithful full D3 (no DSFS/fusion-specificity module) or SAF (no HSIC/RFF). Add specificity only if a faithful gate exists; the fixed M3OE scalar is not a per-sample specificity estimator.

Compare exactly on the same theta and rows: J0 original loss; JW weighted loss; JW-normalized divide weights by pool-average; JC weight multiplied by its exact reciprocal, constants detached. Report expected scalar objective, projected and full gradient differences, and same-alpha natural/balanced estimator means. Normalization generally changes the objective despite removing absolute scale; inverse cancellation restores the original value/gradient. This experimentally tests the objective-equivalence claim without pretending that a surrogate is a full method performance reproduction. Report faithful D3/SAF performance gap-removal as UNIDENTIFIED if executable faithful mapping is unavailable; do not label them ineffective.
