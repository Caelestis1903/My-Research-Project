# DESIGN SUPPLEMENT — P2-A matched-theta state readout

Primary, before results; execute only if P1 operational A or as explicitly labeled ambiguous diagnostic, never as proof of necessity when SGD calibration/performance is inadequate.

Use P6 stored projected microbatch gradient pools at the SAME initial / SN-selected / SN-final theta. For selected/final, bind original SN optimizer moments to parameter names and project the identical coordinates; initial moments zero. No SB trajectory optimizer state is loaded at another theta. All shadow histories start from that one legitimate state and advance on frozen-theta gradients without updating model parameters. This is a local frozen-theta diagnostic; not counterfactual full-training performance.

For each partition and snapshot,64 independent paired shadow replicates,128past gradient draws from the exact finite pool, independent current draw. One draw is one32-row single-domain microbatch with q(domain) and uniform over8pool microbatches, importance alpha/q. This is a diagnostic estimator whose objective matches the finite pool; it is **not** asserted to equal the production40960-row IID batch distribution. Include coupled L2 wd*theta in each projected gradient. Shared random uniforms couple N/B domain and microbatch choices. Adam betas/eps/lr and true state step counters match source checkpoint; bias correction advances128+1steps.

Five readouts at same theta: A raw current-gradient SGD update; B common first moment (mean of the paired shadow m) with respective v; C common v with respective m; D common full prior state then each current gradient; E respective complete shadow histories then each current gradient. Shared quantities are defined before the current draw and remain identical within the pair. Report mean paired update vector, norm of difference of expected updates, mean/median paired update distance, and ratios to E. Preserve per-replicate arrays. Also report analytic exact equality of current expected finite-pool gradients; Monte Carlo sampling error cannot be mistaken for unequal population objective.

Interpretation: B attenuation suggests a first-moment local mediator; C attenuation a second-moment local mediator; D residual shows current gradient nonlinearity remains; multiple effects can coexist. Finite projection/pool/MC, common-state choice and frozen-theta histories limit extrapolation. None of these controls blocks a mediator in an actual final-AUC trajectory, so P9 performance causality remains unestablished unless an additional preregistered performance intervention is actually run. This cannot be relabeled a causal mechanism merely because a local mean update differs.

Verification: same state/hash/coordinate mapping, initial m/v zero, moments nonnegative, update equations against direct torch.Adam on arbitrary projected vectors with nonzero prior state, no optimizer/model step applied to original loaded state, repeat reproducibility. Save raw readouts and source hashes. Primary self-review before RUN.

## Pre-execution component definition clarification

B/C block the realized m/v component at the final one-step readout: use the paired mean of post-current m (B) or v (C) identically in N/B; the other component retains its own update. D shares prior m/v only and allows each current gradient to update both. This distinguishes full component blocking from sharing only history. All are same-theta shadow operations, not live optimizer-state transplants or final-AUC interventions.
