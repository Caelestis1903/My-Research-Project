# 2026-10-18｜六方向研究启动提示词（Codex / 科研执行代理）

请基于本仓库 `research_plans/2026-10-18/MDMT_FRONTIER_RESEARCH_REPORT.md` 和 `README.md` 开始系统性 MDMT 科研探索。目标面向推荐系统及机器学习顶会顶刊：**六个方向 P1–P6 必须全部完成实质性研究尝试，逐项判断是否能改善合理指标、揭示真实问题、提出新理论/算法，或应被否定。** 不能因为报告排序低、没有现成阳性证据或某方向需要不同数据，就未经尝试直接跳过；也不能为了保留六个方向而制造提升。

**执行程序：**

1. 先读取 main 的历史证据账本与相关执行分支，确认各方向所需的已有代码、模型、数据、checkpoint、论文原文能否取得。优先使用现有产物；缺失才补充必要测量。不重复已关闭的历史命题，不把未执行的分支写成阴性结果。
2. 为 **P1–P6 各建立独立研究记录**：明确被质疑的论文假设、最直接的已有方法、MDMT 独特科学问题、一个可证伪假设、一个候选机制或方法构想，以及它必须优于的最强简单基线。
3. 对每个方向都要做真正的最小研究尝试：先完成定理/反例、现有数据重分析或冻结 checkpoint 诊断；若有可测试的方法且需要训练，至少安排一次小型、配对且与强基线可比的 pilot，明确 A/B 两种可能结果如何改变继续/停止决策。已经由严格理论反例、同构文献或不可满足的数据条件证明路线无价值时，可以以有证据的 NO-GO 完成该方向，不能为了凑运行次数浪费 GPU。
4. 六方向的具体检验焦点：**P1** 稳定约束在保留任务信息和有限支持下的可行边界；**P2** 跨 cell 逻辑/测量/桥接是否比 ExtraDebias、WCP-DR 等增加识别信息；**P3** 在真实硬部署预算和 cell 非劣约束下的最小可行共享容量；**P4** 相对 full-`DT` 交互测量的决策与计算收益；**P5** 代理不唯一是否真正导致错误共享决策，不能只证明 gate 数字变化；**P6** 与 IS/MIS/EMAIS 强基线比较后是否仍有有效的方向风险与执行成本优势。
5. 实验只检验会改变研究决定的核心差别；对于每次新增训练写清 **它区别什么、结果 A 做什么、结果 B 做什么**。先做单组低成本 pilot；只有出现实际效应、可复核的理论贡献或必须确认的关键结果，再扩展到少量配对种子和必要强基线。不得默认做全因素网格、无止境增加种子/Epoch、重跑已经充分检查的旧实验、完整分解所有可能中介、重复烟雾测试或无关的工程防御性测试。只修会损害算法结论的错误。
6. 评价不只看平均 AUC：在存在相应标签时报告 cell AUC/LogLoss、macro 与部署权重、selected checkpoint、关键保护约束、参数/计算成本；若方向核心是识别性、可行性下界或测量效率，应优先报告对应的严格判据而非勉强追求 AUC。不要事后按 test 选择方法或阈值；保证关键 baseline 容量、数据范围与预算可比。
7. 每个方向必须给出 **GO / CONDITIONAL / NO-GO / DATA-BLOCKED** 的结论和对应证据：有哪些有效尝试、提升多少或为什么没有意义、是否已有论文覆盖、可能形成何种顶会贡献、下一项最小必要动作是什么。DATA-BLOCKED 不能伪称算法无效，且须给出最小缺失数据条件。P1–P6 全部完成一轮判定后，再综合选择可以深化的方法；不允许只完成前三名就宣告任务结束。
8. 所有探索在新的执行分支上开展，不改动或覆盖历史实验。将各方向 `analysis.md`、最小实验配置、关键原始指标/图表、代码（若有）和最终汇总保存到 `research_plans/2026-10-18/execution/` 或清晰引用的实验目录。最终报告必须包含六方向对照表、所有阴性/冲突结果、被覆盖的伪创新、确有价值的机制，以及下一步研究建议。提交并推送研究分支，准备合并到 main 的 PR；不得捏造未执行训练或没有拿到的原始数据。

**执行原则：探索必须充分，验证必须有决策价值。先证问题，再做最简方法，最后做必要确认。不要为了防御性完整性拖延科研，也不要因为没有性能提升而隐瞒重要的理论或边界结果。**
