# P2 首轮判定：DATA-BLOCKED；当前简单方法 NO-GO

已执行同观测世界反例、ML 完整标签的受控 MAR/MNAR 删标签、精确逻辑
边界、同信息普通 LP 及每次最多 128 条的随机/分层审计。四个种子是掩码
和审计随机种子，固定 ML 人口；24 条域×机制记录不等于 24 个独立人口。

| 读数（四种子、三域平均） | MAR | MNAR |
|---|---:|---:|
| Oracle task1 正率 | .230604 | .230604 |
| 只看观察标签的正率 | .230069 | .505677 |
| 无逻辑区间宽度 | .597768 | .683149 |
| 加嵌套逻辑后的宽度 | .345574 | .346469 |
| 固定 .7 对 .3 风险差可判符号的记录 | 0→12/12 | 0→7/12 |
| 随机审计平均 SE | .022200 | .018096 |
| 逻辑分层、同标签预算平均 SE | .014418 | .011838 |

24/24 oracle 正率落在逻辑包络内，同信息普通 LP 的上界与候选完全一致。
逻辑确实增加信息，也减少标签浪费；这不是“只是额外多拿标签”。但它
来自已知单记录任务嵌套和经典分层/约束融合，不证明新的跨域任务识别。
MAR 若利用正确的观察机制，标准 IPW 已足够，派生读数单列于
[`P2_information_summary.csv`](../readouts/P2_information_summary.csv)。

**STRONG**：同观测世界不能唯一识别、已声明逻辑的严格缩界及 LP 等价。
**MEDIUM**：当前固定 ML 人口上的受控遮蔽和审计 SE。**WEAK**：自然业务
缺失/噪声机制中的收益与跨域可推广性。schema 没有自然 O_t、clean 审计
或可用的跨域测量桥；ML 两任务只是同一 rating 的嵌套阈值。不能把人造
MNAR 当作已获得真实 post-click 场景。

对 ExtraDebias/WCP-DR/HiDe-ESMM/Feasible Fusion 的比较在信息和假设层面，
没有忠实神经训练胜负。AEM²TL 全文仍有缺口。故不运行缺真实条件的 GPU
补全网络；新方法 AUC/LogLoss 未测。问题保留，当前简单候选被排重。

下一项最有辨识度的工作是取得真实观察掩码、一个可审计跨 cell 测量关系
和相同标注预算，证明它严格缩小**同信息一般融合**仍不能缩小的决策集。
若只是本轮的逻辑分层，直接停止独立算法立项。
