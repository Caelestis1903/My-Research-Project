# MDMT 推荐系统前沿创新研究报告

基于 My Research Project 的证据审查 文献批判与研究决策

检索与仓库核查截至 2026 年 10 月 18 日

## 研究判断与阅读说明

建议优先投入三个问题：有限支持下的域任务条件稳定性、不完整域任务观测的可识别迁移，以及受参数预算约束的共享收益可行性。它们分别追问分布变换是否可行、迁移结论是否可识别、合格预测解是否存在于模型类中。三者有不同的科学对象，均应先通过理论与小规模现有数据分析，再决定是否训练。

目前不能把任何候选写成已经成立的新算法。广泛检索后的重要结果，是排除了若干看似自然的创新包装：实际更新平衡已有 PUB；多目标验证效用已有 VAO；源领域混合与目标任务鲁棒改善已有 GRAPE；超额风险已有 ExcessMTL；单任务回退安全已有 DSMTL；四类域任务信息流与 LoRA 选择已有 AutoIFS；选择性去相关和有效样本量损失已有 DVD。新的论文需要说明这些方法为什么仍不足，以及所需新增信息、可行条件或计算结构到底是什么。

本报告提出六个正式候选，并额外筛查三个储备问题。候选间允许共享技术工具，但不把同一科学贡献的不同模块计算成不同创新。对于覆盖过强的候选，明确降级为理论审计或停止独立开发。研究优先级与低成本检查顺序分开：一个代数反例很便宜，并不意味着相应方法最值得投入 GPU。

全文使用四种证据标记：**P** 为论文明确陈述、公式或论文报告的结果；**D** 为本次根据公式得到的推导或反例；**R** 为核对代码、配置或原始指标后的仓库证据；**H** 为尚待检验的研究假设。充分条件不满足，不等于算法必然失败；代理解释不唯一，不等于预测效果差。

本轮通过 GitHub 连接进行只读审查，没有修改项目、提交分支或运行新的 GPU 训练。做了历史指标复算与少量 CPU 线性代数核验。完整二进制预测、模型权重和原始数据盘不在已读取的 GitHub 文件中，因此指标复算不能称为从预测文件重新计算全部 AUC。参考文献在附录给出完整标题、年份、venue、原文链接及阅读深度；未取得全文的工作不被用来推断其具体定理。

# 第一部分 已有研究证据总结

## 1 冻结版本与研究对象

main 的冻结提交为 98247ebf1acaf6f9cfbb823441391c1c83bbfb05；最新执行分支 codex/execute-2026-10-17-run 为 5550afbc57f76e0b94c5783db16f4c1796933541。main 已包含 10 月 18 日综合报告，但没有把所有历史执行分支的代码与原始产物完整合并。故关键结论回到相应执行提交核查，不能只读主分支摘要。\[R1–R3\]

同时检查了 10 月 15 日规划、10 月 16 日 v2/v3 规划与执行记录、10 月 17 日分析和问题登记。v3 与 v2 存在谱系分叉，N17 继承 v3；较早的中途阻塞记录不能覆盖后来的完成记录。历史报告中的重复结果也不能当成独立证据。\[R1,R14\]

两个核心问题必须分开。早期 Equal 实验改变目标和历史来源；N17 固定 Sample 目标，只改变采样分布。设训练领域份额为 p，任务数为 T，N17 的数据目标是：

$$J(\theta) = \sum_{d}^{}p_{d}\,\mathbb{E}_{i \mid d}\left\lbrack \frac{1}{T}\sum_{t}^{}\ell_{dt}(\theta;i) \right\rbrack.$$

自然采样 SN 取 q=p；平衡采样 SB 取 q_d=1/D，并使用 p_d/q_d 修正。quota 实现按每批实际域计数修正：每域均值乘 p_d。固定参数和同一计算图下，它们的平均数据导数字段相同；协方差、有限步轨迹和选择后的测试风险可以不同。这是重要性采样的基本性质，不是新的 MDMT 发现。\[R6,R7; L31,L32\]

代码还有三个影响科学解释的区别。第一，早期原始 M3oE 含可学习融合权重和双优化器；v2/N17 将四组融合权重冻结为 sigmoid(1)，约 0.7310586，并使用一个优化器。不能把两类轨迹合成同一算法的重复结果。第二，旧三域两任务 Equal 实现是六个组均值 BCE 的求和；它与普通 Sample 均值的尺度也不同。第三，路由输入保留 embedding.detach()：自动微分中的停止梯度不等于重新运行前向函数时路由数值永远不变。需要区分实际训练导数字段与完整预测 Jacobian。\[R6,R16,R17\]

所谓 domain expert、task expert 也不自动等于私有参数。M3oE 的域与任务专家会跨域、跨任务融合；参数的实际支持关系应由前向和反向依赖决定。仓库中 V1 是 DBO-inspired 损失权重方案，权重未 detach 时包含 loss 乘权重导数项；它不是严格 D3 复现。V2 的幅度对齐也不包含 GradCraft 的完整方向投影。因此不能用它们的失败宣称原论文失败。\[L4,L9,L23; R14\]

## 2 真正保留下来的历史发现

**R 已确认的条件性负迁移。** 在原自然比例 Sample 协议中，S1 的 72 项与 S2 的 24 项比较没有达到预定实用负迁移门；这不能外推为 MDMT 普遍无负迁移。KR Equal 的大域目标则有约 0.039 AUC 的 target-only shared 救援，四个种子同向。这个反例已足以说明困难度不能由领域样本数排序，而“小域不必困难”本身是研究前提，不再作为创新。\[R1\]

**R 历史来源具有窄范围机制价值。** S4 中简单梯度范数或更新范数匹配未复制救援。S5 在 KR Equal 的特定目标与状态下，持久历史来源移植保留约 96%–99% 的救援，而仅当前来源约 0.001。它支持“整段历史是该局部机制的载体”；没有唯一识别 m、v 或 step，也不证明所有采样效应都需要 Adam。\[R1,R20\]

**R Adam 普遍必要性已经被反例关闭。** v2 有无动量 SGD 采样效应，v3 的 calibrated SGD 也有阶段与 selected 指标不同号的结果。旧 Equal 的 Adam-history 现象与固定 Sample 的 q 干预可以同时成立。继续比较更多优化器以确认“不是只有 Adam”没有选题价值。\[R13,R14\]

**R 局部代理改善不足以支持方法。** S7 改变了 utility，却没有稳定性能收益；S7B 的指定 anchor 不是四个种子都恶化，而是三负一正。S8 的 ML 延长训练没有超过冻结的原最佳模型。后期救援、训练代理改善或单个层的几何变化，均不能替代可选择模型上的方法收益。\[R1,R21\]

**R 旧报告中的表面冲突需要协议解释。** 例如旧 S6R2 与 10 月 15 日重建版本的非目标收益不同，涉及代码与实验谱系差异；不能仅看同名指标判定不可重复。v3 的 batch2SGD 指 batch size 乘二，不是第二批独立训练种子。这些纠偏直接影响样本量和证据强度。\[R1,R13,R14\]

## 3 N17 的正式端点与可信边界

核查了 120 条新的 100-epoch 唯一训练轨迹的账本。其中 72 条正式轨迹具有完整 test 读数，合计 7,200 个 epoch 检查点和 43,200 条域任务指标行。依据实际 validation trajectory 重新选择全部 72 个端点，与冻结账本一致；再按种子重算关键 AUC、AULC、权重人口指标与配对区间。\[R2–R5\]

下表均为 SB−SN 的六 cell 宏 AUC。每组有八个训练种子，selected 使用每臂自己的 validation 选点。

| **比较**            | **selected 差值** | **配对 t 的 95% 区间**   | **严格解释**                 |
|---------------------|-------------------|--------------------------|------------------------------|
| KR Adam 同 LR 0.01  | −0.005203         | \[−0.012006, +0.001600\] | 7/8 负；主比较未确认         |
| KR SGD 同 LR 1.0    | +0.000837         | \[−0.004309, +0.005984\] | 5/8 正；未确认，也未证明等效 |
| KR quota Adam 0.01  | −0.009191         | \[−0.015795, −0.002588\] | 次级点对点比较               |
| ML Adam 同 LR 0.001 | −0.010392         | \[−0.014599, −0.006185\] | 8/8 负，限该协议             |
| ML Adam 各臂选 LR   | −0.010875         | \[−0.014447, −0.007303\] | SN 0.001，SB 0.0003          |

KR 两项主要检验经 Holm 校正的 p 值分别为 0.171875 和 0.6953125。因此不能把第一行写成“平衡采样普遍伤害 Adam”，也不能把第二行写成“SGD 完全没有采样效应”。quota 与 ML、固定 epoch 和 cell 读数不能事后替换主要检验族。\[R2,R5\]

阶段信息仍有研究价值：KR Adam 的前 20 epoch AULC 差为 −0.007480，八个种子均负；selected 宏 LogLoss 恶化约 +0.007457，八个种子均正。它们说明问题不只在训练末期，但不证明同一机制支配所有阶段。\[R2\]

ML 各臂选 LR 的 E100 差为 +0.021145，八个种子均正，与 selected 差 −0.010875 相反。这里同时改变了学习率、训练阶段和模型选择对象，不能升格为“SB 改善最佳泛化”。E100 六个 cell 的点均值均正，但小域两个任务的同时非劣界没有过门；这表示保护证据不足，不表示其点均值实际受损。\[R2,R5\]

账本中的 120 条训练已去重，但它们跨不同实验条件，不能作为同一命题的 120 个独立重复；共同 LR 与各臂 LR 比较还可复用同一训练结果。MC draws、epoch 和 cell 行不是新增训练种子。八个种子反映固定人口和子集上的优化随机性；ML 的 population_seed=2022，不是八次重新抽样人口。测试集已被历史研究反复使用，不能将本轮复算当作从未使用过的最终确认集。现有证据足以筛选方向，下一项新方法的最终评价需要独立冻结协议，而无需立即为此重训所有历史基线。\[R2,R3,R12\]

## 4 方差与共享 C 的已关闭解释

N2 的 16 个固定点覆盖四个开发种子、SN/SB 原生路径和 E10/E40。全参数 trace 的 SB/SN 比值在 IID 下为 2.0089–2.5841，quota 下为 1.9947–2.5509。域计数随机项仅占 IID 预测分解总 trace 的 0.001297%–0.105936%；这里的分母不是直接经验 trace。该比例由 raw_moments 与 trace_contrasts 复算得到。\[R8\]

**R 在这些锚点，域计数随机性不是 trace 差的主要来源。** 这不意味着数据规模没有影响，也不证明 trace 决定泛化。quota 还改变批内依赖和高阶统计；其长期 q 交互区间跨零，不能称作纯方差开关。Adam 瞬时均值漂移的原检验仍未识别，不自动成为下一轮任务。\[R2,R8\]

N3 在冻结 embedding/E10 候选后使用四个独立确认种子。SN full 的局部 AUC 均值约 0.00003252；SB full 约 0.00002817；方向残差约 0.000014。MC 精度已达到原要求，但未达到 0.0001 的实用门。**N4 长期 tied/untied 拓扑试验未触发，也未执行。** 不能说“长期共享无作用”；同样不能以局部约三万分之一的改善批准长期结构开发。\[R9\]

这些结果支持停止把旧 C 中介归因当默认路线。新共享研究如有独立的容量或可识别性问题，可以重新立题，但不能把 N4 未运行写成新结构已得到支持。

## 5 评价人口与数据语义的研究价值

同一组预测可以因评价人口不同而反号。v3 calibrated Adam 的 E50：宏 cell AUC 差为 −0.0090743，训练份额加权为 +0.0010156，测试份额加权为 +0.0031080。宏与测试份额插值的差为：

$$\Delta(\alpha) = - 0.0090743 + 0.0121823\alpha.$$

约在 alpha=0.7449 时变号。这是已有逐 cell 指标的算术重组，不需要新训练，也不是新算法。上述三个量均是加权 cell AUC，不是包含跨域正负样本对的 pooled AUC。\[R10,R13\]

KR 的主域训练份额约 86.93%，测试份额约 98.21%；主域点击正率约从 0.3778 变为 0.2105，long-view 正率约从 0.2561 变为 0.1113。实际 split_rule 是 global_row_order_80_10_10_then_filter。可以确认观测人口和标签率不同，不能未经时间戳与预处理核查就宣称严格时间漂移或曝光偏差的因果机制。\[R11\]

ML 的任务是同一 rating 的两个嵌套阈值：rating\>3 与 rating\>4；领域是年龄分组，训练子集份额为 0.184、0.016、0.8。它适合研究有明确标签关系的受控问题，不足以代表自由异构业务任务。KR 当前处理后的特征也未含 user_id，不能默认可以做用户独立 bootstrap 或同一用户跨域反事实对照。\[R11,R12,R18\]

当前仓库没有真实不完整域任务观测图、自然 MNAR 标签、域特异任务测量规则或部署策略反馈的直接实验。这些方向可以比历史优化问题更重要，但其证据等级必须是 H，首先过数据可用性门槛。

## 6 不再自动追加的实验

已关闭或无需重开的命题包括：小域天然困难；Adam 是采样效应普遍必要条件；平衡采样必降噪并改善小域；相同期望梯度应有相同训练轨迹；后期反号代表最佳泛化改善；局部 C 微弱阳性足以支持长期方法；AdaTask 没消除 q-gap 就代表原算法无效。

仍未知但不自动安排实验的内容包括：旧 Equal 的 m/v 唯一必要性，Sample 下覆盖、重复、顺序与协方差谱的完整中介分解，长期共享 C 的必要性，自然困难度的完整因果成因。这些未知不妨碍提出新的、边界明确的研究问题。

# 第二部分 系统性文献批判

## 1 检索范围与判断标准

重点检索 2023–2026 年，回溯 MMoE、PLE、STAR、重要性采样、稳定学习和多目标优化的必要经典工作。来源优先正式会议或期刊页面、作者全文、arXiv 和作者代码；标题命中不能替代方法阅读。正式 venue 与预印本分开：例如 GradCraft 为 KDD 2024，PUB 为 ICDM 2024，SAF 为 AAAI 2026，AutoIFS 为 WSDM 2026，HyperGate 属 WWW Companion 2025。EMS 是指标名称，对应 EMAIS 论文；MIS/OMIS 的直接来源是 ICPRAM 2025，并非推荐顶会论文。\[L9–L11,L22–L24,L31,L32,L48\]

判断 MDMT 特有性使用一个严格对照：把每个 c=(d,t) 平铺为普通 MTL 任务。如果已有方法在同等信息与预算下即可解决全部问题，那么加上域任务索引不是实质创新。真正可能不同的是双轴条件交互、共享参数的交叉支持、同一记录携带多个标签的观测与成本关系，以及不完整网格的可识别性。

## 2 架构和路由论文解决了什么

**MMoE、PLE、STAR 与 M3oE。** MMoE 为任务设置不同 gate，共享专家；PLE 逐层组织共享和任务专有专家；STAR 用共享与域专有参数及归一化处理 MDR；M3oE 进一步组织共享、领域、任务三类专家及融合。\[L1–L4\] 这些架构编码共享偏好，没有据此证明专家语义唯一、所有 cell 不受损，或者任意任务关系都可辨识。它们也不是简单的行列加性模型，不能通过一个四格反例就宣布它们无法表示域任务交互。

**AESM²、M2M 与 PEPNet。** AESM² 已研究多场景多任务的自动专家选择，并报告局部 seesaw；M2M 已指出领域关系随任务变化；PEPNet 对表示与参数进行个性化。\[L5–L7\] 因此“域关系依任务而变”“加个性化 gate”“MDMT 有 seesaw”均不是尚未提出的问题。

**AutoIFS。** P：四类场景/任务信息流、LoRA 参数化、按实例和任务选择信息流并重训。需要注意其 mask=1 表示移除，L1 用于限制过度移除，不能反写正则作用。D：优化整体 BCE 和选择掩码，不等于对每个 cell 的可实现收益集合给出证书；但它能表示交互，不能把论文简化为只会边际共享。R：仓库没有忠实 AutoIFS 比较。H：若研究预算与收益可行性，应将它作为强压缩结构基线，而不是重复四类专家。\[L11\]

**STEM、DRGrad、ConsMTL 与 Selective Task Group Updates。** STEM 已区分前向读取与反向更新所有权；DRGrad 已做个性化梯度路由；ConsMTL 和组更新工作已考虑私有头对共享优化关系的影响。D：MDMT 中交叉共享仍可能产生更复杂的支持约束，但“停止梯度”“调 head 再看冲突”本身被充分覆盖。R：仓库的 detach 使这一近邻尤其必要。不能仅把原方法复制到领域轴。\[L8,L39,L40,L60\]

**SDSP 与 AREAD。** SDSP 已研究非对称、依 backbone 变化的域选择。它的理论使用某一共同表示能够由每个被选源分别恢复的条件；该条件不等价于任意多个互补源的联合编码。AREAD 在几十个域上做层级专家选择，并利用冷门物品正反馈增强小域。两者已覆盖“不是所有源都帮助目标”与“部分共享”。单纯有向关联图没有足够新意。\[L12,L13\]

## 3 D3 的特异性代理存在怎样的精确边界

P：D3 的 Eq12–13 定义两个 softmax 标量，并作如下融合；Eq18 再使用其中一个构造 specificity 权重：\[L9\]

$$\left( g_{sp},g_{sh} \right) = softmax\left( h(x) \right),\quad\quad W = \left( g_{sp}W_{spec} \right) \odot \left( g_{sh}W_{glob} \right).$$

$$w^{spf} = \lambda_{2} + \alpha_{2}g_{sp}.$$
D：交换两个 gate 输出，乘积 g_sp g_sh 不变，故 W 不变；specificity 权重却一般变化。正文称 bias 按相同方式生成，在这一出版构造下可同步保持完整前向不变。这说明该代理不能仅由当前预测函数唯一确定。

这一推导不需要宣称 D3 预测失败。加权目标主动打破对称性可能构成有效归纳偏置；当前预测等价也不意味着 SGD 或 Adam 后续轨迹等价。作者实现未取得，故这是出版数学机制的解释边界，不能写成已发现官方代码错误。仓库 V1 不是忠实 D3，无法补足这个实证缺口。

更重要的创新风险来自 L2RW、SLGrad、VAO、GRAPE、自然梯度和 NTKMTL：把 gate 换成验证梯度或 Fisher 内积已有大量先例。D3 反例值得进入理论审计，尚不足单独支撑一个 MDMT 方法主线。\[L28,L34–L36,L44,L45\]

## 4 SAF 的稳定性证书需要哪些额外条件

P：SAF 用 feature/expert 两层 RFF-HSIC 学样本权重，Eq14 以同一样本的两种权重乘积作用于各任务损失；底层还使用 AdaTask 式机制。Proposition 1 将有限经验 RFF-HSIC 为零推向重加权分布上的独立性。\[L10\]

D：完整核总体 HSIC、有限 RFF 交叉矩、经验统计是不同对象。有限矩为零一般不能推出任意总体分布独立。经典 HSIC 原文明确区分总体独立准则与有限样本检验。\[L17\] 此外，全局独立不推出每个领域内独立：令 D 与 U 为独立公平二值变量，V=U XOR D，则总体 U 与 V 独立，但给定 D 后完全依赖。

这仍不构成“应当去掉所有域内依赖”的理由。条件依赖可能是真实信号，条件化也可能引入选择关系。要批判其稳定泛化边界，必须先声明需要抵抗哪类环境变化、哪些关系是应保留的信息。有限支持也很关键：若某域只有 (U,V)=(0,0),(1,1)，保持两点正概率时不可能独立；退化到一个点虽然独立，却删掉了可学习变异。

已有 DVD 会保留稳定组内相关，且明确讨论激进去相关造成有效样本量损失；ORCA 已处理 CTR–停留时长的任务层过度依赖，CFS-MTL 已涉及任务因果特征选择。因此“条件 HSIC＋ESS＋gate”不能自动成立为创新。值得进一步研究的是给定支持与任务信息约束时，哪些稳定目标联合可行，以及不可行时如何分配残差或拒绝承诺。\[L15,L16,L56\]

不要采用一个错误论证：不同任务需要不同稳定特征，并不足以推出共同 X-only 正权重必然不可能；在支持充分和模型容量足够时，它可以同时保持所有 P(Y_t\|X)。必须给出真正的支持或共享限制。仓库的 Sample 采样反例也不等于 SAF 学习权重失败，两者的目标不同。

## 5 梯度与优化器论文的适用范围

**AdaTask。** P：分别累计各任务的更新历史，形成任务感知自适应学习率。它研究任务主导，不承诺消除任意采样分布影响。D：平铺 DT 可以实现，但异步访问和缺失标签下应明确状态时钟；分域 moment 并非天然新意。R：v3 的 AdaTask 没消除 q-gap，但其绝对性能可能更好，不能只看差值否定方法。\[L22,R14\]

**GradCraft。** P：先幅度对齐，再同时处理每个任务的原冲突集合，最终平均修正梯度。作者以参数维度远大于任务数支持 Gram 满秩假设，但高维本身不能保证独立。D：令三个单位梯度分别为 (1,0)、(−1,1)/sqrt(2)、(1,−10)/sqrt(101)。所有原冲突 Gram 可逆；按 Eq6–10、epsilon=0 求得平均方向约 (0.0174111,0.0174111)，第三个原梯度与该方向内积约 −0.0155922。这个 CPU 复核反例仅否定“逐任务处理原冲突便推出最终对所有原任务共同下降”的加强命题。论文没有提供完整的这项联合下降定理，不能称整篇被推翻。该反例也属于普通 MTL，不计为 MDMT 创新。\[L23\]

**PUB。** P：直接在优化器给出的候选参数更新上做平衡，已指出原梯度几何不等于实际更新几何。D：其候选更新间的内积效用仍不同于每个目标风险的真实方向导数；更新历史的具体聚合带启发式。R：旧 Adam 历史实验可以支持认真区分状态，却不能把 PUB 已提出的问题改名再发表。\[L24\]

**Nash-MTL、FairGrad、FAMO 与 NTKMTL。** 前两者围绕局部下降效用和公平分配，FAMO 用跨步相对损失改善低成本调权，NTKMTL 用跨任务样本 Jacobian 核解释输出动态。\[L25–L28\] 局部训练下降、公平梯度体积、最终测试收益与相对独立模型的非劣是不同目标。对非凸 BCE 使用平方损失梯度流公式，需要说明近似条件；对稀疏 cell 使用跨步损失差，还须避免批次组成变化冒充学习进度。

**优化轨迹与泛化。** TMLR 2024 的 Can Optimization Trajectories Explain Multi-Task Transfer? 在多个任务环境中发现冲突不能一致预测泛化。它与仓库 utility 改善而性能不改善的证据方向一致，但都不证明优化不重要。合理后果是对每个拟议方法直接检验其核心决策价值，不继续追求所有中介的唯一因果分解。\[L43,R1\]

## 6 采样与验证效用的覆盖比表面更广

**EMS 与 EMAIS。** P：EMS 的定义为 minibatch 大小乘以 uniform/IS 协方差迹比；Prop5.2 匹配均值与协方差迹，并未匹配完整协方差矩阵。作者也说明 with-replacement 和非对角信息的范围。对 SGD 的线性 LR 缩放与 Adam 的平方根建议不是普适轨迹或泛化等价定理。\[L31\]

$$N_{EMS} = N\frac{trV_{uniform}}{trV_{IS}}.$$

**MIS/OMIS。** 已将多个 proposal 与向量梯度估计结合，并讨论实际梯度范数代理。支持不能丢失、重要性修正与代理误差是其必要考虑。只把不同 proposal 叫作“域 proposal”和“任务 proposal”不新。D：相同 trace 可以有不同 cell 方向风险；但最小化加权二次型也是广义 IS 的常规推广，不能据此直接获得新颖性。\[L32\]

**PiKE。** 明确研究低梯度冲突条件下的大规模动态数据混合；其理论条件随任务数与分配量变化。它允许改变原目标平均方向，不能以“不是无偏固定目标估计器”攻击一个未作该承诺的方法。MDMT 边际低冲突不保证所有 cell 低冲突，但仅发现充分条件不满足还不足证明方法无效。\[L33\]

**SLGrad、VAO 与 GRAPE。** SLGrad 已做 sample×task 的主任务验证对齐；VAO 已为多个目标分别构造源任务验证效用矩阵；GRAPE 已联合源领域混合和目标任务权重，以验证风险相对改善建立 max-min 游戏。因此“域任务效用矩阵＋动态重加权＋最差任务保护”已不是空白。\[L34–L36\]

VAO 的特殊可迁移条件值得保留：自动竞价轨迹可以按目标重新计算条件标签，推荐中的点击、点赞、购买不能无条件如此重标。其熵正则最优也不意味着未正则线性效用优于任意静态权重：效用为 (1,0)、温度为 1，按数据量 9:1 得到的静态权重为 (0.9,0.1)，其线性效用 0.9 高于 softmax 的约 0.7311。这使用两来源均有数据的内部点，不依赖零权重边界。该推导只限制所述加强保证，不能代替对实证结果的评价。

## 7 收益保护与不完整观测的直接先例

**ExcessMTL。** 已用超额风险而非原 loss 衡量训练不足，局部二阶代理约为半个梯度 Hessian 逆二次型；实际实现用历史梯度统计近似曲率。该代理不是无条件等于贝叶斯可学习性，尤其不能将只需私有头修复的问题直接解释为应增加共享资源。后一问题又受到 ConsMTL 和组更新文献覆盖，不能简单二次包装。\[L37,L39,L40\]

**DSMTL。** 已明确定义每任务与平均意义的安全；IL 的私有 STL 回退与分阶段学习给出优化解层面的个体经验保证，JL 主要给平均保证，泛化界含复杂度与样本残差。它不是有限样本无条件零损害的承诺。MDMT 候选需要研究压缩模型是否还容得下这些回退解，不能声称首次提出相对 STL 的收益约束。\[L38\]

**PIVRG、SVFair 与 PaLoRA。** 性能公平、贡献公平、可调偏好 Pareto 适配均有先例。领域/任务风险保护也不自动等于用户群体公平；目标、参考模型和评价人口需分别定义。\[L41,L42,L46\]

**ESCM²、ESCIM 与 AEM²TL。** 已有全空间反事实多任务 CVR、因果生成未点击样本转化标签，以及正式 TKDE 的多场景多任务 entire-space 模型。普通 masked BCE、ESMM 多域化或 domain/task embedding 补全均不构成新贡献。风险所在是把未点击转化零、潜在点击后转化、未观测标签和结构上不存在任务混为一谈。\[L18–L21\]

2026 年的直接近邻进一步压缩该空间。HiDe-ESMM 已用 weak separability 下的正负 anchors 识别行为链噪声率；BADR 已处理小 propensity 下的 batch-adaptive DR 和渐近双稳健。ExtraDebias 更已针对零 propensity，用真实概率的 Lipschitz 假设构造伪标签区间并最小化最坏风险。WCP-DR 已用加权 conformal 区间修正或丢弃补全；其理论使用 observed 与 missing 的条件标签分布相同、协变量分布变化的条件，给出边际覆盖，不能扩大为任意 MNAR 或每个稀少 cell 的条件覆盖。\[L51,L52,L57,L58\]

Feasible Fusion 在 ICML 2026 已研究结构不重叠下的观测数据与随机实验联合估计，以实验矩约束恢复可行性，并给出带附加条件的误差界。它进一步说明“补少量随机数据＋约束融合”不是空白。其 structured treatment 与 MDMT 中同一记录的多个不同标签并非同一对象，但这项区别必须落实成额外识别定理或更低信息成本，不能停留于术语。\[L59\]

因此，本报告已淘汰泛泛的“零支持＋区间＋拒绝补全”创新表述。P2 只保留跨域任务结构能否提供额外可识别信息这个更窄的问题。没有任何一篇未覆盖所有细节，就不代表新颖性已经得到证明。

# 第三部分 创新机会全景

## P1 有限支持下的域任务条件稳定性

**研究问题。** 面对有限观测支持与多个标签，哪些去相关或环境平衡要求可以同时满足，同时保留各任务真正需要的信息？当前应质疑的不是“是否应去偏”，而是“优化到很小的经验稳定性统计，是否对应合法、可行的稳定目标”。归属方向 A 与 C。

**文献依据。** SAF 提供直接 MDMT 对话对象；DVD 已覆盖保留稳定依赖与样本量损失；HSIC 提供统计条件；ORCA、CFS-MTL 与 M-scan 是任务依赖和场景因果近邻。Feasible Fusion 已将重叠恢复与结果信息保留的可行性矛盾明确建模，因此“同时保留信息和恢复支持”也不是首次。若候选仅增加 conditional HSIC、ESS 正则，或把约束融合改成多输出，应淘汰。\[L10,L14–L17,L56,L59\]

**MDMT 特有性。** 同一记录同时服务多个任务，域改变可用支持和条件关系；共享表示与共用权重会把多个 cell 的平衡要求耦合。需要证明联合可行集合与分别按域、按任务处理不同。仅将 DT 个独立加权问题平铺后求解不构成新贡献。

**已有证据。** R：KR 训练与测试人口、标签率不同；ML 的嵌套标签提示应保留任务信息。D：pooled 抵消与对角支持两个反例成立。H：这些关系在真实域内环境变化中是否导致风险损失，尚无证据。N17 的 q 和 trace 不能用于声称 SAF 已失败。

**核心构想。** 先定义每个 cell 需要保留的边际、标签或稳定机制约束，再计算最小可达平衡残差；使用可行性证书决定哪些依赖可消除，哪些只能保留或分配松弛。算法输出包含不可满足的约束，避免将优化残差都解释为模型训练不足。最终共享表示只对已经界定的合法稳定目标负责。

**最小关键实验。** 一个 2 域×2 任务的已知机制有限支持模型，包含确实应保留的相关关系与会在部署环境改变的 shortcut；比较普通 pooled 权重、DVD 式选择性平衡、朴素 conditional＋集中度约束、可行性方法。结果 A：既有方法满足表面统计却破坏任务信息，新方法靠证书改善目标风险，继续；结果 B：增加 RFF、朴素条件化或普通 DVD 即完全解决，停止。没有必要先训练大 M3oE。

**创新性风险。** 支持不足、条件独立与多环境稳定都是成熟理论；它们本身不新。新意必须是 MDMT 联合约束的必要或充分条件、能区分结构不可行与估计误差的证书，以及对共享决策有用的构造，不能拼接 HSIC、ESS、门控。

**可行性与价值。** 理论和 CPU 起步成本低，真实 shift 数据要求中等。若能给出“哪些稳定目标不可同时满足”的定理与接近可达边界的方法，有推荐顶会和学习理论会议价值。若没有可信 nuisance 定义，强行去相关可能伤害真实信号，应直接停止。

## P2 跨域任务约束能增加多少可识别信息

**研究问题。** 在非完整域任务观察和异构标签选择下，跨任务逻辑、共享测量机制或少量桥接观测，究竟能识别哪些目标风险与迁移决策？归属方向 A、B 与 C。重点是新增识别信息，不再将零支持、区间或拒绝本身作为创新。

**文献依据。** ESCM²、ESCIM、AEM²TL、HiDe-ESMM、BADR、ExtraDebias、WCP-DR 与 Feasible Fusion 构成直接基线链；早期 MDMT tensor 文献覆盖简单组合补全。\[L18–L21,L51,L52,L57–L59\] 这些工作分别使用行为链、anchors、propensity、Lipschitz 或随机实验信息。需要逐项区分观测假设，不以“不是 MDMT”一笔带过。

**MDMT 特有性。** 一个领域的某任务可作为另一个任务的标签约束或测量锚；同一任务跨域又可能提供校准关系，形成交叉信息路径。任务标签不是可随意分配的 treatment，也不一定能按竞价目标重标。只有这些交叉路径提供了超出普通特征平滑或独立补全的识别信息，MDMT 特有性才成立。

**已有证据。** 仓库完整 3×2 标签可用于受控删格并保留 oracle；ML 的嵌套关系可验证逻辑约束的边界。当前没有自然缺失机制或随机桥接标签，不能声称实际有效。已处理 KR 没有 user_id，也不能假定存在所需用户桥接。

**核心构想。** 明确允许的数据生成模型集合，输出目标风险的可识别集；将跨 cell 的可信逻辑、测量或随机审计限制加入集合。优先估计“某项共享是否可能有害”的符号，而非强求所有缺失概率点恢复。按缩小关键决策歧义所需的信息量选择桥接标签；若标签逻辑未提供新增信息，就拒绝复杂方法。

**最小关键实验。** 构造两个观测数据完全一致、缺失 cell 最优决策相反的世界，再加入一项业务合理且有成本定义的跨轴桥接。A：交叉约束可证明区分两世界，且相同标注预算下比逐 cell ExtraDebias/WCP-DR 或普通低秩补全更有效，继续；B：识别集不变，或桥接只是额外同分布标签量，停止。必须先审数据 schema；自然数据不存在时不训练。

**创新性风险。** 2026 论文覆盖极强。图距离替换欧氏距离、分组 conformal、区间 minimax、共享 embedding 的 DR 都不够新。跨 cell 约束也不能靠未证的“图连通即充分”支持。AEM²TL 全文仍是排重缺口；Feasible Fusion 的完整证明也只做了相关部分核查。

**可行性与价值。** 理论空间高，真实数据风险最高。若得到可识别条件、信息下界和具有明确优势的桥接设计，可形成强方法论文；若只能得到永远宽的区间或需要不可获取的潜在标签，应转为严格负结果，或退出该应用路线。最近文献发现使它的优先级低于初始设想。

## P3 受预算约束的交叉共享能否保留每个 cell 的可接受解

**研究问题。** 当 MDMT 模型用共享、剪枝或低秩结构压缩 DT 个预测器时，每个 cell 相对参考的收益要求是否仍同时可行？需要多少交互容量才能恢复可行？归属方向 B 与 C。

**文献依据。** DSMTL 的私有回退已提供安全先例；AutoIFS、M3oE、AREAD 是共享结构基线；PaLoRA、预算分支、剪枝蒸馏和 2025 safe-pruning 预印本构成压缩先例。FairGrad、GRAPE、PIVRG 控制不同形式的收益，不能替代模型类可行性分析。\[L4,L11,L13,L26,L36,L38,L41,L46,L54\]

**MDMT 特有性。** 按域拆开仍在任务间共享，按任务拆开仍在领域间共享；同时满足两轴的保护约束可能需要 cell 交互成分。成本应按真正可复用的域、任务和交叉模块计算。若任意重编号 DT 个任务后结论完全不变，应将其视为普通 MTL 压缩研究，不宣传 MDMT 特有贡献。

**已有证据。** 旧 Equal 的目标救援说明共享更新来源与优化轨迹可以影响性能；同一模型类内的救援不提供容量不可行证据。自然 Sample 早期负迁移很弱，反而提醒收益约束可能平凡。N17 的保护门未通过不证明整个模型类无可行解。尚缺同协议、预算可比的参考模型组合与容量前沿。

**核心构想。** 定义参考风险向量与部署预算，研究最小合格成本及不可行性证书；根据证书增加最少的跨 cell 残差容量，或拒绝某些共享路径。方法的核心必须是证书指导的结构修复，不能只是给损失加若干约束或增加私有头。
**最小关键实验。** 先在异构二次风险下建立精确小模型可行条件，再使用已有预测或冻结表征检查同类预算矛盾。A：真实成本模型中存在清晰证书，少量有针对性的交互修复优于等成本通用扩容，继续；B：必须人为删掉原 M3oE 的 DT towers 才有矛盾，或小型 flat-DT 头已解决，停止。

**创新性风险。** 不能重述 Eckart–Young、低秩逼近或 DSMTL 的回退门控。需要非均匀 cell 容忍度、异构特征二次型、交叉共享成本下的新下界或构造。经验没找到好模型不等于理论不可行。

**可行性与价值。** 理论和现有模型分析成本中等，业务价值明确。它允许两个有用贡献：相同保护要求下降低部署成本；相同成本下恢复原来不可能的保护。若只能靠增加完整 DT 容量获得收益，或证书不能指导优于常规压缩的修复，应停止。当前最适合优先形成一个窄而严格的理论问题。

## P4 以少于完整展开的成本识别域任务交互

**研究问题。** 域边际与任务边际相同的两组训练状态，可能要求相反的 cell 共享决策。能否用明显低于完整 DT 展开的信息和计算成本识别这些交互？归属方向 A 与 B。

**文献依据。** M2M 已指出域关系随任务变化；AutoIFS、MMFI 能建模 cell 交互；GRAPE 已处理源域与目标任务两组权重；MultiBalance、FAMO、NTKMTL 与完整 cell 的梯度优化是成本强基线。\[L6,L11,L27,L28,L36,L47,L50\]

**MDMT 特有性。** 对均匀 2×2 网格加入如下梯度增量，不改变任意行、列边际：

$$\begin{pmatrix}
v & - v \\
 - v & v
\end{pmatrix}.$$

完整网格的零边际交互子空间维数为每个参数方向上的 (D−1)(T−1)。这给出边际观测的信息缺失；普通 full-DT 方法当然能看见，故新方法必须有额外计算优势或决策保证。

**已有证据。** 现有宏指标与人口权重反号不是这种交互的实证。需要已有 checkpoint 的 cell 响应；N17 保存的 trace 总量不能恢复全交互张量。若二进制梯度未持久化，需要加载少量既有 checkpoint 重新求梯度，属于测量，不是重训。

**核心构想。** 将响应分解为总体、域、任务与交互项；以低秩或稀疏假设进行自适应测量，并对不支持的交互返回不确定。研究恢复哪些模式足以保持共享决策，以及最少测量下界。低秩必须是可检验条件，不能预设全部 MDMT 关系低秩。

**最小关键实验。** 一个既有 checkpoint 的两组不重叠小批次，比较边际模型、结构交互估计与完整 cell oracle 对第三组 cell 响应的预测和决策。A：交互跨批次稳定、改变决策，且结构估计有实际成本优势，继续；B：交互主要是噪声，或完整展开成本很低，停止。当前 D=3、T=2 的设置很可能没有可扩展性痛点，这本身是有效否定结果。

**创新性风险。** ANOVA 分解、矩阵补全和 task affinity 都是成熟工具。仅画四格图、增加交互专家或把 PCGrad 展开到六任务均不够。最终要有信息复杂度或算法误差保证。

**可行性与价值。** 理论深度与 MDMT 特有性较高；对很多域和任务的工业系统更有价值。当前仓库规模小，外部实证扩展需求高。与 P3 的区别是它研究测量成本和信息缺失；P3 研究模型容量与可行解是否存在，不能把同一交互模块同时算成两篇贡献。

## P5 潜在代理语义与函数等价下的迁移决策

**研究问题。** 用 gate、attention entropy 或累积统计解释 specificity、困难度、可迁移性时，该解释是否能由预测与观测分布唯一确定？若不唯一，是否真正导致可纠正的错误决策？归属方向 A。

**文献依据。** D3 给出精确对称入口；ExcessMTL 区分风险定义与近似代理。自然梯度、NTKMTL、SLGrad、VAO、GRAPE 已覆盖大部分替代工具。\[L9,L28,L34–L37,L44\]

**MDMT 特有性。** 一个标量代理可能无法同时表达源更新对多个域任务的异向作用，但异向作用本身是普通 MTL 几何。要独立成立，必须证明实际双轴结构造成旧代理不可区分，而一个低成本、可观测的函数响应足以区分。否则保留为理论批判，不立方法项目。

**已有证据。** D3 出版公式的前向保持变换是 D；官方实现未核。仓库没有 D3 gate 与反事实收益配对数据，V1 不能补这个缺口。旧 utility 与性能不一致反而反驳“换代理必有效”的预设。

**核心构想。** 对同一候选函数扰动定义 cell 风险方向导数，将代理视为对该量的估计；只要求对纯表示对称一致，不要求所有训练轨迹在任意参数化下相同。可用预测 KL 限定局部动作，但不能将 KL 小解释为 AUC 不下降。

**最小关键实验。** 先做出版公式对称核验，再在严格定义的同一函数扰动族中比较决策。A：代理随等价表示改变，而且改变造成稳定错误选择，现成自然梯度验证方法仍不能解决其 MDMT 部分，保留；B：仅命名或数值改变，决策无损，或现成方法已解决，停止。

**创新性风险。** 六个候选中覆盖风险最高。Fisher＋validation、注意力不等于解释、预测等价但优化不同，都不能单独包装为 MDMT 创新。代码含 detach 时，用停止梯度 Jacobian 近似实际预测 KL 还可能有额外误差，应直接检查真实预测变化。

**可行性与价值。** 成本低，适合形成可复核的理论边界或方法审计。当前不建议独立 GPU 开发；只有接入 P3 或 P4 的新问题后才有方法价值，届时计为一个统一科学贡献。

## P6 多标签共采样下的目标保持与方向风险

**研究问题。** 在一条样本同时产生多个任务梯度、多个共享路径共用计算时，能否在固定目标和预算下，降低关键 cell 的方向风险，而不是只最小化总 trace？归属方向 B 与 C。

**文献依据。** EMS、EMAIS、MIS/OMIS 已覆盖均值保持、范数代理与多 proposal；PiKE 研究数据混合效率。必须对照广义加权范数 IS，不能将一个二次型采样公式当新发明。\[L31–L33\]

**MDMT 特有性。** 采一行同时获得多个标签和共享前向，在普通 MTL 和向量 MIS 中也已存在，不能单独作为 MDMT 特征。只有领域相关的标签可用性、共享执行路径和成本，使可实现的联合采样集合发生额外变化，才可能产生双轴的新问题。若只是共同采一行，或各 cell 可独立等成本采样，则退化为已有多任务 IS。

**已有证据。** N17 支持固定目标改变 q 会改变统计和轨迹，并排除所测锚点域计数项主导；它没有证明方向协方差有长期收益。SGD 反例说明该问题不需要预设 Adam。N3 只关闭其所测共享 C 路线，不提供方向采样的直接支持或否定证据。

**核心构想。** 固定风险权重 pi，建立样本、标签、共享计算的关联结构，在预算下优化多 cell 风险投影方差或可信局部二阶上界。估计误差与额外求梯度成本必须进入目标；若 oracle 都没有收益空间，学习 sampler 更没有理由继续。

**最小关键实验。** 重放一个既有 checkpoint 的可用梯度或重新做少量固定点测量，比较自然采样、范数 IS、MIS 和方向 oracle。A：相同目标、相近总 trace 下方向 oracle 有实用优势，且低成本估计保留优势，才做短方法试验；B：范数 IS 已达到、估计成本抵消、或优势量级太小，停止。无需识别方差到泛化的全部中介。

**创新性风险。** 经典公式会给出 q 与加权梯度二阶量平方根成比例；这种性质完全不新。只有由领域相关标签和执行路径产生的新可实现约束、相应近似保证和真实成本改进，才可能提供实质贡献；普通多标签联合采样本身也已被覆盖。

**可行性与价值。** 工程可行性较好，科学新意和收益不确定性较高。当前列为低优先条件候选，不能因为已有 N17 数据多就优先续训。

## 三个额外问题的筛除与保留

**领域特异标签语义的迁移。** 可定义全部标签都可见，但 Y_dt=1{Z\>tau_dt}，不同域阈值或行为机会不同。即使潜在兴趣 Z 稳定，源域正例也不能直接复制为目标正例。它能检验 AREAD 假设的迁移边界，并与 LabelCraft、ORCA、AEM²TL、测量不变性和序数模型对话。\[L13,L15,L18,L53\] 但当前 ML 各域用相同阈值，KR 缺少测量规则证据。若核心仍是观测机制识别，则并入 P2；仅新增域阈值头不独立立项。

**共享可改善风险与私有头可改善风险。** 可以研究固定共享后的 head 最优响应与共享动作收益，但 ExcessMTL、ConsMTL、Selective Task Group Updates 覆盖很强。\[L37,L39,L40\] 只有真实双轴私有子空间造成系统错误决策时才纳入 P3；不重新启动 C 的全中介分解。

**域粒度一致性与双轴优化器状态。** 等价域随机拆分是否改变风险权重、路由或状态值得作理论边界；但匹配总目标质量和总容量后可能消失，层级 MTL 与域发现也已广泛研究。shared/domain/task moments 的分解更接近已有 AdaTask/PUB 的工程扩展。两者不列入近期 GPU 队列，也不用于凑正式候选数量。

# 第五部分 重点方案深入设计

## 方案一 P3 预算与 cell 保护之间的可行边界

### 问题定义

令 c=(d,t)，R_c 为固定部署人口上的风险，f_ref,c 为预先冻结且协议可比的参考。定义共享结构 S 的真实部署成本 C(S)，以及允许风险损失 epsilon_c。需要研究：

$$\mathcal{C}_{B}(\epsilon) = \{ f_{S}:C(S) \leq B,\ R_{c}\left( f_{S} \right) - R_{c}\left( f_{ref,c} \right) \leq \epsilon_{c}\ \forall c\}.$$

$$B_{min}(\epsilon) = \inf_{S,\theta}\{ C(S):R_{c}\left( f_{S,\theta} \right) - R_{c}\left( f_{ref,c} \right) \leq \epsilon_{c}\ \forall c\}.$$

如果整个参考组合本来就在预算 B 内，直接复制参考就可行。这种平凡情况不应立题。研究应明确压缩预算低于参考组合成本，或者各 cell 参考无法由同一个预算模型直接实现。参考选择只用训练与验证信息；不同历史目标、数据或训练预算的最好值不能拼成不公平门槛。

第一阶段用平方损失研究精确边界，后续 BCE 只使用明确的局部近似或有界概率区间。不要把平方误差可行性定理直接称作 AUC 非劣保证。经验风险要求也需要配对估计误差，不能把训练约束写成测试总体保证。

### 可证伪假设

H3a：在与真实部署压缩方式对应的模型类中，存在由双轴交互造成的非均匀 cell 保护不可行，而按域或按任务单独观察会漏掉该约束。
H3b：不可行证书能够定位少量需要额外交互容量的路径，产生优于同预算通用扩容或剪枝蒸馏的修复。

H3c：所需交互具有可复用结构，因此可以比完整 DT 私有回退更省成本。若必须保留全部独立容量，安全压缩价值不成立。

### 一个已经成立的受限模型引理

设 y=W_dt x+noise，条件噪声均值为零，s_dt=E\[x²\]\>0，使用不含半系数的平方损失。则相对真实系数参考：

$$R_{dt}(\theta) - R_{dt}(W) = s_{dt}\left( \theta_{dt} - W_{dt} \right)^{2}.$$

假设 epsilon_dt≥0，令 delta_dt=sqrt(epsilon_dt/s_dt)，保护条件等价于系数处于 W_dt 周围的区间。对两域两任务的纯加性类 theta_dt=a_d+b_t，可行的充要条件为：

$$\left| W_{11} - W_{12} - W_{21} + W_{22} \right| \leq \delta_{11} + \delta_{12} + \delta_{21} + \delta_{22}.$$

理由是加性矩阵的交叉差为零，四个允许误差的交叉差恰覆盖右侧总宽度。对参考矩阵 \[\[1,−1\],\[−1,1\]\]，左侧为 4；在 s=1 时最佳加性预测为零，宏超额 MSE 为 1，无噪声时即总 MSE 为 1。本轮已用 CPU 最小二乘核验。一个秩一交互即可精确拟合这个特例。

一般网格令 z_t=−b_t，则 W_dt−delta_dt≤a_d−z_t≤W_dt+delta_dt 是二部图上的差约束，可用负环给出受限类不可行证书。这是标准差约束理论的应用，是可靠起点，不是已完成的顶会创新。高维真实问题的 cell 误差是异构二次型，而非统一 Frobenius 范数；需要在共享路径成本、非均匀保护与最小修复上取得新的结论。

**不能把这个引理用于声称 M3oE 无法表示 checkerboard。** M3oE 有 DT towers 和非线性融合，已经超出纯加性类。若问题只能通过人为删除它已有能力制造，应停止此路线。

### 可能的算法框架

先冻结参考和成本定义，再在域、任务与 cell 交互模块组成的结构族中求可行解。对能够证明下界的简化族输出证书，对一般网络只报告经验可行前沿。根据最紧的约束选择最小成本的结构扩张，再优化风险。约束乘子表示当前限制的紧迫程度，不被解释为领域“天然困难”。

$$\min_{S,\theta}\sum_{c}^{}\pi_{c}{\widehat{R}}_{c}(\theta,S),\quad\quad C(S) \leq B,\quad{\widehat{\Delta R}}_{c}(\theta,S) + \rho_{c} \leq \epsilon_{c}\quad\forall c.$$

rho_c 是按明确采样假设得到的风险差不确定度或保守估计，不是随意调参惩罚。若该量驱动结构搜索或模型选择，概率保护还需覆盖相应的自适应选择；否则仅是经验筛选量，不构成总体非劣保证。若直接寻找最小合格预算，应改为最小化 C(S)，约束所有 cell 的风险差；成本加权罚项只能作为搜索启发式，不能替代硬预算或保证求得 B_min。这个写法本身是常规约束优化；新贡献必须来自如何检测结构不可行、如何以成本保证修复，以及它为什么利用了域任务交叉结构。

### 与最近方法逐项区别

| **最近工作**       | **已经具有**               | **本方案必须新增**                 |
|--------------------|----------------------------|------------------------------------|
| DSMTL              | 完整私有回退与个体安全定义 | 低于参考组合成本时的可行条件       |
| AutoIFS            | 四类信息流和自动选择       | 选择结果的风险可行性证书与成本下界 |
| PaLoRA             | 低秩偏好适配与 Pareto 控制 | 非均匀参考保护与最小结构修复       |
| safe pruning 加 KD | 任务感知压缩和损失控制     | 可验证的双轴不可行结构及构造优势   |
| GRAPE FairGrad     | 局部或验证收益分配         | 模型类是否包含合格解的判断         |

### 最小实验与停止规则

**T3a 理论与 CPU。** 非均匀容忍度、不同 s_dt 的 2×2 与小网格，验证精确可行条件和负环证书。A：证书与求解器一致且指向明确交互修复，进入真实模型检查；B：候选成本模型与真实结构无对应，停止。不是为了证明线性代数而无限扩大网格。

**T3b 复用模型。** 对已有、同协议的参考预测或冻结表示，拟合预算结构并比较证书预测的难点。A：真实残差呈双轴模式，有同成本修复空间，才训练最小原型；B：普通 cell heads 或同预算 KD 已实现保护，停止。没有相应 checkpoint 时登记访问缺口，不把缺口变成重训全部参考的理由。

**T3c 条件性 GPU。** 只比较最强同预算共享基线、通用扩容、证书引导修复，并保留完整参考作上界。关注成本—保护前沿与 selected 风险；AUC、LogLoss 各自评价。没有相对等成本扩容的稳定实用优势，或理论证书只预测训练误差而不影响部署选择，停止。

若成功，论文可以形成“明确失败边界—预算下界—结构构造—推荐规模收益”完整链。若只得到一次额外私有头带来的小幅提升，价值不足。

## 方案二 P1 支持和信息保留下的条件稳定学习

### 问题定义

区分领域 d 与领域内部环境 e，例如不同时间窗口或曝光策略；只有日志确实提供这些含义时才这样定义，不把行号当时间。每个任务 t 有明确目标风险和需保留的预测关系。记 w_dt 为作用于该 cell 风险的训练权重，phi_dt 为必须保留的可观测矩，psi_dte 为已论证与目标 shift 有关的待平衡矩。以下 E_d,e 明确指原始观测分布 P(X,Y\|D=d,E=e) 下的期望，权重在每个环境内归一化。

$$\mathcal{W}_{dt} = \{ w \geq 0:\forall e,\ \mathbb{E}_{d,e}\lbrack w\rbrack = 1,\ \mathbb{E}_{d,e}\left\lbrack w\phi_{dt} \right\rbrack = m_{dte},\ \mathbb{E}_{d,e}\left\lbrack w^{2} \right\rbrack \leq \kappa_{dte}\}.$$

$$\xi^{*} = \min_{w \in \mathcal{W}}\max_{d,t,e} \parallel \mathbb{E}_{d,e}\left\lbrack w_{dt}\psi_{dte} \right\rbrack - b_{dte} \parallel_{2}^{2}.$$

这里的联合集合 W 还应包含同一记录共用权重、允许的 cell-specific 权重或其他已声明的共享限制。有限个 phi 矩约束只保留所声明的矩；保留全部预测信息还需额外充分性或函数类条件。目标矩 m、b 必须由声明的目标人口、可信机制或可用锚决定，不能利用最终测试标签拟定。固定目标矩和上述逐环境归一化下，离散线性平衡可以做凸可行性诊断；一般 HSIC 本身未必是凸问题，不能将非凸训练失败解释为 xi\*\>0 的结构证明。

共用样本权重时，所有 w_dt 受同一记录上的共享约束；允许 cell-specific 权重会扩展可行域，但不自动使一个有限共享模型同时达到所有任务风险。P1 研究分布变换与信息保留，P3 研究模型容量；两者无需在第一篇论文里强行一起解决。

### 可证伪假设

H1a：存在实际有意义的领域内环境变化，使 pooled 稳定统计遗漏了会影响 cell 泛化的依赖。

H1b：在保持任务重要信息与权重集中度约束后，部分平衡目标存在可证明的正残差下界；残差不是优化器或 RFF 数量不足造成的。

H1c：依据可行边界分配平衡残差，比朴素 conditional HSIC、DVD 或单独增加样本权重正则更能改善目标风险，且没有通过删掉困难标签群体取得表面稳定。

### 两个反例及其合法使用方式

全局抵消例 D,U 独立、V=U XOR D 只说明统计对象不同。要形成预测问题，应另定义一项会改变 shortcut 关系的部署环境，同时规定真正稳定预测机制。例如在已知生成模型中令任务依赖独立的稳定变量，训练域内 shortcut 强度随 e 变化；另一任务使用被第一任务视作 shortcut 的变量作为真实信号。构造的依据必须写清，而不能凭“相关”将变量命名为因果或非因果。

对角支持例中，任何同时保留两点的权重都无法得到 U 与 V 独立。如果只要求 ESS 大，仍可能在一个大量重复的取值上获得较大 ESS，却丢失另一标签类别。因此集中度预算还需与标签或关键亚群覆盖约束结合。ESS 只衡量权重集中，不等于独立用户数、真实信息量或 EMS。

### 可能的算法框架与理论目标

先以固定有限支持 oracle 求目标矩的最小残差和约束冲突集合，再用可解释松弛分配避免强行零化；只有被机制或多环境证据支持的依赖进入稳定目标。随后学习表示与预测器，在未参与权重拟合的环境或样本上检验风险。

应尝试证明三件事：在明确离散或线性模型下的联合可行条件；有限样本估计误差与结构残差的分离；在明确 shift family 下，保留信息和允许残差如何影响最坏风险。不能在尚未给出条件时写“去相关保证因果稳定”或“ESS 保证泛化”。

### 最近方法与最小对照

| **对照**                      | **为什么必须有**       | **哪个结果会否定新方案**     |
|-------------------------------|------------------------|------------------------------|
| SAF 忠实实现                  | 最新直接 MDMT 稳定方法 | 其原机制已解决所构造问题     |
| DVD                           | 已有选择性稳定去相关   | 仅需按域运行即可达到同样边界 |
| conditional HSIC 加集中度约束 | 排除常规扩展           | 简单条件化已完全解决         |
| 不做平衡的同容量模型          | 检验是否删掉真实信号   | 平衡始终损害目标风险         |
| 有生成真值的 oracle           | 区分不可行与训练没找到 | 不存在声称的支持障碍         |

另须将 Feasible Fusion 的信息保留与矩约束视为理论近邻；若使用随机审计信息，应在其适用假设成立的版本中作同信息量比较。它的 RCT 治疗效应设定与多标签推荐有区别，但区别必须进入定理，不能只改输出头。\[L59\]

**T1a CPU。** 用一个完整 2×2 机制构造，同时有可平衡和不可平衡支持；比较上述必要机制，不跑多 backbone。A：新证书发现旧方法遗漏且影响风险的不可行目标，继续；B：只是有限特征近似，增大 RFF 即消失，停止。

**T1b 已有数据。** 先审 KR 时间、曝光和标签定义，仅在存在合理 e 时计算分域与 pooled 的目标矩、权重集中度、关键标签覆盖。A：支持实际问题，进行一个稳定方法 pilot；B：没有可定义环境或 nuisance，停止该数据路线。不能用主域测试正率变化直接证明 H1a。

**T1c 条件性 GPU。** 同目标、同容量下比较最佳现成稳定基线、朴素条件基线与可行性方法。主要看预先声明的外部环境风险；只改善拟合 HSIC 或漂亮 saliency 不算方法成功。

如果成功，贡献是可行性驱动的稳定目标设计及适用边界；若只能再加一个 HSIC penalty，停止。

## 方案三 P2 跨轴桥接的额外可识别性

### 问题定义

每条记录包含 X、领域 D、标签观察掩码 O_t，以及 O_t=1 时可见的 Y_t。先区分三类情况：有意义但未观察的标签、结构上不适用的任务、已经观察到的负例。只对前者定义待恢复风险；不能给“不适用任务”凭空创造业务标签。

$$R_{dt}(f) = \mathbb{E}\left\lbrack \ell\left( f_{dt}(X),Y_{t} \right) \mid D = d \right\rbrack.$$

令 P_obs 是观测分布，A 是明确声明的逻辑、测量或桥接假设：

$$\mathcal{P}\left( P_{obs},A \right) = \{ P:P\text{ 产生 }P_{obs}\text{ 且满足 }A\}.$$

$$\mathcal{I}_{dt}(f) = \left\lbrack \inf_{P \in \mathcal{P}}R_{dt,P}(f),\ \sup_{P \in \mathcal{P}}R_{dt,P}(f) \right\rbrack.$$

这里的 I 是风险识别上下界形成的区间包络；若 A 使兼容分布集合非凸，实际可取得的风险值未必填满区间。离散线性约束下可另外证明凸性与端点可达性，才将其称为精确识别区间。区间与最坏风险本身已由 ExtraDebias 等覆盖。这里拟研究的是加入真实跨轴关系后，集合比逐 cell 方法缩小多少，能否识别一个新的共享决策；如果只是区间呈现形式变了，方向不成立。\[L57–L59\]

对固定或条件于已训练结果的候选 f_shared、f_ref，决策对象应直接用同一兼容分布下的风险差。定义 Delta_dt,P=R_dt,P(f_shared)−R_dt,P(f_ref)，再求：

$$\mathcal{J}_{dt}\left( f_{shared},f_{ref} \right) = \left\lbrack \inf_{P \in \mathcal{P}}\Delta_{dt,P},\ \sup_{P \in \mathcal{P}}\Delta_{dt,P} \right\rbrack.$$

分别求两风险区间再相减通常只是更保守的包络；它可能丢掉桥接已经提供的收益符号信息。只有 J 的上界不超过允许损失，才支持对应的稳健共享判断。

### 两个不能省略的不可识别起点
2×2 观测图有三条边时是连通的，但可以存在两个世界在全部已观察 cell 相同、在缺失 cell 的标签概率相反。没有结构限制，图连通不能恢复未知 cell。低秩假设也必须说明作用于概率、logit、参数还是条件函数；一般非线性网络不会因一个连通图自动获得识别信息。

即便每个 cell 都有观察，outcome-dependent missingness 仍可能不识别。固定 X 时，观察率 r、已观察正率 m 和未观察正率 q 给出：

$$P(Y = 1) = rm + (1 - r)q \in \lbrack rm,\ rm + 1 - r\rbrack.$$

多个 q 产生相同观测数据。若另有可信 Y_1≤Y_0 和完整 Y_0，可加入上界 P(Y_1=1)≤P(Y_0=1)，但不自动点识别。这是经典缺失数据逻辑起点；新贡献应在跨域任务桥接的额外收缩条件，而不是重新发表这一公式。

### MAR 校正的明确范围

当 O_t 与 Y_t 在给定 X、D 后条件独立且观察概率 e_dt(X)\>0，可用损失回归 m_dt 与 propensity 构造 DR 风险估计：

$${\widehat{R}}_{dt} = \frac{1}{n_{d}}\sum_{i:D_{i} = d}^{}\left\lbrack {\widehat{m}}_{dt}\left( X_{i} \right) + \frac{O_{it}}{{\widehat{e}}_{dt}\left( X_{i} \right)}\{\ell_{it} - {\widehat{m}}_{dt}\left( X_{i} \right)\} \right\rbrack.$$

这是标准工具，不是候选贡献。需要交叉拟合或明确 nuisance 与评价依赖；真正零支持和未说明的 MNAR 不会被正的数值 propensity 修复。WCP-DR 的边际 conformal 覆盖也不能自动变成每个域任务条件覆盖。\[L19,L52,L58\]

### 拟研究的新增识别结构

最值得先分析两个窄版本。版本一：任务有可信嵌套或联合标签约束，部分域具有少量随机审计标签，能否识别其他域中某个迁移收益的符号，而无需恢复全部概率？版本二：域任务测量通道具有可检验的共享结构，一些 cell 缺乏 HiDe-ESMM 所需的极端 anchors，跨域和跨任务桥接能否替代该条件？\[L51\]

对第二种版本，定义 a_dt=P(观测标签=1\|真实标签=0,D=d)、b_dt=P(观测标签=0\|真实标签=1,D=d)。在给定真实标签后噪声率不依赖 X 的 class-dependent 假设下，观测后验可以写成：

$${\widetilde{\eta}}_{dt}(x) = a_{dt} + \left( 1 - a_{dt} - b_{dt} \right)\eta_{dt}(x).$$

多个未知 clean posterior 与噪声率可以相互补偿。只有额外结构或审计信息能拆开它们。不能把学习一个共享噪声网络当成证明识别；也不能先假定所有域噪声率相同，再宣称发现跨域迁移。将哪些共享限制可由数据反驳、哪些必须外部声明列清，是这一研究的一部分。

### 算法框架与最接近论文差异

从单 cell 的可行概率或风险集合开始，加入跨 cell 的可信等式、不等式和审计约束；在离散支持上先用 LP 或约束优化精确计算收缩。只有识别集对某项共享选择给出稳定结论时才采用该迁移；否则保持不确定或获取最有价值的桥接信息。实际桥接应指明领域、任务、X 支持和标签获取成本，不能抽象成没有业务来源的一条图边。

| **最近论文**       | **提供的识别或控制信息**         | **拟议方案必须超出的部分**          |
|--------------------|----------------------------------|-------------------------------------|
| AEM²TL ESCM² ESCIM | 固定行为链与全空间学习           | 非完整域任务结构的新增信息          |
| HiDe-ESMM          | weak separability 的噪声 anchors | 缺 anchor cell 的可证明跨轴替代条件 |
| BADR               | 小正 propensity 的稳健估计       | 无法观察处的额外信息来源            |
| ExtraDebias        | Lipschitz 概率区间及最坏风险     | 跨 cell 逻辑能严格缩小其识别集合    |
| WCP-DR             | 协变量偏移下的补全区间与拒绝     | 超过分组校准的结构性识别增益        |
| Feasible Fusion    | RCT 矩约束与结构不重叠融合       | 多标签共同观测的不同桥接条件        |

### 最小实验与停止规则

**T2a 文献和理论。** 精确写出与上述六类近邻各自不同的假设，构造两个同观测世界，并证明业务合理的跨轴约束确实区分它们。A：得到新可识别量或更小必要审计成本，继续；B：逐 cell ExtraDebias、WCP-DR、普通低秩或一般数据融合已给同样结论，停止。

**T2b 数据 gate。** 只读标签 schema、生成规则与可用审计/桥接字段。A：存在真实机制和可访问的信息来源，进入受控检查；B：只有完整标签，且人为 masking 是唯一情境，保留理论验证但降低推荐应用立项优先级。不要先训练再寻找问题。

**T2c CPU 加现有数据。** 在完整标签上构造一次已知 MAR、一次与标签相关的受控 missingness，用未遮标签作为 oracle；比较精确识别集和方法估计，不把 MAR 结果冒充 MNAR 保证。同一桥接标注预算下比较结构选择与随机标注。A：跨轴关系显著减少决策歧义且覆盖边界正确，才考虑真实场景 GPU；B：全部收益来自多拿标签或宽区间从不支持决策，停止。

若成功，可形成识别条件、不可识别反例、信息成本和选择性共享的一体化贡献。若只做“DR＋MDMT backbone＋conformal”，直接淘汰。

# 第六部分 具体下一步行动

## 1 优先完成的非训练工作

**第一步 固定研究对象与最强反对解释。** 为 P3 写出真实模块成本和参考组合；为 P1 写出应抵抗的 shift 与应保留的信息；为 P2 写出允许的观测机制和跨轴桥接来源。每个问题先写一页“现成方法为什么可能已经解决”，尤其包含完整 DT 展开。若无法说清差异，不进入实现。

**第二步 完成最短理论判别。** P3 推进非均匀 cell 约束与最小交互修复，P1 求有限支持 oracle 的联合可行性，P2 证明加入跨轴信息前后识别集合是否严格变化。D3 gate 对称、GradCraft 联合方向反例作为已获得的数学边界留档，不需要靠训练增强其逻辑真值。

**第三步 只读数据和产物可用性。** 确认原数据的时间戳、标签定义、缺失指示、随机日志、用户标识及 checkpoint 是否仍可访问。当前 GitHub 的 SHA 索引不能替代实际模型和预测文件。没有对应数据时，明确降低某条应用方向，不从历史现象推测它存在。

**第四步 复用既有模型做有决策价值的读数。** P3 看预算结构对参考预测的可达性；P4 看跨独立批次的交互响应是否稳定；P6 只看方向 oracle 的收益空间。它们可以共享同一小批冻结 checkpoint，但不能因共享算力便顺带铺满所有旧机制问题。

## 2 每项新增工作如何改变决策

| **工作**           | **区分的两个关键解释**          | **结果 A 的动作** | **结果 B 的动作**        |
|--------------------|---------------------------------|-------------------|--------------------------|
| P3 成本与可行证书  | 缺合格容量 或 仅优化未找到      | 定向修复结构      | 转现成优化或停止         |
| P1 有限支持 oracle | 目标本来不可行 或 统计估计不足  | 研究约束松弛      | 用简单统计修复并停止新法 |
| P2 跨轴识别证明    | bridge 增加信息 或 只是更多标签 | 研究信息成本      | 合并现有去偏方法或停止   |
| P4 独立批次响应    | 稳定交互 或 梯度噪声            | 研究低成本测量    | 停止交互控制开发         |
| P6 方向 oracle     | 有可利用空间 或 范数 IS 已足够  | 一次短原型        | 不训练 sampler           |
| 自然数据 schema    | 场景真实存在 或 仅人为标签构造  | 冻结对应评测任务  | 降级为理论受控问题       |

如果两个结果都不会改变继续决策，该项工作不应执行。上述是带条件的分支，不是必须全部完成的矩阵。

## 3 哪些工作才值得新的 GPU 训练

新 GPU 的前置条件是：问题定义已稳定，至少一个原文条件或结构边界已被理论/现有数据支持，最强简单基线不能直接消除差异，oracle 优势达到事先声明的实际意义，并且有适配该问题的数据。

通过前置条件后，先选一个主候选、一个最相关数据环境、一个忠实强基线、一个能区分核心机制的简单对照进行短 pilot。P3 需要等部署成本的结构比较；P1 需要合法环境变化和信息保留读数；P2 需要同标注信息预算。不同方法假设不成立时应报告不适用，不能以不公平配置制造失效。

训练前一次性冻结目标权重、模型选择规则、风险容忍度、计算预算与种子数。种子数由预期实用效应和已有波动估计决定；pilot 无核心优势就停止，不因显著性不足循环补种子。正式论文确认阶段再扩到能支撑外推的独立数据机制，并保留未参与方法选择的评价信息；不把历史 test 重新命名为全新确认集。

## 4 工程检查只保留科学必要项

只检查会改变结论的实现：目标与采样修正是否一致；quota 是否按实际计数；模型参考与参数预算是否可比；训练图 detach 的定义是否与数学一致；论文基线是否忠实实现；标签掩码是否把未观察错当负例；selection 是否只用允许信息。这些检查服务算法正确性。无需为报告增加通用单元测试、全平台兼容或无关防御性工程工作。

## 5 可以立即停止的开发设想

不开展 Adam 替换矩阵、所有 moment 交叉移植、围绕 C 的长期拓扑补齐、更多 Equal/Sample 普遍性重复；不开发纯 validation cosine＋softmax、AdaTask＋HSIC、四类 LoRA 信息流、零支持＋普通区间 minimax 等已被覆盖的组合；不以更大的模型或更长训练弥补科学问题缺失。

最有价值的下一份研究产物应是一份窄问题说明及其成立和停止条件：P3 的可行性证书与真实成本对应，P1 的合法稳定约束及有限支持边界，或者 P2 相对 2026 最强去偏工作的新增识别信息。只有其中一项产生明确差异，再投入训练资源。
