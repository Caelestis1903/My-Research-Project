# 研究方向重新设计与决策


版本：`DFD-v4.0 / 2026-10-26`。本文作研究决策；精确算法以[04](04_核心算法与Codex实现规范.md)为准，运行与晋级以[05](05_完整实验矩阵与研究决策.md)为准。所有新方法效果均**未测**。文献检索截至 2026-10-26。

## 1. 最终选择


下一阶段只批准一条完整主线：**需求条件来源函数形成（Demand-conditioned Function Development，DFD，暂定工作名）**。它检验的问题是：在同一目标域内部，能否先从样本可见特征预测对不同来源函数的相对需求，再把这种需求用于组织来源域自身的监督学习，使形成的函数库在相同读取器下具有可重复的增量？

主线采用稳定表示、显式来源监督、概率导出的条件风险差、保持每行总权重的内容分配以及普通连续读取。它不采用一步元梯度，不增加状态 NN，不把门控本身作为新贡献。完整训练是从原始数据和随机初始化开始的**分阶段流水线**，不是一个持续共同更新的端到端计算图。

RHD 不列为第二条完整训练主线。保留一次有上限的共享/私有更新四叉诊断，以及现有日志上的控制频率分析；只有未来形成超越早停与固定共享冻结的证据，才值得另立研究方案。本轮不把旧 PB 的正式失败改为“后期成功”，也不将第二方向用于兜底追求阳性结果。

选择 DFD 的原因有三项。第一，v3 已观察到普通 foreign 读取的有限机会，而形成元学习的额外收益不稳定；因此问题仍有实证入口，但形成方法需要改变。第二，稳定函数与来源监督允许把“读取器能力”“来源功能”和“额外标签拟合”拆开比较。第三，即使失败，也能回答需求不可预测、需求不能跨支持区域转移、或形成后的内容可被普通本地函数替代中的哪一项限制成立。[证据复盘](01_实验事实复盘与机制分析.md)

## 2. 为什么不继续机械修补 RHD


### 2.1 原始价值及现有反证


RHD 的原始假设是：相同训练状态下的实际更新响应，可以比梯度夹角或静态域权重更直接地指导共享更新。保留价值在于完整状态反事实分叉、真实 Adam 更新、逐目标风险响应以及历史信息与当前信息的可分离定义。

v3 的 PB_HB 在 KuaiRand 开发阶段积极，但正式四 seed 的 validation-selected 模型在 exposed test 上，相对 BASE 的平均 ΔLL 为 `+0.00074075`，相对 PB_H1 为 `+0.00041321`。与 HISTORY 相比虽然平均 LL 为负，四 seed 只有两次改善，AUC 四次均下降。共同 epoch50 的优势较重复，但全部 20 条正式轨迹的终点 LL 均差于各自 selected。这支持“部分训练路径晚期少恶化”的描述，尚不支持“最佳可用模型更好”。[正式报告](https://github.com/Caelestis1903/My-Research-Project/blob/8a4b3b296ca5dc7349956fae9eca5e202aefe2c0/research_reports/2026-10-25_v3/FORMAL_LOCKED_REEVALUATION.md)

### 2.2 竞争解释与可建设性修改


| 解释 | 当前证据 | 技术上应怎样区分 | 本轮决定 |
|---|---|---|---|
| 当前反馈提供有用信息，但接受门槛过于保守 | 开发局部收益支持；正式 selected 不稳 | 在事先固定的动作占用率/阶段预算内比较历史与当前信息；不能用 HB 事后接受时间给对照指定未来日程 | 只先分析现存日志，不开新完整 PB 网格 |
| HB 的价值主要来自少行动 | HB 的非 STATIC 事件明显少于 HISTORY，信息与剂量混杂 | 固定阶段预算的历史策略与当前策略用同一非 STATIC 上限；同时对比简单固定阶段停止 | 有研究意义，证据不足以优先完整训练 |
| C8 的共同域质量不能表达真正的局部需要 | 宏收益与逐格损害可能相反；没有充分重复的同域两任务响应证据 | 先查已有六格响应；不能仅凭宏失败扩成 C14 或任意样本控制器 | 暂缓 |
| 共享与私有参数成熟时间不同 | 晚期 selected/endpoint 分离；尚无共享与私有路径的独立识别 | 同状态做全更新、只私有、只共享、全停四叉，比较相同后续数据和多跨度 | 仅批准有界诊断 |
| 短期响应不能预测长期路径 | 探测窗口与执行路径不同；旧回放两锚对比动作相同 | 使用预定非退化的更新掩码和完整状态；记录早期与后续风险符号，不能把零对比当作稳定性 | 四叉诊断同时回答部分问题 |

新的控制对象如果成立，应是**共享表示的继续可塑性与私有适配的相对价值**，而不必仍是 C8 域权重。具体可发展为“共享停止、私有继续”的训练日程，或在明确的阶段约束下控制真实 Adam 位移。但“异步成熟”已有任务蒸馏等近邻，且固定数据上保存最佳 checkpoint 是很强的简单方案。只有 private-only 的完整方法能超过同预算早停、固定冻结和已有方法，才能声称实用训练贡献。[文献边界](02_相关研究与创新定位.md)

## 3. LPS 应保留什么，必须替换什么


### 3.1 保留科学问题，改变形成对象


原始 LPS 价值是同一域内不同样本可能需要不同知识，而不是“低秩块数量越多越好”。v3 说明读路径确实有小的固定状态贡献，普通读取在部分开发比较中有效；但 L4 的独立形成增量没有稳定成立。元梯度非零说明实现执行了，不能说明形成了不同的功能；高 raw-gradient cosine 也不能反推代码错误或 Adam 位移相同。[形成报告](https://github.com/Caelestis1903/My-Research-Project/blob/8a4b3b296ca5dc7349956fae9eca5e202aefe2c0/research_reports/2026-10-25_v3/LPS_FORMATION_REPORT.md)

保留来源身份、只读外域路径、相同状态干预、连续读取及完整标签访问账本。替换四个并无固定功能含义的低秩块、一步虚拟 Adam 作为主要形成信号，以及不断漂移的表示与收益标签。新函数单元有两个明确身份：在哪个来源域、哪个任务标签下学习；面向哪个外域需求分布分配来源训练样本。身份是设计定义，是否形成不同功能仍要实测。

### 3.2 五种可行的重构路线


1. **先形成 whole-source 函数，再学习读取。** 每个 source/task 用自己的标签训练全表示函数，库固定后拟合目标读取器。它简单、可复现，是 DFD 的基础与强对照。若本地全表示修正已经匹配它，则不宜再把门控加深作为主要研究方向。

2. **先测目标需求，再形成来源函数——本轮主线。** 在从未参与 source-function 拟合的 P_form 上估计条件风险，得到只依赖可见特征的需求函数；随后把需求用于分配 source fit 样本给两个具有不同目标意图的函数。使用 source 的真实标签学习内容，而不是把 target 的即时标签直接写入来源参数。

3. **基于几何或任务支持形成原型。** 特征聚类、任务损失轮廓或显式群体可使来源支持更清晰，但几何不同不自动意味着目标收益不同。固定 K=2 几何形成作为核心对照；动态聚类、任意 K 搜索本轮不启用。

4. **目标条件直接写入或读写利益分离。** 若目标读取有收益，但 source 自身监督无法形成所需内容，允许 target 通过单独参数或受约束写入产生内容可能更合理。需要将 source 能力损失、target 收益、teacher 蒸馏和普通联合监督分开。10/24 I1_PERM 的 selected ranking 反证使它目前不优先；DFD 来源需求可转移性失败、但固定库读机会稳定时才重新立项。

5. **联合更新与慢速/滞后库。** 可以让 backbone 继续训练、周期更新 teacher/bank、用函数蒸馏维持身份，减少冻结造成的容量限制。但这会重新引入表示漂移、需求过期和刷新预算。本轮先固定函数库判明是否存在内容增量，不能在结果不佳时自动切换到联合训练。

### 3.3 为什么普通概率拟合应该进入核心设计


对于固定的两个候选 logit `a0,a1`，BCE 差满足

$$
d(y)=\operatorname{softplus}(a_0)-\operatorname{softplus}(a_1)-y(a_0-a_1).
$$

给定包含这两个候选预测的特征 `v`，条件期望只需要 `η(v)=P(Y=1|v)`。因此监督一个复杂“收益网络”并没有凭空增加新的标签信息。本轮直接用条件概率头解析得到需求，不另训独立收益回归器；P1只执行05登记的四种策略。主张是**怎样用需求组织来源学习**，不是“发现了超越标签的新监督”。

同理，固定 bank 的输出是共享表示 `h` 的确定函数；它携带来源监督形成的参数知识，但没有增加逐样本可观察变量。旧 L0_FEATURE 只有压缩 `u34`，所以本轮加入完整 `h256` 的本地函数、更多本地容量及相同读取器，直接挑战“只是额外非线性拟合”的解释。

## 4. 独立候选方向的比较


以下候选的科学对象不同，不是给同一个门控结构换名字。

| 候选 | 核心问题及现有依据 | 核心技术与最小判别 | 最近研究与潜在新增价值 | 主要风险、执行性与决定 |
|---|---|---|---|---|
| **DFD：需求条件来源函数** | 同域内部可预测的相对来源需求，能否组织更有用的 source 内容？普通读有机会，形成元学习不稳 | 稳定来源函数→交叉拟合需求→保持每行总权的 source 内容分配→同门读取；对比 uniform/geometry/shuffle/local | SDSP、PRP、CESAA、AREAD、STEM；待证差异是目标风险定义的 source 功能形成及跨支持转移 | source 外推可能失败；现有两数据和 cached h 可执行；**主线** |
| **共享/私有异步成熟** | 晚期恶化是否由特定写路径造成？ | 同状态四叉；若 private-only 真正优于全停与全更新，未来比较固定冻结/蒸馏与自适应日程 | STGU、AdaTask、异步任务蒸馏；差异应是参数写路径的机制识别，不是“任务不同步”本身 | 固定数据上早停强；本轮仅有界诊断，不称第二论文 |
| **支持条件下的目标与模型选择** | ML validation 用户 OOV 与 Q/test 差异，是否使选点对应不同目标人口？ | 固定所有方法，按 fit 可见支持状态分层；分解角色风险与选点排序；将来用预先定义的用户/时间 split 重评 | 推荐离线切分与 OOD 研究；新增价值若有，应是 MDMT 聚合目标与支持混合的联合分析 | 当前支持差异不是因果解释；新划分旧行不是新样本；本轮只作必须报告的边界分析 |
| **优化器路径与目标聚合** | 同 Sample 目标下的不同梯度执行路径为什么仍影响训练？ | 固定损失目标、参数写权限与 batch；分离聚合/序列次序、Adam 状态、真实位移，不能再混 Equal 与 Sample | AdaTask、GradCraft、STGU；潜在价值是路径依赖的必要条件与可部署简化 | 现有自然复核已限定 Adam 不是全部必要原因；另立严格 factorial 成本较大，暂缓 |
| **任务联合标签结构** | 任务的交集监督是否提供现有 marginal head 缺少的功能？ | 先核标签语义，再考虑 joint head，与同容量普通辅助头比较 | RecSys26 Learned Cross-Task Relationships、ESMM、AITM 已直接覆盖交叉标签和任务关系 | ML 两阈值任务存在嵌套，AND 可能退化；KR 不能从名称推断逻辑关系；当前不推荐作为新主线 |
| **有语义约束的数据干预与来源识别** | source 数据中的何种可改变因素真正贡献 target 群体？ | 仅对有已知语义/不变性假设的特征生成反事实；与等量复制、无变化数据及普通增强比较 | AREAD、因果推荐与反事实增强；潜在差异是 source 内容的机制定位 | 没有可信生成机制时，噪声不是有效反事实；历史复制/噪声不足以支持，暂缓 |

支持条件与目标聚合方向可以形成独立研究，但当前尚没有足以直接批准完整新算法的识别证据。它们在本轮作为可检验解释被保留，而不是塞进 DFD 增加模块。

## 5. DFD 的核心机制与假设链


### 5.1 三个串联但可分别失败的假设


**H1：目标需求可预测。** 固定候选来源函数，在未用于其训练的 P_form 上，基于可见特征学习的策略在折外风险上优于域任务固定混合。逐行标签最优动作、门权不同、训练误差下降都不满足这一假设。

**H2：需求能指导 source 内容形成。** 在 source 自身样本上使用 target 需求函数的预测，给两个函数分配不同的 source 监督；保持每行两函数总权为 2，从而不把总体样本重权混为内容分工。这个步骤需要跨支持区域外推，是最脆弱也最值得测的假设。

**H3：形成的内容有可部署增量。** 相同读取器、相同角色标签、相同函数数/训练次数下，DFD 比 uniform、几何与需求置换形成更好，并超过强本地方法。模型必须从 scratch 完成整个分阶段流水线；固定状态删除某一路有损只证明该模型使用了那一路。

### 5.2 具体新增能力


相对于简单共享或 MoE，DFD 不仅为当前样本分配已有函数，还把目标侧的需求预测用于定义 source 侧的训练支持；相对于一步元权重，信号作用于完整的多步函数训练，表示和需求在该阶段固定；相对于几何原型，分工依据是目标条件风险而非距离；相对于直接 target 写 source，内容标签仍来自 source，target 只通过冻结的需求函数影响样本分配。

这些都是方法定义的差异，**尚不是已经证实的新能力**。只有 H1–H3、同信息简单对照、来源替换和代价比较共同成立，才有条件形成“需求驱动的功能来源组织”的论文贡献。若普通 gate、几何形成或本地容量即可匹配，应明确缩减主张，不能用学到不同权重作替代证据。

### 5.3 为什么固定两个函数


每个来源域有两个外部目标域，因此每个 source/task 定义两个目标意图函数。K=2 来自当前三域协议中的可解释意图身份，不声称是最优 K，也不根据结果搜索 K。目标读取时可使用两个 foreign source 各自的两个函数，因此同一来源可以向不同目标提供不同功能。两个函数的输出如果没有稳定区别，允许研究结论退化为 whole-source 函数足够，而不以增大 K 补救。

## 6. 与强简单解释的对抗


| 新增机制 | 更简单解释 | 必须观察的量 | 判定边界 |
|---|---|---|---|
| 完整 h 的来源 pilot | native 之外多训练了一个 MLP | NATIVE、LOCAL、来源函数相同状态预测；训练成本 | 只胜 LOCAL、不胜 NATIVE，不算实用提升 |
| 条件需求 | 基率/置信度校准、拟合难样本 | 完整特征与 logit-only 需求、OOF 固定混合和普通 gate、支持分层 | 可预测不等于新增监督；若简单概率校准匹配，承认其充分性 |
| 目标条件内容分配 | 普通 sample reweighting | 每行两函数权重和精确为 2；实际 Adam 位移、源内标签/难度分层 shuffle | 不把梯度权重等同参数位移；shuffle 匹配则功能意图未获支持 |
| 功能原型 | 容量或随机集成 | uniform 相同微扰、几何、逐函数/来源替换，输出差与 target 贡献 | 不用参数欧氏距离或非零 gate 单独证明 |
| foreign 来源身份 | full-h 本地变换或 pooled 训练 | LOCAL_CAP 强本地与 P3 pooled 替换 | 本地替换匹配则不能声称独有外域知识 |
| 冻结稳定性 | 只是降低过拟合或提前停止 | 原生 selected/epoch24、固定 pipeline 中间结果、所有额外 pass | 本轮可证完整分阶段方法，不外推到联合训练 |

## 7. 明确的负结果出口


- P1 折外需求不优于常量：结束 DFD-v4.0 的形成扩展；报告需求在当前表示/支持/样本量下不可可靠利用。不得改成 oracle 分群或换 seed 过关。
- P1 通过而完整形成不胜 UNIFORM：说明“可读需求”尚不能跨 source 支持转成更好的知识内容；优先归因外推、功能表达或训练限制，不继续增加元学习步数。
- DFD 胜 UNIFORM，但不胜 GEOM/SHUFFLE：需求的特定语义没有独立证据；可保留一般群体专门化发现，不能写收益驱动形成成功。
- DFD 胜全部来源形成对照，但不胜 LOCAL_CAP/NATIVE：保留有限机制发现，停止实用 MDMT 优势主张。
- LL 改善而 AUC 超出预设退化边界：登记校准与排序取舍，不改用更好看的指标宣布通过。
- 所有机制与性能门槛通过：进入固定 seeds 的锁定复评及来源替换，不增加开放式超参数搜索；旧 test 仍是暴露基准。

失败后可以提出下一项研究问题，但本轮 Codex 的执行边界不包含自行发明新算法。重新启动备用路线需要新的方案版本和明确的证据依据。
