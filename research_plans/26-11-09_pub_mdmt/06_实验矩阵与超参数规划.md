# 实验矩阵与超参数规划

## 固定协议
MovieLens、KuaiRand；M3oE fixed1；Seeds 2022–2026；自然样本目标、初始化、数据顺序、batch、epoch预算、学习率和optimizer设置保持一致。Validation六格Macro AUC最早严格最大值选点。

## 核心对照
| ID | 更新规则 | EMA | 目的 |
|---|---|---|---|
| A | 普通Adam | 无 | 在线基准 |
| B | 普通Adam | 固定EMA F | 最强内部参考 |
| C0 | P0两任务PUB | 无 | 论文粒度 |
| C1 | P1六任务全局PUB | 无 | 六格粒度 |
| C2 | P2拓扑PUB | 无 | 局部共享拓扑 |
| G0/G1/G2 | 对应alpha加权原始梯度再Adam | 无 | 隔离更新空间贡献 |

所有正式候选至少五seed。A/B可复用同seed匹配结果，但必须核对轨迹和协议身份。

## 阶段
0. 审计、正确性测试，不做科学训练。
1. 权重/几何诊断：每10 step记录alpha、Gram、夹角、范数、solver残差。短诊断不作性能否决。
2. 五seed正式训练：C0/C1及匹配梯度控制，两个数据集全覆盖。
3. C2/G2拓扑版本，完成五seed。
4. 仅当PUB单独有明确收益，才测试PUB+EMA。

## 小规模搜索
alpha频率：每1、10 step；每100 step仅低成本频率诊断。CCP迭代数{50,100,200}，容差{1e-4,1e-6}。Gram相对稳定项{1e-12,1e-10,1e-8}，先按trace尺度检查。原始PUB不做候选向量归一化；归一化属于独立变体。

先在两个数据集都进行五seed低预算比较，再选共同配置完成正式训练。不得用1seed预筛选否决候选，Test不参与超参选择。

## 评价
报告六格AUC/LL、Macro AUC/LL、Traffic/Pooled、Validation/Test、selected epoch、逐seed配对差、alpha/Gram/更新诊断、求解失败率、吞吐、额外backward、峰值显存和状态内存。AUC合格需五seed平均Macro增量≥0.003且每格平均增量≥−0.001；LL独立裁定。

## 成本
PUB最多6次任务梯度抽取；论文在其AliExpress设置报告约16%额外训练时间，但当前模型/批量/数据不同，必须实测。不能以论文成本替代本地测量。

## 停止
实现错误、数值故障、资源阻塞分别记录，不能写成性能失败。P0/P1/P2完成五seed且无收益后，可停止当前迁移，不无限扩展solver或权重先验。
