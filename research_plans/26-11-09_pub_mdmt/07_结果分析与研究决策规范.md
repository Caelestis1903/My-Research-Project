# 结果分析与研究决策规范

## 证据层次
1. 实现正确性：候选更新、alpha、m/v、参数坐标和自然目标。
2. 机制现象：alpha是否非均匀、Gram结构、候选夹角、梯度空间与更新空间差异。
3. 经验性能：五seed Validation/Test六格和Macro AUC、LL。
4. 成本与泛化：backward、吞吐、显存；两个数据集及六格收益分布。

机制指标不能替代实际指标；AUC提升也不能单独证明效用假设。

## 结果解释
| 结果 | 解释 |
|---|---|
| PUB超过Adam与固定EMA且保护通过 | 具有替代固定EMA的实证价值 |
| PUB超过Adam但不及固定EMA | 更新平衡有效，但不足以替代EMA |
| PUB与EMA接近 | 比较成本、LL代价和适用条件 |
| PUB+EMA额外提升 | 两种机制可能互补 |
| PUB低于两者且alpha近均匀 | 当前候选更新几何未提供有效差异化 |
| alpha不稳定或solver失败 | 数值/条件性问题，先定位实现 |
| PUB优于同alpha梯度Adam | 支持更新空间组合有独立贡献 |
| 二者接近 | 动态权重可能是主要贡献，更新空间增量有限 |
| P2优于P1 | 局部拓扑权重可能有价值，需结合成本与逐格保护 |
| P1优于P2 | 全局一致权重可能更稳定，局部自由度无增量 |

## 效用边界
PUB优化Σlog(u_iᵀΔθ)，是更新空间代理效用，不直接最大化真实loss下降或validation/test AUC。报告u_iᵀΔθ正负、单任务短步loss变化与utility排序是否一致，以及阶段/参数组/数据集差异。

## 归因
PUB vs同alpha梯度控制：更新空间组合增量。
PUB vs普通Adam：任务权重、更新组合、moment历史总效应。
PUB vs固定EMA：竞争算法完整性能与成本。
PUB+EMA只在PUB单独有收益后判断互补性。

## 决策门
五seed平均Macro AUC差≥+0.003且任一cell平均差≥−0.001为AUC合格。Macro达标但cell保护失败时如实报告。LL平均差<0为改善。少于五seed只能记初步信号。工程/资源失败不能伪装科学阴性。

## 最小充分矩阵
Adam、固定EMA、P0、P1及同alpha梯度控制，在两个数据集各五seed；P2作为预注册拓扑方案完整保留并排在P0/P1之后。仅当PUB单独有收益才跑PUB+EMA。
