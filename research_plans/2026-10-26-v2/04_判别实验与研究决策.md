# 判别实验与研究决策

**目的：用少量有决策价值的干预，判断应保留普通读取、推进功能形成，还是调整科学问题。** 方法/数据精确语义见05。本轮设计不运行GPU；下次Codex可按本表自主执行全部被触发阶段。

## 1. 当前最需要区分的四组解释

| 竞争解释 | 现有证据为何无法区分 | 最小干预 | 结果如何改变路线 |
|---|---|---|---|
| 来源内容无当前增量 / 内容有用但读取受限 | DFD与直接头同时变了内容、训练和概率范围；H_DIRECT输入已有跨域训练历史 | 同一prefix、同一B/pilot，换PILOT_PROB/PILOT_LOGIT/FULL_SOURCE；配CAL和FULL_TARGET | 普通读即可→保留简单方法；完整源空间仍有机会→进入功能形成比较 |
| 需求可用于target风险 / 不能直接迁移到source样本 | ML P1通过但形成弱，KR完整η弱于LOGIT；outer μ遗漏 | 在真实target行估计B剩余score，不把η外推到source；比较群体A与pooled/shuffle | target风险组织有增量才保留A；没有则保留统一微调/直接头 |
| 真正形成互补功能 / 只是多了参数和目标训练 | 正权BCE非恒定未证明功能；局部删路损失不能证明多函数必要 | RCF、POOLED、LOCAL_ACTIVE，后续K1_WIDE重训+相同reader；固定群体风险矩阵 | 只target-only有效→局部拟合；K1等效→单函数；跨组互补且完整增量→保留多功能 |
| 重加权相对信息 / 常数尺度、增强或更新路径 | D权重近常数仍有收益；G−Gτ0 selected反向；历史目标/阶段不同 | 独立补Dconst01_NO_AUG并核Adam尺度桥 | 已知等价解释足够→修baseline；相对权重仍有收益才另立算法 |

这些解释可以同时成立，实验结果不必被强行归入唯一根因。不能把某个机制对照失败扩写为整个共享问题不存在。

## 2. 阶段执行顺序

### S0：身份与共同前缀

核最新main、原始hash、实际RoleBundle与fixed-fusion模型。盘点服务器工件，确认旧h/pilot/模型是否已删除。必要时只新建两数据×5201/5202四个native/pilot前缀。保存B的OOF/refit、候选源输出、φ、原生群体阈值；禁止为了恢复旧μ而重跑整个关闭版本。

**S0验收**是协议/代码/工件正确，不是AUC要好。四个prefix均应完成；某数据真正缺失时记录BLOCKED，不伪造替代数据或悄悄改比例。新方法不沿用旧DFD P1作为准入条件。

### S1：两个问题共用一次固定内容比较

执行05第3节的读取与内容控制，所有臂共用B/pilot/原生状态。主要问题：

1. 相同源输出换读法后是否有增量？
2. 来源函数是否超过同等目标监督、完整h输入和活跃容量的本地方法？

**优先对比**：PILOT_LOGIT−PILOT_PROB、FULL_SOURCE−GROUP_CAL、FULL_SOURCE−FULL_TARGET、FULL_SOURCE_ALL−H_DIRECT/H_DIRECT_EFFORT。ETA_DIRECT_MATCHED与H_DIRECT用于消除旧实现中输入/Adam历史不一致的混淆。并非每个比较都必须通过，具体含义分别登记。

S1状态：

| 状态 | 条件性证据 | 行动 |
|---|---|---|
| READABLE_SOURCE | 真source相对CAL/本地出现两seed同向的完整或预定组增量 | S2，检验功能形成是否还有必要 |
| READOUT_LIMITED | 同源加性/全隐藏读胜凸读，校准/本地不能充分匹配 | S2仍做，若普通读最终已足够则保留简单reader |
| SOURCE_SIGNAL_UNRESOLVED | 全源不胜强头，但组间响应或来源初始化有有限线索 | 仍准许一次S2三臂，避免混淆“现有内容不好”和“无法形成” |
| NO_FIXED_SOURCE_INCREMENT | 所有固定内容均无稳定增量 | 仍准许同预算的一次S2；之后不能循环增加K/seed |

这里没有要求先证明来源信息在抽象意义存在。S1只约束当前空间；S2是为功能形成预留的有界直接实验。

### S2：唯一主候选的最小形成试验

两数据×两seed，固定运行三臂：

1. RCF；
2. POOLED_TARGET；
3. LOCAL_ACTIVE。

它们共享同前缀、目标标签、普通reader和RMS预算；RCF/POOLED还同来源行为预算。LOCAL_ACTIVE不加外源保留约束，且活跃函数容量充分，作为较强目标再拟合解释。

**不等待“全部机制解释完”才实现RCF。** S1与S2可共用一次实现与前缀准备；S1输出后不由Codex临时发明新方法。S2只做当前规范一版，最多12个小后继训练包，不追加正向seed。

结果分支：

| S2结果 | 决策 |
|---|---|
| RCF比强直接头、FULL_SOURCE_ALL、POOLED、LOCAL有实用增量 | 进入S3归因；此时尚不声称来源功能机制已证 |
| RCF与POOLED相当，而二者胜强头 | 保留普通来源约束微调；RCF群体形成不成立，S3只完成必要K1/source-init归因，不扩全部矩阵 |
| RCF/POOLED仅胜弱头，不胜FULL_SOURCE_ALL | `SIMPLE_READER_SUFFICIENT`，不跑完整S4 |
| LOCAL_ACTIVE匹配或胜RCF | 目标再拟合解释保留，不能说来源特异功能成功；仍按预定来源初始化一项区分是否只为优化起点 |
| 仅预定群体有两seed一致交叉优势，macro不达实用门槛 | `MECHANISM_ONLY`；只完成K1_WIDE、POOLED和群体功能矩阵，不开四seed全矩阵 |
| 大量δ缩放至0 | 先按05区分无需求、约束强、实现/数值错误；正确实现且源约束阻止有效目标拟合→`METHOD_REDESIGN_REQUIRED` |
| 所有三臂无支持 | `NO_INCREMENT_IN_TESTED_SPACE`；结束当前形成，不否定所有共享、不自动增加K/换backbone |

“相当”此处仅指未达到预定实用门槛/方向不稳，不是统计等效结论。

### S3：只为具体主张做归因

按05矩阵实施对应子集。只有S2完整实用增量时才全跑五个新增非线性对照；机制-only等分支只跑上表指明项目。

主张与必要证据：

- **追加source监督有用**：RCF胜LOCAL_ACTIVE，SOURCE_INIT_RANDOM/source-label置乱不能完全匹配；结合FULL_SOURCE而不单靠标签置乱。
- **需求组织有用**：RCF胜POOLED与ASSIGN_SHUFFLE；实际K、目标覆盖、有效更新次数和label-pass完整记录，POOLED作为较强简单对照，不虚称总剂量相等。
- **多功能有用**：RCF胜重新训练的K1_WIDE，预定群体风险有跨seed交叉优势；不是只看删除某单元。
- **非线性重新形成有必要**：RCF胜FULL_SOURCE_ALL、SPECTRAL_K2和RRR_K2；否则降级为更简单读出/监督降维。
- **来源保留约束有意义**：ANCHOR_OFF显示有用的风险/保留权衡；同预算不自动等同相同实际保留误差，应报告源S/K的Pareto位置。
- **来源支持解释**：对所有以上比较同时报告source支持、OOV与低/高原生预测组。支持分层仅解释，不按外层标签事后筛成功人群。

不能要求每项都出现正向结果才能保留任何价值。例如ANCHOR_OFF更好说明锚可能限制了目标有用函数；可以保留source初始化的普通适配，而不声称源保留预算是收益机制。

### S4：有明确主张后再四seed与外部扩展

资源门槛以05第1节为准。**完整主线晋级**至少要求RCF在Q_explore相对H_DIRECT/H_DIRECT_EFFORT、FULL_SOURCE_ALL、POOLED_TARGET、LOCAL_ACTIVE达到既定实用门槛和保护，K1/组织/来源归因结果支持所保留的贡献层级。不存在“必须超过全部历史算法才允许研究”的要求。

冻结代码、所有λ/K/群体/预算、比较方法清单和目标主张后才启动6201–6204，并统一打开test_exposed/legacy。不能因一个seed负向而中途换方案。报告每seed、均值、不确定性、每格/每组、成本。

若来源保留在训练满足、P_cal或Q却明显超预算，主张只能是训练预算约束，不能写泛化的保留保证。冻结后可完整复评仍不得事后修改ε追阳性。外部/新数据不可得不阻断核心结论，但限制其论文级范围。

## 3. 独立SCALE最小分支

按05第8节执行，不抢占主线。先做Adam等价数值桥，再补缺失的Dconst01_NO_AUG历史配置。

- 关增强仍有收益且有效wd/eps对齐后消失：解释为优化尺度/正则比例，修正baseline。
- 关增强收益明显消失：增强套件是重要解释，进一步噪声/复制控制只复用已存在对照，不新增大网格。
- 恒权已足够、相对样本区分不增益：不以“动态权重学到了重要性”叙述。
- G仅早期收益：应研究选点/训练阶段，不能把终点或前几epoch升高当最佳质量成功。

该分支有独立科学价值，但若最终只有已知等价关系，不强行发展第二篇方法论文。

## 4. 最少充分验收与可复用结论

每阶段只核能改变判断的事项：数据/模型身份、监督角色、真正执行的梯度、源/目标功能、原始配对预测、选择与清理。

以下内容不独立触发新实验：更漂亮的热图、更多随机seed、不同簇名字、正交性、参数距离、小域是否“更难”、反复证明Adam不是唯一原因。

旧DFD自然比例与v4代码大部分已落实，不能把本轮变成重审全部历史。已缺失的outer μ如无法精确恢复，标MISSING并保留原结论边界。本轮新导出必须在清理前完成，不能重复该缺项。

## 5. 源保留、目标性能与新颖性的三层结论

1. **工程成立**：代码按规范运行、预算/梯度/数据正确。
2. **机制成立**：对应控制隔离了来源监督、群体组织或多功能增量。
3. **方法成立**：强对照、合法选点、多seed、成本和数据边界支持实际增量。

第一层不自动推出第二层；第三层也不凭一个AUC小提升倒推科学问题。若近邻机制被发现高度重合，保留可复现发现并将相应组件降为基线，再聚焦已被实际对照支持的新增能力。本文件已把H-score/RRR谱方向、普通残差读取和普通锚定微调作此处理。
