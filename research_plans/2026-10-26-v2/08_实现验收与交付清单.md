## 2. 已采纳的建设性自批判

| 初始风险 | 最终修订 | 为什么改变研究有效性 |
|---|---|---|
| 把白化/谱方向当新算法核心 | 降为H-score/RRR/GIST近邻强基线，主线聚焦预算内功能形成 | 避免数学上相近技术换名 |
| 正权BCE理论被过度套用 | 明确实际f(h)+Z的条件最优；不假定Z是h函数 | 保留加权投影可能性，批评限于无功能保证 |
| 原型槽只是两个目标域名字 | k按真实target群体剩余响应组织，可跨域共用、同域拆分 | 功能对象与域ID分离 |
| 需求外推到source没有目标真值 | 直接在真实target样本定义剩余风险响应 | 不需要虚构目标标签语义 |
| 形成用B+δ，读取却可能读F | 统一只读δ，F=f0+δ仅用于源保留 | 消除背景函数错位 |
| δ随机初始化却声称来源继承 | source隐藏复制、末层0；记录初始化/需求/约束三条来源路径 | 来源作用可具体干预 |
| 基准OOF被误当全链OOF | 后继/分配用PF，reader仅PR；FULL_ALL明确训练角色 | 不制造虚假的独立性 |
| RMS只管assigned组 | 约束所有可能foreign读取支持 | 避免未分配区域输出不受控制 |
| dual迭代被当保证 | 全量S/R验收与确定性最大可行缩放，精确0退路 | 约束失败可定位，非靠阈值叙述 |
| 空query跳步改变正则比例 | 每槽assigned-row计划+明确重要权 | 目标与实现对应 |
| target-only被多余anchor限制 | LOCAL_ACTIVE只有目标目标与同RMS，活跃容量充分 | 保证强简单解释 |
| 删除一个槽被当多原型必要 | K1_WIDE重新训练/重新读取+交叉风险矩阵 | 区分使用与不可替代 |
| 同ε被当同实际保留 | 报训练/选择/外层S/K及Pareto位置 | 不把预算符号替代实际作用 |
| 形成完立即清理 | outer候选/需求/μ/群体输出成为cleanup前硬验收 | 不重复旧信息缺项 |

## 3. 下一轮最少必要数值与权限验收

### 3.1 训练目标与样本权重

使用可手算小batch，比较逐样本显式求和与实现：
Sample分母、短末批、组条件均值、π仅乘一次、Z_k、每槽重要权、POOLED fractional A、LOW_SUPPORT后的重归一化。不能因平均loss相近就跳过梯度比较。

只核这些真实分歧，不为可逆文档/日志变化创建大量镜像测试。

### 3.2 梯度权限与初始函数

- δ末层0时前向必须为精确0，source后继初始等于f0，目标初始等于B。
- 对非退化真实小batch，delta末层首步应有梯度；隐藏首步0合理，第二/后续步可非零。
- native、source pilot、B、A和normalizer无梯度/参数变化。
- K0/未参与参数grad=None，optimizer step/m/v不增加；不要用全零tensor替代None。
- reader训练只修改reader，源/后继参数hash不变。

### 3.3 来源可行性与预测一致

人工构造可行/违反S/违反R/两者违反样例，检查缩放最大可行端、c=0、投影只影响δ；ANCHOR_OFF和LOCAL只投R。真实小batch再核一次稳定BCE/KL，不以概率先clip改梯度。

同一原始X经过完整预测器与缓存路径，FP32原生误差阈值沿用1e-6；FP64分析指标从保存的p复算。出现错误查原因，不扩大容差掩盖。

### 3.4 严格恢复

保存完整模型、Adam、dual、RNG、query与aux row position、pass、c/selection、代码/配置/数据hash。连续两步与一步后resume再一步比较参数、状态和预测。缓存身份有异必须拒绝复用。仅模型权重无法恢复Adam历史。

### 3.5 reader和选点

验证有界线性reader的实际objective、梯度、收敛残差；α是正系数，不能exp后仍宣称全凸。整组六头选点不可逐cell拼接。OFF为精确B_refit，不用极端gate近似。FULL_SOURCE_ALL的额外PF监督明确记录。
