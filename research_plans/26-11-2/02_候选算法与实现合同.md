# 02｜候选算法与实现合同

## 0. 通用定义

对当前参数 θ、同一原始 batch B，真实目标梯度 g=∇L_real(θ;B)。增强差分 δ=∇L_target_aug(θ;B,v)−∇L_target_clean(θ;B)。δ 必须来自同一 θ、同一 batch；沿用 GA31/AIGM 的目标域、Sample 权重和原始 B×T 归一化。不得以目标域样本数重新归一化。当前 Gaussian 视图只改变目标域非路由 sparse embedding，RMS 尺度 stopgrad。

所有统计门 detach；保留 coupled weight decay、Adam bias correction 和当前优化器语义。不得改变模型结构、标签、人口、Sample 总权重预算、batch 或 epoch。

## A 组：轨迹平均条件与强基线

同一 online 轨迹维护 shadow，不反馈 online 参数。每条轨迹最多 4 个 shadow，每个 shadow 每 epoch validation 一次：

1. **固定 EMA**：ML 用 H2 对应 rho=0.982820598545；KR 用 rho=.995。它们是各自数据集的强基线，不强制共用 rho。
2. **延迟 EMA**：前 5 epoch 不更新 shadow，E6 起按该数据集固定 EMA rho 更新；对照相同 rho 的非延迟 EMA。
3. **有限窗口 Polyak**：从 E31 起收集 online 参数，E31–E50 等权平均（W=20 epoch）；使用滚动和/队列，不逐 step 保存完整模型。
4. **梯度稳定性自适应 EMA（C2）**：记录 clean full-real gradient norm 的 100-step 滑动均值 μ_t 与标准差 σ_t；CV_t=σ_t/(|μ_t|+1e−12)。每 100 step 更新 rho_t=rho_min+(rho_max−rho_min)·CV_t/(CV_t+c)。ML rho_min=.95,rho_max=.995；KR rho_min=.98,rho_max=.999；c=.5。高波动对应更长平均记忆是待检验假设。该 shadow 不反馈训练。
5. **Replay 控制**：记录 adaptive rho 序列；用固定 seed 1729 打乱其时间顺序，保持 rho 值分布一致但切断与当前梯度波动的时序关联。若 adaptive 与 replay 相当，优先简单日程。

A 组用于回答平均窗口、启动和动态时间尺度问题。普通 EMA/Polyak 本身不是创新。

## B1：难度感知的增强特征选择（数据侧）

**问题与预测**：统一对所有目标域非路由 sparse embedding 加噪，可能把增强预算花在不适合扰动的样本/特征上。旧 MASK 文档提出难样本低掩码率、易样本高掩码率，但该规则尚未在当前 Gaussian 协议中验证。

对目标域样本 i，clean forward 得到两个 task 的 per-example BCE，难度 ℓ_i 为两任务 BCE 均值。每个 batch 内在目标域样本上做线性 rank 归一化得到 r_i∈[0,1]（高值=难）。按旧文档的方向设样本级特征覆盖率：
p_i=clip(0.05+0.90·(1−r_i),0.05,0.95)。
对每个目标域样本、每个非路由 sparse embedding 字段独立 Bernoulli(p_i)；仅在被选字段上施加原 Gaussian 扰动，未选字段保持 clean。dense、domain ID、标签和真实样本 loss 不变。mask RNG 使用独立 keyed generator，不消费 loader/view RNG。

**默认参数**：难度按 batch 内 rank；覆盖率范围 [.05,.95]；噪声 κ 与 A1 相同；λ=.5。训练时记录每个样本的 p_i、字段选择率、实际增强 embedding RMS 与总扰动能量。

**必要控制**：A1 全字段 Gaussian；均匀随机字段 mask，匹配 B1 每 batch 的实际字段数/扰动能量分布；均匀固定覆盖率的 mask，匹配总体平均覆盖率。控制只选最有区分力的随机匹配版，若能通过 replay 同一 mask 数量和噪声 RMS 实现则不额外训练两套控制。

**关键替代**：固定覆盖率随机 mask 更简单；若 B1 不超过随机 mask，停止难度感知机制。高 loss 不预设为增强价值，且 rank 在每个 batch 内归一化可能不稳定，必须报告分位数与跨 epoch 稳定性。

## B2：任务条件的增强冲突分量移除（梯度侧）

**问题与预测**：当前增强差分聚合两个任务后注入；若其对一个任务的方向与该任务 clean gradient 冲突，聚合可能掩盖相反任务效应。该设计只移除相对于同任务 clean gradient 的反向分量，不假设同向就等于有 AUC 收益。

对目标域两个任务分别计算同 θ、同 batch 的 clean 梯度 g_t 与增强差分 δ_t。对每个参数张量组 G（E=全部 embedding；P=共享参数和目标域预测路径；U=其他参数），在 E/P 上计算：
a_t,G = <δ_t,G, g_t,G> / (||g_t,G||² + ε)
δ⁺_t,G = δ_t,G − min(a_t,G,0)·g_t,G。
U 组不施加增强差分（沿用 AIGM U 组“无目标差分”的实测语义，若真实代码审计发现 U 有非零差分则先暂停修正分组）。合成 δ⁺_G = (δ⁺_0,G+δ⁺_1,G)/2，再以原 λ 注入 clean gradient；保留当前 Adam，不改 exp_avg 的 β。ε=1e−12，投影系数 detach。

**计算图**：同一 θ 做 target clean / target augmented 的 task-separated autograd.grad；真实 full loss 梯度 g 仍按原 Sample 目标计算。投影仅作用于 δ，不改变真实梯度、weight decay 或 loss 权重。对 E/P 各参数按完整张量聚合内积，不能先逐层归一化再求均值。

**必要对照**：普通 A1+EMA；B2 完整投影；随机投影方向控制（每参数组构造与 g_t 同范数的随机方向，固定独立 RNG，投影掉同等平均范数分量）；固定比例缩小 δ 的剂量匹配控制。若随机控制成本过高，优先固定比例缩小控制并从训练统计中冻结比例。

**关键替代**：直接减小 λ 或固定衰减增强，比梯度投影更简单。若 B2 与匹配减量控制相当，保留简单缩放；若 B2 只改善某个 task，结论限定该任务。方向一致性不作为晋级结果，只作为机制诊断。

## B3：等剂量延迟增强日程（数据/时间侧）

**问题与预测**：增强在训练早期可能改变模型表征形成过程；AIGM01 已显示 EMA 时间尺度具有早期滞后差异，但尚未证明增强也有相同现象。

A1 常量 λ=.5 为参考。B3 前 5 epoch 不启用增强，E6–E50 使用 λ=0.5×50/45=0.5555556，保持按 epoch 计的增强总权重预算相同。增强 κ 不变，样本和视图数按原训练协议。所有 epoch 仍执行完整训练。

**匹配控制**：同样 5 个 epoch 关闭、45 个 epoch 启用，但关闭 epoch 固定 seed 1729 随机选取并预先冻结；该控制保持总剂量与启用 epoch 数一致，只改变是否延迟。若随机日程与 B3 相当，说明结果更像时程敏感而非早期特定效应。

**替代**：常量 λ=.5 最简单。若 B3 无稳定增量，不再试 10/15 epoch 多组日程；只有开发结果达到探索保留门时才允许一个预登记延迟 10 epoch 的 trial。

## C1：最佳 B 候选 + 固定 EMA

将开发阶段唯一晋级的 B 候选（优先级 B2、B1、B3）与 A 组固定 EMA 组合。该组合不另造新优化器；使用 B 候选本身的 online trajectory 与其 shadow EMA。比较：
- 同候选 online；
- 同候选 + 固定 EMA；
- A1 + 固定 EMA；
- 若 B 候选相对 A1 的增量不成立，则不把 EMA 的收益归给 B 候选。

只有一个 B 候选进入 C1；不得对三个 B 候选全组合。

## C2：梯度稳定性驱动的自适应 EMA

这是独立时间机制，不依赖 B 组成功。公式、参数和 replay 控制见 A 组第 4–5 条。比较 adaptive EMA、固定 EMA、延迟 EMA、SWA W20、replay-rho shadow。自适应 EMA 只作用于评估参数，不回写 online；若与 replay schedule 相当，停止自适应信号主张。

## 通用实现开关与正确性测试

每个组件独立配置开关：augmentation_enabled、difficulty_mask_enabled、task_conflict_projection_enabled、delayed_augmentation_enabled、ema_enabled、delayed_ema_enabled、swa_enabled、adaptive_ema_enabled。关闭组件必须严格退化到对应 A0/A1/固定 EMA 行为，不消耗其额外 RNG 或梯度计算。

必须测试：g/δ 同 θ 同 batch；投影后 <δ⁺,g> 不小于负容差；投影系数为负时只删除冲突分量、为正时 δ 原样保留；两个 task 独立计算后再合并；weight decay 不进入 δ；mask 不改变 clean 分支和标签；B3 的累计 λ 权重预算等于 A1；EMA/SWA shadow 不反馈 online；checkpoint/RAM restore 后下一步及 shadow 更新一致；关闭开关后梯度/参数与既有参考逐位或按已登记浮点容差一致。
