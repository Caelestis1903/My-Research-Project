# 01｜证据与问题优先级

## 1. 最新实验结论（以 26-11-01_v3 为准）

AIGM01 完成 56 条唯一完整训练、2800 epoch、96600 次参数更新，训练失败/OOM 为 0。正式比较保留 A0、A0+EMA、普通增强 A1+EMA；固定 SAD 和 AIG-M 停止在开发阶段。

| 现象 | 当前结论 | 强度与决策 |
|---|---|---|
| MovieLens EMA | selected test macro AUC +0.003849，5/5 seed 正向；LogLoss +0.001249，4/5 恶化 | 排序收益 STRONG；保留为强基线，报告损失代价 |
| KuaiRand EMA | AUC +0.004616，4/5 正向；最大域两任务均 5/5 改善 | 当前协议可用，证据 MEDIUM；保留 .995 |
| 普通增强 | ML 相对 EMA AUC +0.000318、2/5 正向；KR +0.001476、3/5 正向，但最大域两任务明显下降 | ML 不晋级；KR 是收益/损害交换 |
| 固定 SAD | 两数据集有限搜索未达到增量门 | 停止当前版本扩展，不重开 β/λ 网格 |
| AIG-M | ML 最佳开发增量约 +0.000260；KR 两 seed 方向相反、均值约 0 | 停止当前版本；不能把门非零或 q 非零写成有效信息 |
| 创新量信号 | 门改变更新，平均 λ 非零，但缺少平均剂量/时程匹配控制 | 预测效用仍 WEAK；优先检验“信号选择”是否超过剂量匹配控制 |
| 域规模 | KR 小域有局部收益、大域损害；ML 难度与规模排序不一致 | 不使用“小域=难域”假设 |

### 必须继承的解释边界

1. ML EMA 的 AUC 排序收益是已接受经验结论，不因新候选失败而归零；LogLoss 代价必须同时报告。
2. KR 普通增强相对 EMA 的 macro 增益不能掩盖 d1t0/d1t1 的稳定损害（均值约 −.00465/−.00493）。
3. AIG-M 的失败否定的是当前注册公式/参数/协议的推进资格，不是所有梯度识别、梯度修正或历史状态机制。
4. AIG-M 没有与动态门平均注入剂量匹配的固定/回放控制。本轮优先区分“信号选择有效”与“只是减少/重新安排增强剂量”。
5. EMA 是参数轨迹平均，不能推导出修改 Adam 的 exp_avg 一定有效；两者训练反馈位置不同。

## 2. 历史机制的真实可复用程度

### MASK

PROJECT_ARCHITECTURE.md 记录旧 mask 分支的高层实现：稀缺域样本复制、Phase 2 随机替换 movie_id、仅对增强样本做样本级特征掩码；难样本掩码率低、易样本掩码率高，概率公式为：

p_mask = clip(b + (1−2b)(1−ℓ_norm^(1/τ)), 0.05, 0.95)，b=0.3。

掩码只作用于 Phase 2 随机替换样本，不作用于真实样本。旧分支还包含 VUG、DBO 和三阶段训练。当前 main 根目录没有完整旧 mask/ 源码包；10-21 复现档案能核实 Gaussian embedding noise 的实际代码，但不能据此声称恢复 VUG 或旧自适应 MASK 的完整实现。旧分支历史 AUC 有配置身份/日志完整性问题，不能当成当前协议基线。

因此 B1 是“按旧文档机制重新定义的难度感知增强特征选择”，不是旧 MASK 的逐行复现。若 Codex 在历史分支找到完整配套代码，只做只读差异审查，不阻塞其他候选，也不得直接移植旧三阶段训练或 DBO。

### Polyak / EMA

PROJECT_ARCHITECTURE.md 记录旧 v2_momentum 的 PolyakAdam(0.995) 在旧 MovieLens 协议六 seed 上 mean +0.004022，36/36 cell-seed 正向；KuaiRand 没有同等收益。旧 v2_momentum 原始 RESULTS/log 文件不在当前可核验工作区，不能复算该数字。当前 AIGM01 已有可核验 EMA shadow 实现与完整结果，直接复用当前 shadow 更新/验证接口。普通 EMA/Polyak 是强基线，不作为本项目创新。

### 其他历史约束

- 旧 v1_momentum 的分层 β 与域课程依赖“共享组件慢、gate 快”“d2 是难域”等先验；本轮不复活这些未经当前协议支持的假设。
- 旧 CAM 在历史总结中表现有害；本轮的任务梯度冲突修正不等同于旧 CAM 的全局投影。
- 基础 Adam lr/wd 已做有限校准，本轮不重复大网格。
- 新候选开发 seed 2022/2024，确认 seed 2023/2025/2026。确认 seed 属于既有 seed 池，不称为全新数据独立确认。

## 3. 问题优先级

P0：增强差分是否存在可被低成本规则保留的任务相关信息？首要判别是 task-wise conflict removal 是否超过同剂量固定/随机控制。

P1：增强在样本/特征/时间上的选择，是否优于简单固定增强？难度分数仅是候选选择依据，不预设其是真实“价值”。

P2：参数平均的收益是否只由固定窗口决定？在 EMA 基线上，延迟启动、有限窗口和训练梯度稳定性调节是否有额外价值？

P3：收益是否局限于目标域/任务？尤其 KuaiRand 最大域保护项和 task0/task1 方向差异必须单列。

## 4. 必须停止的不存在/未经支持的假设

- “梯度差分与真实梯度同向就一定提高 AUC”没有逻辑必然关系；alignment 只是可测试筛选规则。
- “高 loss 样本必然更值得增强”没有证据；旧 MASK 文档采用难样本低掩码率的反向规则，也只是设计假设。
- “增强门控的非零输出代表有效信息”不成立。
- “更长动量/平均窗口总能更稳定且更好”不成立；KuaiRand EMA 有明显早期滞后。
- “小域就是难域”不成立。
- “更多反向传播总能得到更准确收益估计”不成立，额外计算必须换来可辨识的实验问题。

## 5. 本轮决策

保留 EMA 作为强基线；停止当前 AIG-M/SAD 扩展；实际检验数据侧难度感知选择与梯度侧任务冲突修正两种机制；dose-matched schedule 作为低成本替代解释；时间机制与 B 候选分离评价。无需等所有机制被完全解释才接受稳定经验结果。
