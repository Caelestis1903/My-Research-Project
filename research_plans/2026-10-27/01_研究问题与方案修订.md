# 研究问题、继承与最终修订

## 1. 总体评价

上一轮研究已经正确区分了来源知识、目标需求、读取适配、功能形成与容量选择，F0→F1也是合理的递进。但报告仍把若干改变算法语义的决策留在概念层：二叉与平坦门控混用、需求预测器未定型、来源标准化后的教师偏置、冷启动退出方式、局部冻结范围、优化器提交、模型选择指标及对照容量。它适合作为研究设计基础，不能原封不动当作已闭合执行规范。

本次保留三个问题：已有读出适配后是否仍有可预测需求；目标风险能否在来源约束下形成有用函数；真实增长是否超过简单继续训练和普通容量扩展。**可预测需求、来源增量及跨任务复用均是待验证假设，不是不存在的条件。** 反之，推理时真实标签/共享收益、已删除的历史状态、未定义的来源归属，都不能被假定可用。

## 2. 仓库事实及其使用边界

以下基于固定main和原始阶段报告；路径及链接见09。

| 阶段 | 可以继承的事实/机制 | 不能外推的结论 |
|---|---|---|
| 10/24 B/C/I | 读写分离；I1有正式轨迹；复杂控制未建立普遍优势 | 未执行分支不能记作失败；关闭通路不自动意味着代码bug |
| LPS-v2/RHD-C8 | 固定几何来源单元、收益读取；共享更新动作的同状态探测 | K4未稳定优于K1不证明所有多原型无效；候选局部树生成后被收缩不等于从未建树 |
| LPS-v3 | 目标风险通过元分配影响来源块训练；四rank4加和与rank16等价检查 | 有超梯度不等于目标标签直接形成新函数；晚期风险减损不等于最佳选点收益 |
| DFD-v4 | 来源标签加权形成、条件读取；ML读取需求有有限线索，形成增量未晋级，KR早停 | 其失败不否定不同监督路径的目标风险形成；模型缓存已删除不能假定直接续训 |
| RCF | 目标风险训练来源后继、来源保持、强完整读出及低秩对照 | 是设计阶段；这些机制不能重新命名为本次首创 |

DFD报告给出的ML CONST−DEMAND开发LL均值约0.001089350，而完整DFD相对H_DIRECT的开发LL更坏约0.001639660。它支持“读取差异与内容形成尚未接通”的研究问题，不证明必须分裂。当前没有D2内只能靠新增函数解决矛盾的确认性证据。

## 3. 逐项审查与修订

| 原报告机制 | 判断 | 最终选择与可检验替代 |
|---|---|---|
| U=0、不同V的K2 | 输出相同不意味着梯度永远相同；但不保证功能分化 | 先reader预热；保留零U/独立V，不人为强制多样性；比较WIDE和功能干预 |
| 固定K2与rank8 | 常数q时两个rank4可精确拼为rank8 | 配对初始化基底；动态q才增加条件组合能力，仍须同容量对照 |
| 普通BCE reader | 能优化当前组合，不输出脱离集合的因果收益 | 保留；收益解释限定为风险训练、结构差值及匹配干预，不额外堆gain网络 |
| F0/F1门控不统一 | 会使结构比较混入前向类别变化 | 都使用来源/null门＋二叉树；w跨同源叶共享 |
| source教师与标准化 | 缺bias或clip会改变teacher | 保留native z和输出bias；phi不clip，仿射变换head使logit精确保持 |
| source KL与RMS | KL只保持两任务读出；总体RMS可能掩盖局部偏移 | 每叶每源任务风险及源/各foreign域RMS；记录独立gamma_LL和gamma_RMS |
| 来源归因 | 源初始化并不能证明正迁移 | 同容量TARGET_ONLY、强DIRECT、追加pilot联合标签置乱PERM |
| 条件梯度 | 单样本含标签噪声，且门或w为0会遮蔽需求 | 预测条件均值、限支持和时间稳定性；另设每来源最多一次REACTIVATE |
| 需求回归及分组 | 原报告接口不够确定 | 当前r32上的两折ridge，OOF均值KMeans2，完整ridge＋中心差精确编译成一个仿射节点 |
| 历史梯度平均 | V/trunk改变后坐标不再对应 | 每窗重算；仅比较固定请求上的分区ARI，不混合跨坐标向量 |
| 冷启动 | 只设w非零而rho仍0不够；强制门验收会虚高 | 短期正通路→训练输入bias校准→恢复普通门→持出验收，拒绝仍记成本 |
| 固定新q | 冻结节点参数但trunk仍动，q输出并不固定 | 两分支前半局部步共同冻结trunk，split还冻结新节点 |
| 局部父子更新 | 其他轻量函数可能有更好继续适配机会 | KEEP/ALT都训练整个轻量bank和reader，均fresh Adam；NO_GROW独立闭环 |
| 分裂锚定质量 | 重新平均1/K会改动其他叶约束 | 子叶继承父alpha/2，来源总质量不变 |
| 回滚/合并 | 没有现有证据证明首版必须 | 暂不实施；真实增加物理叶，不把掩码激活称增长 |
| 两seed门限 | 逐seed全部过线过于机械 | 平均实用价值或双seed局部互补可推进；不确定性允许全campaign一次有界修订 |
| 外部正式基线 | 原清单缺完整统一实现合同且预算分散 | 本轮锁定内部强匹配控制；不冒称已复现外部模型或建立SOTA |

## 4. 理论依据及不能成立的推断

BCE对logit导数p−y在最优条件概率处仍有单样本噪声。按真实标签梯度分群可能得到不可部署的两簇。两个任务标签方向相反也可能由相反head读取同一个h解决。因此负余弦既不充分，也不必要。

固定读出、共同正定局部曲率H、来源约束未激活、可部署群体c及局部最优扰动可行时，分别更新与共同更新的二次近似差为

\[
G=\tfrac12\sum_c\pi_c\|\mu_c-\bar\mu\|_{H^{-1}}^2,
\quad\mu_c=E[g\mid c],\quad\bar\mu=\sum_c\pi_c\mu_c.
\]

这是由最小化muᵀDelta+DeltaᵀHDelta/2推得的提议动机，不是Adam、软门、非线性训练及源约束下的增长保证。真实接受必须看KEEP对照。

对只依赖x且严格正的冻结权重w(x)，无限容量的来源加权BCE最优条件概率仍为P_source(y=1|x)。权重能改变有限模型的重点与优化，却不能仅凭权重不同保证不同条件目标。本版比较来源监督形成与目标风险形成，不把两者混为同一监督路径。

所有后继均是冻结h的确定函数，不创造h之外的观测信息。潜在价值来自有限目标样本、函数族与优化预算下更容易访问的来源监督基础。两个source任务读出不约束64维所有信息，源支持外也无保留保证。

## 5. 与近邻的差异定位

本节继承上一轮全文/代码审查，补核出版与作者资料；证据不足处保留限制，不由摘要缺项推断某机制不存在。

| 近邻 | 已有覆盖 | 本版拟检验的具体增量 |
|---|---|---|
| RCF（仓库设计） | 目标风险形成、来源保持、强读出、有限预定需求分组 | 跨任务共用向量库、推理可识别的非预定需求、真实各源K；TASK_BANK只检验库归属，不冒称完整RCF复现 |
| PRP，MM2025 | 直接MDMT多原型表示投影；作者部分代码可见固定K | 不把“多个原型/任务条件”当差异；须检验目标功能形成和数量选择。全文/完整实现不足，不能断言其没有目标监督形成 |
| M2R，RecSys2026 | 官方摘要已提出域内异质性、联合监督隐式场景、LoRA专家 | 动机高度接近；动态K及精确梯度路径尚缺全文证据，保留新颖性边界 |
| MASS，AAAI2026 | 梯度漂移触发专家扩张、复制与差异训练、适应路由、收益式留存 | 来源预算下可预测MDMT需求、跨任务复用、先刷新reader且对KEEP验收；不声称复制/收益验收首次提出 |
| AutoIFS，WSDM2026 | 低秩场景/任务信息单元及实例条件信息流选择 | 学习可复用的新函数与真实容量改变，而非仅四类预设流选择；必须胜强READ及target-only才有实用价值 |
| CDC / SDSP | 来源组合条件下的收益，或几何筛选结合验证反馈 | 继承集合依赖认识；函数收益必须注明共同函数集合和reader再适配预算 |

参考入口：[MASS全文](https://arxiv.org/html/2512.19765v1)、[AutoIFS全文](https://arxiv.org/html/2512.13396v1)、[PRP作者部分代码](https://github.com/ljy2222/PRP/blob/dee4a320e27f3758f8a17f4a4b9ba78ed90a6693/scenario_wise_rec/models/multi_domain/prp.py)、[M2R官方摘要](https://recsys.acm.org/recsys26/posters-3/)、[CDC](https://arxiv.org/html/2507.06877v1)、[SDSP](https://arxiv.org/html/2505.20227v1)。M2R链接本次复抓未成功，沿用上一轮官方摘要级证据，不声称本轮取得全文。

MASS-inspired trigger只在04规定的有限机制桥中启用，未复制CPD、原专家梯度投影、top-p、删除等完整机制，因此不得写成完整MASS复现或据此排除原MASS能力。

## 6. 可验证贡献与退化路线

拟议贡献是：在强读出之后，把可预测的域×任务局部需求转为受来源风险预算约束的共享函数，并在继续训练、固定K及宽函数可替代性的竞争下决定是否增长。来源归因、实际功能互补、跨任务复用和成本收益均需要实验；现在只能声称提出了一套闭合、可检验的设计。

若READ足够，保留读取；若WIDE足够，保留宽函数；若TARGET_ONLY足够，保留目标适配而收缩来源迁移主张；若F0有效而F1无增量，保留固定K。需求连续而非离散时，候选C的连续基底值得下轮研究，但不在本轮无限加入稀疏网络。无新增长证据不等于证明所有多原型思想无效。
