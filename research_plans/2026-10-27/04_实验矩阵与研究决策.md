# 实验矩阵与研究决策

本轮为机制可辨识的MDMT功能形成/结构增长实验，不是已完成结果。阈值是预先资源分配与实用尺度，不是统计显著性或方向真伪的定理。两开发seed不逐一强求同一小阈值，允许整体或局部证据推进一次有限研究。

## 1. 研究对象、数据和指标

固定融合M3oE、共同冻结表示h、强基准B之上的增量是研究对象。区分追加source监督、目标函数形成、条件多函数与宽函数、结构增长与额外训练机会。自然ML/KR，三域两全观测任务，精确行合同按03；不人为改变采样比例。

T0训练native/B/pilot并提供源锚；F训练bank/reader/需求与局部分支；S五片仅结构验收；Q仅开发路线和干预判断；V仅选完整checkpoint；E/legacy锁定后历史复评。现有CSV边界不是经验证user-disjoint或严格时间外推，旧test不称新独立确认。各角色natural权重用各自实际域/请求数，不能拿F分布替换E分布。

主训练自然BCE；V macro LL最小选完整模型，差≤1e−12取最早。stage1与正式CORE候选BASE_OFF、WARMUP_END、pass5…20；stage2与正式DYNAMIC全部方法候选pass15…20。必须完整训练20pass并单列pass20。macro AUC、macro LL、natural LL、按格请求数加权cell AUC、六格与最差格均报告；pooled AUC另命名。单类AUC=NA。

开发seed3101/3102，正式6101/6102/6103/6104。3103只允许第8节唯一不确定性桥。seed才是训练随机性重复单位，不把六格/epochs当额外seed。正式报告每seed差、均值、SD及区间，配对预测bootstrap1000次仅描述样本不确定性：ML按原user簇，KR按row并说明未知用户相关性；同row两任务共同抽，不反馈方法选择。

## 2. 共同前缀和阶段1六臂

前缀native24T0 epoch、pilot12T0 pass、B20T0 pass按03。各臂同B与完整F目标标签；1pass reader预热＋20formation、batch2048、同Adam。DIRECT/TARGET_ONLY预热训练整个新增残差头，其他方法冻结bank预热reader。source root、B、native均冻结。

| ID | 精确定义与梯度路径 | 可训练参数 |
|---|---|---:|
| DIRECT | 六个258→40 ReLU→1残差head加B；hidden Xavier/bias0、末层0；F训练整个head，无source | 62406 |
| READ | 每source固定phi；router宽43，source/null/w/a定义同02；F只训练reader，无bank形成 | 12302 |
| SOURCE_K2 | F0结构；F只训练reader，bank输出detach；bank训练来源BCE＋KL及同约束 | 12525 |
| F0 | 每source两rank4向量后继，共同task库，F直接形成bank，KL/风险/RMS保持 | 12525 |
| WIDE | 每source一rank8后继、无节点、其余同F0；V初值stack对应F0两primitive | 12426 |
| TARGET_ONLY | 单个共享条件263→47 ReLU→1残差加B；F训练全头，无source；末层0 | 12456 |

DIRECT和TARGET_ONLY不是重复定义。DIRECT是更强简单对照且其增量部署参数接近F0：F0还要49344冻结source隐藏，总61869；不能只报12525掩盖前缀。B49926、native另计。READ把相近增量训练参数预算给更宽条件reader。WIDE差99个真实node参数，不能补dummy；逐叶源约束与宽函数整体约束也不同，不冒称严格函数等价消融。

SOURCE_K2：每source从T0_s固定无放回取min4096个phi，以KMeans2（kmeans++、n_init10/max_iter300/tol1e−4、具名seed）拟合固定中心，全部T0_s最近中心硬责任c_s(x)，距离平局取小ID。空簇保留并报告，不重抽。源BCE为

\[
L_{src}=\sum_s\nu_s\frac1{2|A_s|}\sum_{i\in A_s,t}
\ell[y_{it},z_t+c_{st}+v_{st}^\top f_{s,c_s(x_i)}],\quad
\nu_s=|T0_s|/\sum_u|T0_u|.
\]

每步loss=reader的F BCE＋系数1的源BCE＋共同KL；源BCE使用同256/source anchor，按天然硬责任不均衡簇。每叶仍接受KL与完整风险/RMS约束。目标reader仍自由条件二叉路由，不能将目标读取也固定成source几何而制造弱对照。

每数据两seed六臂，共24条主适配轨迹。唯一共同前缀另计，不重复训练身份相同的native。禁止用有利E结果挑方法或checkpoint。

## 3. 功能分析：不能只用去模块AUC

对每个拟判断F0/F1的V选中状态，冻结bank与全部前缀，进行至多四次匹配reader再适配：fresh reader Adam、同F行计划、R=min(32,ceil(F/2048))步、固定终点，无V选refit。源gate/w/a/已有node/trunk均reader可训练；bank不变。学习率与母方法一致。

| 状态 | 干预 |
|---|---|
| FULL | 完整bank |
| ALL_ROOT | 所有f替换其phi，保留全部概率质量、路由和读出 |
| CUT_0 | 只把预先选定节点左侧所有后代f替换phi |
| CUT_1 | 右侧对应替换 |

不重分配被移除质量，不把reader归零。BASE_OFF/WARMUP_END或全部U范数≤1e−10没有内容形成证据，跳过重复refit并作精确等价记录。没有split的F1只做FULL/ALL_ROOT，不捏造左右组。

群体选择只用F/S，不读Q风险：F0选择两个开发seed完整foreign F上平均rho最大的source s*，平局小ID；每seed选中node的q≥0.5分组。保存每个formation pass同4096F panel路由；选中p与p−2同row/task的ARI≥0.5且非恒定单组，才称稳定。正式F0沿用开发s*。

F1取轨迹最早接受split的node（事件、source、node顺序破平局）；用所选checkpoint该node分组，左右CUT作用于现存后代。比较p与p−2同node，p−2尚不存在则LOCAL稳定性不足，不换节点或晚期checkpoint凑条件。

群体在refit前冻结，评价Q时两个组各≥200请求、正负各≥30、至少两个域任务格各≥50；不足记INSUFFICIENT，不搜索其他source/阈值。增长本身使用LL支持规则，不把此更严格的功能证据门暗加到所有增长上。

G_form=macroLL(ALL_ROOT)−macroLL(FULL)。单seed正形成证据须选中formation状态、G_form≥0.0001且natural差≥−0.0002。delta_gk=LL(CUT_k|g)−LL(FULL|g)。LOCAL互补须形成、支持、稳定都满足，且存在a∈{0,1}：delta_0a、delta_1(1−a)均≥0.0001，并各比同组另一分支delta高≥0.0001。只交换两组名称，不搜索其他群体。该条件是本轮明确的局部机制标志，不是所有多原型必需的全局理论。

跨任务复用：同一物理分支k在两个task上，各至少一个既定g的delta_gkt≥0.0001，且group×task≥100请求、正负各≥30。完整展示2组×2分支×2task，不只报正项。它说明局部函数收益，不等于共享库优于任务私有库，后者靠TASK_BANK_MATCHED。

正式前先仅用F确定群体、生成四套refit状态并锁hash，再在E/legacy评分；E不能触发另一套群体/refit选择。所有refit/评分计真实成本，但不作为额外可挑选主模型。

## 4. 阶段1推进规则

对每数据独立：C*为DIRECT/READ/WIDE/TARGET_ONLY中两seed平均Q macroLL最小者，tol1e−6再按平均实际完整训练时间较少、方法ID字典序。C0同规则在DIRECT/TARGET_ONLY选。身份写入STAGE_DECISIONS后冻结。

对M相对C，DeltaLL=mean_seed(LL_M−LL_C)，DeltaAUC=mean(AUC_M−AUC_C)。GUARD要求natural LL伤害≤0.001、macroAUC差≥−0.0005、六格最大平均LL伤害≤0.003；NA使对应条件INSUFFICIENT。

PRACTICAL=GUARD且满足任一：Delta_macroLL≤−0.0005；或Delta_macroAUC≥0.0005且Delta_macroLL≤0.0002。每seed方向和极端格仍完整呈现，不要求两seed各自超过阈值。

依次取首个状态（F0对C*）：

| 状态 | 条件 | 下一步 |
|---|---|---|
| GREEN | PRACTICAL且至少一seed正形成证据 | 允许阶段2；登记来源归因 |
| LOCAL | 非GREEN，GUARD且两个seed均LOCAL互补 | 允许阶段2，注明整体收益未建立 |
| AMBER | 非以上；任一seed实用/LOCAL，或GUARD且任一正形成，或平均实用但无形成，或第8节约束/振荡信号 | 仅允许全campaign一次受控机制桥 |
| STOP_CORE | 其余 | 不启动F1；判断简单来源路线或停止正式训练 |

收益若仅来自WARMUP/OFF或ALL_ROOT已能替代，不以总体数字给F1无条件通行。阴性首先定位读取/形成/分组/结构哪个环节，不直接否定原始思想。

## 5. 阶段2六臂和增长价值

每获准数据六方法×两seed最多12轨迹，两数据上限24。全部采用phase2日程：pass4刷新诊断、6/8/10/12/14窗口，whole-lightweight fresh Adam与KEEP，V仅15…20。

| ID | 定义 |
|---|---|
| F1 | K1起步，02需求提议、保函数物理split与S验收 |
| FIXED_PROFILE | 取同seed F1 post-pass14的K_s/树形，fresh U=0、独立V、节点0.5从头训练，不复制学到的函数/门 |
| WIDE_PROFILE | 同profile每source单rank4K_s，初V按FIXED_PROFILE primitive stack |
| NO_GROW | 独立K1完整闭环，禁split但保留刷新、重启、KEEP、REACTIVATE |
| GEOMETRIC | 仅换为02当前r32几何提议，其余支持/预算/状态/S验收不变 |
| TASK_BANK_MATCHED | 按F1 profile每source/target-task独立K_s个rank2叶；2N叶，函数参数512N，node参数66(N−3) |

TASK每私有叶仍保护两个源teacher任务，KL额外除以两个task库；各库alpha和1，逐叶硬约束不平均。它是RCF式库归属机制控制，不是原RCF完整复现。固定profile看过F/S得到架构，是有架构信息的静态强控制；分别报告独立训练和继承搜索费用。

各来源臂允许同资格REACTIVATE，优先于split且不增K；不会因为READ无bank就禁止其重新打开source。静态臂无需运行不适用的U梯度公式，但执行同读出刷新与KEEP。所有候选拒绝成本照计。

C_dyn为FIXED_PROFILE/WIDE_PROFILE/NO_GROW中两seed Q macroLL最优，平局同第4节。DYNAMIC晋级须F1对冻结C0通过GUARD、至少一seed真实接受split、至少一seed正形成，且满足：对C_dyn PRACTICAL；或对C_dyn GUARD且两seed LOCAL；或效率路径。

效率路径：相对C_dyn平均macroLL伤害≤0.0002、macroAUC伤害≤0.0002、GUARD，独立完整训练时间≤对照90%，推理p95≤对照110%。完整训练时间包含必要prefix全部训练/选点、完整20pass及所有失败/候选，不能只计到最后选中checkpoint。不能单方面加给对方F1架构搜索费制造90%优势。若两seed都不split，不可宣称动态增长成立。

## 6. 来源增量PILOT_PERM

开发最多每数据一个母方法×两seed=4轨迹。F0 GREEN/LOCAL优先归因F0；否则唯一桥结束后，在相对C0有PRACTICAL的READ/SOURCE_K2/WIDE中按Q规则选一个；没有来源收益主张就不注册。不能用F0的PERM结果冒充F1的归因。

每source T0内固定索引置乱双任务标签向量，保留联合分布/嵌套，不跨source或独立打乱task。重新训练同预算pilot和自己的phi/teacher，native与B保持真实前缀。F目标以及Q/V/E标签不变。

**PERM所有T0源BCE、源风险硬约束、投影都使用固定置乱标签视图**，KL用自己teacher，不能通过真实T0投影偷偷加回source监督。S来源安全审计仍用真实标签相对自己的teacher。F1母方法的PERM独立运行自己的结构决策，不强制真实F1结构。

TRUE−PERM平均macroLL≤−0.0005且GUARD记实用来源对齐证据。不同teacher可行域和K应披露，这是完整追加source监督对齐路径，不是控制所有中介后的纯知识量。native仍含真实跨域监督，PERM不是完全无source系统。若无优势，保留目标条件学习结果但收缩source正迁移主张。

## 7. 同曝光、同时间和费用预算

主表为相同20个普通F pass，但额外窗口曝光另列，不能写成完全同更新数。每dataset开发总同步墙钟上限为其实际一次完整24epoch-native时间的20倍，含前缀、失败/重启、投影、CPU需求预测、全部ALT、S评分、干预及通用分析。达到上限诚实STOP_BUDGET，不改时间账。

每F1轨迹需求诊断加ALT费用≤自身普通formation1…3的pass时间中位数×10；达到后不再ALT，若总预算允许继续必需KEEP。reader刷新/KEEP不在该额外上限内，但总成本绝不删除。参数上限每source4/global8。

对动态阶段另报告等适配时间视图：FIXED_PROFILE/WIDE_PROFILE/NO_GROW/C0/READ沿同一轨迹从pass20继续，最多pass60，无新窗口，直到自身适配成本接近同seed F1完整20pass训练＋刷新＋所有KEEP/ALT＋投影＋S审计成本。排除共同prefix及通用V/Q/E/导出/report计分，源约束和结构评价属于算法成本不能排除。完整系统成本另报。

开发C0/READ若来自stage1，就延续已有轨迹，不倒补过去phase2窗口；正式DYNAMIC七臂才统一phase2日程。时间预算先锁定，再注册额外完整pass终点，最后访问V选择等时间视图；保留原20pass结果不覆盖。只允许未超上限的完整pass checkpoint；超时最后pass不入候选但费用照计。控制原20pass已比F1贵则记不可比，不能悄悄缩短训练。

raw-X端到端时延包括native、B、source隐藏、实际叶和reader，batch1/256，50warmup＋200测量，p50/p95与峰值显存。缓存适配速度另列。共享prefix campaign只计一次，但独立方法成本包含其必要前缀。

## 8. 全campaign唯一一次机制桥

最多一个数据、一个类型、至多4条新增主轨迹；不重复换阈值直到成功。先按类型优先SOURCE_LL_RELAX→RMS_RELAX→LOWER_LR→SEED_UNCERTAINTY找合格AMBER数据，再按类型严重度最大、平局ML优先。锁桥类型/数据/run IDs后才能训练。若四类均无触发，名额保留给阶段2后的MASS_TRIGGER。

来源/幅度绑定诊断用F0两seed pass11…20：分别统计独立gamma_LL或gamma_RMS<0.95且与实际最小gamma相差≤1e−6的比例b；实际gamma<0.5比例c；固定F panel平均投影后−前natural LL=D。触发b≥0.5,c≥0.25,D≥0.0001；严重度b*c*D。

| 类型 | 触发/唯一改变 | 新增轨迹 |
|---|---|---|
| SOURCE_LL_RELAX | source绑定；训练epsilon .001→.003，S审计联动2epsilon=.006 | 同data F0/WIDE×3101/3102=4 |
| RMS_RELAX | RMS绑定；所有支持RMS .5→1 | 同上4 |
| LOWER_LR | 无前两类，任一seed pass14…20的6个F-panel相邻LL差至少2正2负且中位绝对差>.002；score取两seed最大值。所有轻量预热/形成/local/refit lr .001→.0003，prefix不改 | 同上4 |
| SEED_UNCERTAINTY | 无前三类；任一seed实用/LOCAL，或GUARD且有形成，或总体实用但形成不足。score=两seed相对C*的macroLL差之差绝对值 | F0和冻结C*在3103，共2＋新prefix费用 |
| MASS_TRIGGER | 名额未使用，stage2两seed F1合格需求split提议均0，GEOMETRIC至少一seed接受split且对NO_GROW PRACTICAL；score=平均NO_GROW−GEOM Q macroLL | 同data trigger×3101/3102，共2 |

前3桥F0须对修订WIDE和冻结原C*同时GREEN，或对二者GUARD且双seedLOCAL，才能推进；不是仅胜自己旧版。seed桥三共同seed重算F0对冻结C*，不重选对照，形成≥1seed或LOCAL≥2。桥后被保留的参数用于后续所有对应来源对照；LR修订作用所有轻量臂。原结果不删除。

trigger只替换02的提议信号，不冒称完整MASS。新trigger须对GEOMETRIC和NO_GROW均PRACTICAL、对C0 GUARD，且有真实split与正形成才可锁为正式F1变体；正式重新生成自身profile。没有第二桥。若技术NaN/身份错误，应修代码，不用LR桥掩盖。

## 9. 正式矩阵与标签冻结

逐数据固定路线，新seed6101…6104，每数据最多7方法，合计≤56。未触发不补满，阴性dataset仍保留在总报告。

| 路线 | 触发 | 方法集合 |
|---|---|---|
| DYNAMIC | 第5节或合法trigger通过 | F1或唯一锁定变体、FIXED_PROFILE、WIDE_PROFILE、NO_GROW、C0、READ、PERM(最终F1) |
| CORE | 无DYNAMIC；F0 GREEN/LOCAL，或READ/SOURCE_K2/WIDE之一对C0 PRACTICAL | DIRECT、TARGET_ONLY、READ、SOURCE_K2、F0、WIDE、PERM(M_src) |
| STOP | 以上无成立或预算/数据阻塞 | 不注册正式轨迹，报告原因及开发结果 |

CORE M_src优先F0 GREEN/LOCAL，否则取合格source臂中Q最优。DYNAMIC各seed静态profile来自该seed自身F1 post14的F/S，不套用开发树，不读E。七臂统一phase2日程与V15…20；C0无router trunk，窗口全头fresh Adam继续L步，不冻结不存在的模块，披露其更充分优化机会。READ有同REACTIVATE机会。SOURCE/PERM标签与teacher合同始终遵循第6节。

GEOMETRIC和TASK_BANK_MATCHED仅开发；本轮正式证据不能声称确认优于几何提议或私有库。正式可以检验相对固定容量/宽函数/NO_GROW的增长增量、相对READ和C0的形成增量及source对齐。外部原版M3oE、AutoIFS、STEM和完整MASS未进入本轮独立训练，不提出SOTA或跨backbone主张。此范围收缩换取核心对照清晰，不因已有相似方法放弃方向。

FORMAL_LOCK在E访问前固化每data方法、母PERM、参数revision、seeds、模型选择与成本视图；EVAL_LOCK进一步绑定实际完整predictor、F定义群体与refit诊断状态、评分行hash。E和legacy只评分报告，不挑方法/K/群体/seed。无formal时也可锁定实际开发模型进行限定历史复评，但不把空正式矩阵称完成。

## 10. 数量上限和结果解释

开发24核心＋最多24结构＋4source归因＋最多4桥=≤56主适配轨迹；正式≤56。prefix、4类干预refit、继续训练和失败重启不算新的可选择主模型，但全部费用入总预算。不能在计数外隐藏额外超参搜索。数据不足或预算不足的对照标INCOMPLETE，不将缺结果记阴性。

| 结果 | 允许判断与后续 |
|---|---|
| F0胜READ/WIDE/C0且干预有正形成 | 保留功能形成，按规则推进F1/CORE |

| 约束长期绑定、唯一桥失败 | 如实报告已试预算边界，不无限松约束 |
| 开发正、正式四seed不支持 | 保留冲突，收缩主张，不换seed和主指标 |
| 缺数据/GPU/身份损坏 | 技术阻塞，保留工件，不写成算法无效 |
