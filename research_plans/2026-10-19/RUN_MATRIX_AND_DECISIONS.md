# 2026-10-19 全量实验矩阵、资源、比较关系与结论判据

本文件是 [FULL_EXPERIMENT_PLAN.md](FULL_EXPERIMENT_PLAN.md) 的执行性附表。**不是单次 proxy pilot**；规定从头训练、早期路径测量、完成训练预算、选中/最终评价、因果隔离、必要跨数据泛化，并保留所有阴性结果。条件扩展不是“能省 GPU 就不做”，而是避免在先验不适用的异构模型上强行验证同一个参数范数。

## A. 数据、训练与汇总口径

|条件|KuaiRand (KR)|MovieLens-1M (ML)|
|---|---|---|
|物理领域|tab0、tab1、tab4|历史项目的三年龄域|
|原生任务|click、longview|rating>3、rating>4|
|N19参考主训练每域样本数（5% meta 排除）|164143 / 1656704 / 84980|32775 / 2850 / 142500|
|基础优化器、学习率|Adam / AdamW，LR=0.003|Adam / AdamW，LR=0.001|
|默认 batch 与训练预算|40960 / 50 epochs|40960 / 100 epochs|
|权重衰减|基线 1e-5，机制对照含 0|基线 1e-5，机制对照含 0|
|随机种子|2022/2023/2024/2025|2022/2023/2024/2025|

N19 默认 Adam 和 AdamW 同名 decay 都是 1e-5，并非相同的有效正则化。固定各模型可用训练样本、验证人口与划分随机性；STAR/HAMUR 单任务只使用其目标任务标签，不借用另外一任务信息；联合两任务模型不因数据多一个标签便声称参数量、算力完全可比。

从头训练必须跑满预算，禁止以早期观察到零灵敏度就取消模型的所有预定种子。所有实验每组四种子，且保留完整每 Epoch AUC/LogLoss；早期 step 检查点仅对与路径机制相关的模块实施。

## B. 实验组 G0：忠实模型与跨模型基本发现（预先承诺完整）

每行表示**每个数据集×两优化器×四种子**，即 16 个网络；总 10 行 = **160 个正式从头训练网络**（如果同协议模型的历史 checkpoint 已有且早期 step 信息足够，可核对后复用并标注复用，不虚增新训练数；为了采样 step0/1/5/... 早期轨迹，必要时重训）。

|编号|模型/任务形式|任务/域目标|诊断对象|重要比较|
|---|---|---|---|---|
|G0-01|M3oE fixed（N19 协议）|联合两任务|STAR shared×slot|历史 N19 正对照|
|G0-02|M3oE original（核对论文及公开实现）|联合两任务|STAR shared×slot|原论文风格下还失活否|
|G0-03|M3oE original_sample（可学习融合/统一 Sample 控制）|联合两任务|STAR shared×slot|辨别损失与优化器协议|
|G0-04|STAR 完整模型，任务 0|跨域单任务|Star-FCN 乘性权重|原始结构是否复现|
|G0-05|STAR 完整模型，任务 1|跨域单任务|Star-FCN 乘性权重|不同任务下复现情况|
|G0-06|PEPNet 完整联合模型|域×任务|EPNet、PPNet gate|更广义乘性门控|
|G0-07|HAMUR 完整模型，任务 0|跨域单任务|hyper adapter|动态适配器对照|
|G0-08|HAMUR 完整模型，任务 1|跨域单任务|hyper adapter|任务依赖对照|
|G0-09|MMoE（仓库审计版）|联合两任务|shared expert pool|非同构共享基线|
|G0-10|PLE（仓库审计版）|联合两任务|shared expert pool|非同构共享基线|

**重要**：original 的 Equal 与双优化器是其待核对的原始风格协议，不与其它模型的 Sample 结果直接作为纯架构因果比较；要报告与 original_sample 和 fixed 的成对桥接。STAR 与 HAMUR 原论文核心目标是多域预测，不能把“任务0/1两套独立单任务模型”直接说成一次 MDMT 训练。

对每个 G0 必须记录初始化、step1/5/10/25/50/100/200/500（存在才取；短于某 step 不伪造）、epoch1/2/5/10、selected/final 的功能灵敏度和路径强度。对照模块采用**各自定义的中性干预**，而非统一将网络参数置零。

### 附加 G0-M：真正联合任务迁移（非原论文模型）

只在忠实 STAR/HAMUR 单任务模型通过来源与计算图检查后，构造保留其核心调制模块的共同两任务迁移版：STAR+2 task towers、HAMUR+2 task towers。每行 ×KR/ML×Adam/AdamW×四种子 = 16，合计 **32 次**；和各自单任务模型分表分析。若原模型无法在保留主要计算图的前提下迁移，明确阻碍及替代，不能拿另一种新算法冒充。

该组回答“MDMT 任务间冲突是否引起超出单任务多域训练的失活”；严禁把双任务加入后不同损失 scale 的结果直接视为多任务特殊性，需要统一 loss normalization 和 matched no-task-sharing 控制。

## C. 实验组 G1：优化器及衰减分离

**主对象：M3oE fixed、STAR 任务0、STAR 任务1。** G0 已包含 Adam/AdamW×1e-5，不重复计。另进行：

|编号|干预|新增训练配置（每数据集×四种子）|核心识别|
|---|---|---|---|
|G1-01|Adam / WD=0|3模型配置|不带耦合 L2，单独观察原强衰减是否消失|
|G1-02|AdamW / WD=0|3模型配置|验证 AdamW-Adam 的重要差异是否主要来自 decay|
|G1-03|固定非调制参数为 Adam+WD1e-5；仅 shared_weight 对应更新组取消 decay|3配置|单独干预共享因子|
|G1-04|同上，仅 domain-specific/slot 对应更新组取消 decay|3配置|单独干预领域因子|
|G1-05|同上，两个调制因子均取消 decay|3配置|两因子相互作用|
|G1-06|非调制组保持 Adam；仅调制因子组改 decoupled AdamW|3配置|更接近优化更新规则局部因果检验|

每编号 3模型×2数据集×4种子 = 24 次；6 编号理论上 **144 次**额外正式训练。若 G1-01 与 G1-02 在同一零 decay 更新数学上及实测完全等价，可将其标记为可复用的同一个独立训练而不重复两套 GPU：相同损失/梯度/更新即为严格等价控制，而非方向早停。此时报告名义配置数与实际非冗余训练数，不编造次数。

本组需要记录**全模型优化器切换**与**仅调制参数更新规则切换**的差异。不能说“其余参数每步数值保持不变”：训练若继续，改变调制参数必会反过来改变其它参数梯度。为隔离即时效应，从一个共同 checkpoint 复制参数/梯度，做单步局部替代更新和 loss/branch 灵敏度测量；这只是单步机制证据，与长期重新训练相互补充。

强制比较 WD0/非0 在固定模型、STAR 上的路径作用、损失和 AUC；若完全失活仅与特定耦合衰减一致，也仍须和普通 AdamW 或 WD0 对比实际效益和独立新颖性。

## D. 实验组 G2：旁路竞争与参数化（从头完整训练）

**对象：M3oE fixed、STAR任务0、STAR任务1**，每项在两个数据集、两优化器、四种子运行（每项基础 24 次）。

|编号|结构条件|为什么|
|---|---|---|
|G2-01|标准架构，但 **去除 Skip / STAR 辅助预测分支**，其余设置不变|检查旁路是否接管训练|
|G2-02|保留旁路，把 W_shared ⊙ W_domain 替换为 **等可学习参数量的加性 domain residual**|区分乘性参数化导致的共同塌缩|
|G2-03|保留乘性参数化，对旁路施加控制的可学习/固定缩放以匹配有效激活量，并记录权重|区分旁路强度、模型容量与分支输出支配关系|

如三组全部独立：3×3模型×2数据集×2优化器×4种子 = **144次**。为了不把原生 STAR 辅助路由与 M3oE 的中间 Skip 视为相同机制，每个干预在论文计算图里必须有独立描述。只有结构上等价、完全重复的运行可以合法复用。

补充从头训练**永久移除调制路径**与**匹配成本容量替代网络**（G2-04）：对象至少 M3oE fixed + STAR，两个优化器、两数据集、四种子；按相同参数/预算公平比较。该组不能由 G0 的单次 module-off 代替，是“失活是否有害”的核心。

## E. 实验组 G3：其他结构的模块功能与性能后果

|模型|最有辨识度的训练对照|需要避免的错误|
|---|---|---|
|PEPNet|完整 vs EP gate 固定中性 / PP gate 固定中性 / 两者中性，从头训练；样本级 gate 分布与任务差异|把 gate≈1（中性）误说 gate≈0（失活），或简单用参数范数比较|
|HAMUR|完整 vs 不使用 adapter / 只用静态域 adapter / 不共享 hypernetwork，从头训练|忽视 adapter 是 domain-specific，生成权重不一定直接乘性分解|
|MMoE/PLE|完整 vs 可训练的无共享专家/匹配私有容量，从头训练；共享专家使用率和条件贡献|把专家使用率低等同于 STAR shared×slot 数值塌缩|

G3 是预先声明的完整结构研究模块。只有 G0 完整 checkpoint 显示目标调制模块与其预先定义的主导问题根本不相关（如模型根本不存在对应路径），可合法记录 NOT_APPLICABLE；否则所有合理的训练对照都需要完成。对于完整网络内 G0 没有衰减的模型，G3 的阴性结构对照仍用于证明“这类调制机制不同”，不能全部省略。

## F. 实验组 G4：步数、数据规模和指标依赖

- **共同训练进度轴**：0–500 个相同 update steps 的直接诊断；保留完整 KR50/ML100 epoch。若需要比较 500 步以后的 KR，则在同一模型同数据集内部增加匹配更新数量/样本暴露的学习率、采样方案对照。
- **域规模受控实验**：在同一原始领域/任务内改变训练样本比例与重复采样（如 25%、50%、100%，具体样本最小数和曝光量冻结在实现说明），固定 evaluation population，同时分别控制 optimizer steps，避免把 N 改变与训练更新数混在一起；逐域报告，不预设“小域就是难域”。
- **任务交互**：同 backbone 的单任务与联合双任务对照；在相同数据/目标尺度与相同 shared-path 结构下比较，识别 task0/task1 信号与共享优化竞争。
- **泛化质量**：selected 与 final checkpoint 两套分开；宏 AUC、加权 cell AUC、宏 LogLoss、各 cell、实际参数/训练 FLOPs、推理耗时及峰值内存都保留。部署只把校准/排序/训练阶段一致的收益称作有价值。

新增规模/训练阶段对照**不能替代** G0–G3 已承诺的训练矩阵；但可以避免没有决策价值的全集合超参网格。

## G. 原始源码、checkpoint 记录与排除无效比较

- 训练根路径、原始/移植代码 commit、论文/代码对应审查版本写入 manifest；每个 run_ID 唯一，绝不覆盖旧 N19 文件。
- 诊断原始值：模型输出、自然中性干预后的输出摘要、各 cell 变化、有效权重乘积、梯度/更新/Adam m/v、对应更新/样本计数，默认全部用相同预先冻结的 train-meta 和 validation 诊断池。
- 单任务与多任务、不同任务标签定义不同：只在同任务同人口下作公平绝对性能比较；不同模型间的模块“贡献量”按自身中性干预解释，不跨模型把数值直接排大小。
- 四种子成对差；如发现有希望的机制，再增加全新随机初始化和独立样本人口/数据集作确认，明确科研开发证据与真正 out-of-sample 确认。

## H. 对结果的逐项判定（不得缺项）

|观察组合|允许的解释|禁止的推断|
|---|---|---|
|N19 fixed失活、original不失活|修改协议相关|不能说原始M3oE普遍缺陷|
|original与独立STAR均失活|STAR类架构候选共性|不能直接说所有乘性门控均如此|
|PEPNet/HAMUR也发生各自模块贡献下降|较广条件调制退化的证据|不能宣称机制必然与STAR耦合Adam L2相同|
|MMoE/PLE共享模块也退化|更一般共享模块优化竞争可能性|不能把不同中性干预值混成单一量纲|
|AdamW使路径活跃但选中AUC不升|有效贡献恢复≠泛化提升|不能包装成已解决的性能方法|
|失活后去除路径重训无性能损失或更好|良性冗余/结构选择可能|不能将其当普遍优化病害|
|仅同一测试集final变好而selected不变|阶段/正则解释优先|不能用final反向选择部署epoch|
|局部干预、等成本训练、独立人口均证明失活有害且新机制能救|可继续方法/理论研究|仍须检索与最接近已有工作区别|

最终报告必须分别给出 **结构普遍性、机制归因强度、因果性能价值、已有方法覆盖风险** 四维结论，任何维度未确认都应标 NOT_ESTABLISHED，而不是一个“已证明”的总标签。

## I. 完成与资源原则

- 本项目已有两张 RTX3090 等 GPU 资源，**禁止再把“节约GPU”为理由缩成冻结诊断后结束**。所有 G0 基础网络和科学上有意义的 G1–G4 核心比较应完整执行并保留足够种子与实际训练。
- 可以并发，遵守服务器本地 start.md 关于 worker/GPU 进程的规则；当模块计算图被证实不适用时记录 N/A，而非制造无效训练。
- 只允许基于严格等价的运行复用、明确的数据授权限制、模型不适用性、已证明的文献/数学覆盖停止具体候选；**不允许**用“没有达到任意代理指标门槛”跳过应训练的方法。
- 防御性测试仅保留能改变实际模块梯度、模型训练、指标解释或结论的关键项：参数组无重叠、干预前向值、同数据配对、冻结测试与权重乘积数学一致性。禁止普通工程全链路重构、重复同值 checks、无关防御性 ablations。
- 交付全量可核实矩阵、运行/缺失原因、正负结果及新问题；明确原模型与移植/消融版本。**不能提前将全部方向标记 COMPLETE，也不能把未运行计划冒称结果。**
