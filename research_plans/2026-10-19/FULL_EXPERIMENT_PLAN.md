## 1. 核心科学问题、互斥解释与可证伪预言

**RQ1 泛化范围**：现象仅见于 N19 fixed M3oE 的优化协议、严格 M3oE 原论文风格训练、独立 STAR 乘性权重族，还是也见于 PEPNet/HAMUR 的其他条件调制模块？非同构的 MMoE/PLE 是否有可比的共享路径弱化？

**RQ2 触发机制**：乘性权重共同缩小、Adam 耦合式 L2/自适应更新、Skip/辅助旁路竞争、累计更新次数、域/任务样本分布、标签率、梯度抵消，哪个因素是必要条件或主因？允许多因素共同成立，不能为一个预设答案设计实验。

**RQ3 功能与价值**：失活是无害的自发冗余淘汰，还是显著降低了在相同资源预算下可达到的泛化能力？通过保持路径活跃得到的是最佳选中 checkpoint 改善、特定 cell 保护，还是仅改善训练末期过拟合？激活路径但损害 AUC 的反例必须保留。

**RQ4 文献与创新性**：与 Adam/AdamW、STAR、跳跃路径竞争、乘性分解的尺度不识别、已有低秩或门控退化方法相比，新增的是普遍成立的新边界、实证失效机制，还是某个配置下的已知优化现象？如无超出已有理论/方法的贡献，明确 NO-GO，不包装为顶会创新。

预注册四类竞争解释：
- H1 **乘性梯度饥饿/耦合衰减**：乘积权重趋近零，反向梯度经另一小因子衰减；预言该效应在乘性结构和特定更新规则中更明显，改变该路径的衰减可恢复其贡献。
- H2 **旁路竞争/良性冗余**：Skip 或辅助网络足够强，调制主路被忽视；去除/缩弱旁路会改变失活速度，但可能改善也可能损害性能。
- H3 **更新次数与数据混杂**：KR、ML 的每个 epoch 更新步数差异等引发看似数据集特定现象；按 update-step 和曝光量分别对齐后效应可能收敛。
- H4 **一般条件调制退化**：其他实现不同的乘性门控或动态适配器也会在其自身中性干预下贡献衰减；若只在 STAR 类 Hadamard 权重里出现，则不能推广到任意共享机制。

|---|---|---|---|---|
|A0|**N19 fixed M3oE**，冻结融合、Sample、单优化器|重复现象的正对照|STAR 乘性调制路径|历史 N19 已测，不默认重复训练|
|A1|**M3oE original 风格**：原始可学习融合、Equal 聚合及双优化器；另设 original_sample 单优化器/同目标桥接组|鉴别 N19 fixed 与原训练协议区别|相同 STAR 调制路径|original 风格仍须按原论文和公开代码核对，不能凭文件名声称严格原论文一致|
|A2|**独立 STAR**：论文定义的多域 CTR 主干、PN 与 Auxiliary Network；分别对两项任务训练单任务版本|最关键的跨模型结构验证|shared × domain-specific FCN 权重|STAR 是多域单任务，不能把单任务效果冒称一个联合 MDMT 模型|
|B1|**PEPNet**：尽可能忠实保留 EPNet/PPNet 与门控控制变量|检验乘性激活/隐藏层缩放是否同样衰减|EP/PP gate 对实际表征/预测的增量|门控缩放不是 STAR 参数的 Hadamard 权重分解|
|B2|**HAMUR**：保留 hyper-network 与 domain adapter|检验超网络生成的适配器是否被网络忽略|adapter 的函数增量/使用程度|是另一个参数生成机制，不能以 slot 范数为统一标尺|
|C|**MMoE、PLE**（仓库已有已审计实现）|非 STAR 共享结构对照|共享专家/共享分支对输出的贡献|无 STAR 权重，不能称为“相同 STAR 失活”|

可选的**结构机制对照**：同容量 M3oE/STAR，将乘性权重改为加性 domain residual；原始 STAR 保留/去除辅助网络和 PN；M3oE 保留/去除 Skip。以上均是明确标记的**人为改造实验**，不得冒充原论文模型。

**模型实现忠实性最低要求**：逐模块列明论文定义、来源代码或已验证第三方实现、输入输出维度、domain/task 定义、归一化、旁路、实际 trainable 参数、损失和优化器。忠实单任务 STAR/HAMUR 与人为扩展 MDMT 版本应当分列。迁移实现时先比较其公开示例在可运行数据上的输出/损失语义，再投入正式训练；仅修复可能影响结论的功能错误，不进行通用工程重构。

## 3. 可复核的统一“失活”定义

### 3.1 不仅监测参数大小：以路径对预测的贡献为主

对某模型的目标调制模块 M，在同一 checkpoint、同一数据批上定义中性/移除干预后的输出：

- P3/M3oE、STAR：保持 shared、bias、Skip、专家、head 不变，仅将对应的**乘性 domain-specific 权重贡献**替换为零；同时提供“完整移除 STAR 主路并保留 bias/旁路”的单独定义，避免把两种实验混淆。
- PEPNet：把相应门控输出替换为**中性缩放系数 1**，分别测 EPNet 与 PPNet；若原论文门控使用非 1 中性系数，按其实际计算图定义并记录。
- HAMUR：关闭 adapter 残差贡献、保留共享 backbone 和其它合法路径；另测超网络输出范数与 adapter 激活。
- MMoE/PLE：对所选共享专家（或共享专家池）的输出作中性替换/重路由，明确是否重新归一化 gate，单独报告，不与 STAR 零 slot 数值直接等价。

核心指标：
1. **路径输出与预测灵敏度**：平均绝对概率变化 E|p−p_neutral|、P50/P95、logit 差、每 cell 的 BCE 与 AUC 变化；记录对应的分层 CI。
2. **有效项强度**：M3oE/STAR 的 ||W_shared||、||W_slot,d||、||W_shared ⊙ W_slot,d||、调制主路激活范数及相对 Skip/aux 的输出贡献；避免因 W_shared*c、W_slot/c 的尺度等价而错把大/小单因子范数当作函数证据。
3. **优化动态**：上述分支梯度、带/不带 WD 的实际更新、Adam m/v、有效学习率和梯度尺度；只统计影响本结论的模块，不抓整个模型的无关日志。
4. **重训练反事实**：从头训练“无调制路径”“弱旁路”“匹配参数量替代分支”等模型，比较完整测试性能。单次删除的 Δp≈0 不代表网络从头去掉该模块仍能达到同样风险。

只有当**功能灵敏度接近数值精度底噪 + 有效路径项可忽略 + 跨 checkpoint 连续成立**，才报告“数值失活”；否则使用“弱化/贡献较小”。零变化必须记录 float32 分辨率，不称数学上严格为零。基于固定 train-meta 的删除试验不能充当测试集泛化改善。

### 3.2 时间定义

保存和诊断 **初始化 step0、optimizer step1/5/10/25/50/100/200/500**，以及 Epoch 1/2/5/10、验证最优、最终；长运行额外保存适当的 1000、1500、2000 与最终更新步。为了不重复跑完后的额外复制，可在新训练期间按既定检查点直接记录。

同时保留 **按 Epoch、按累计 optimizer updates、按累计训练样本暴露数** 三条横轴。对 KR/ML 至少覆盖共同更新区间（0–500），并在完成正常全预算后针对仍存在的更新次数混杂开展匹配步数/匹配曝光量的完整对照。不能把“第 5 Epoch”误当成两数据集拥有同等优化历史。

## 4. 完整实验模块（全部执行，排除逻辑须明确）

### E0：历史复核、模型复现与比较口径冻结
- 读取 N19 328 训练记录、两数据集 fixed/Adam 与 fixed/AdamW 的四种子预测/秩移除诊断；核对历史版本、模型结构、不同损失协议和更新数。无需重训所有旧实验。
- 从原始 M3oE repo 和 STAR/PEPNet/HAMUR 一手文献核对关键计算图。只确认会改变被测模块与目标函数的代码差异。
- 冻结：两数据集原有 train/val/test 人口、task/domain、seed2022–2025、目标指标、选模规则、训练预算和原始协议差异。历史测试集多次使用，只能视为探索性证据。

### E1：原始协议复核——回答“原始 M3oE 是否也失活”
- 在 KR、ML 上测 paper-faithful M3oE（若公开实现与本仓库 original 存在差异，先明示差异）和受控 original_sample。**各模型 Adam、AdamW、四种子从头完整训练**。
- 对每一个原始协议运行上述早期路径诊断，并明确可学习融合/Equal/双优化器与 fixed/Sample/单优化器之间哪一种改变可能引发失活。
- Equal vs Sample、Adam 历史机制不能未经隔离互相归因；历史 S5–S8 / N17 的结论作为先验研究证据，不重新从零做全部网格。

### E2：跨架构实证——回答“是否不限于 M3oE”
- **STAR**：KR、ML 的任务0与任务1各自做多域单任务 STAR；保留 PN/aux 原本架构。Adam/AdamW×4seed×正常预算；两任务独立结果不可直接宣称一次 MDMT 联合训练。
- **PEPNet**：两个数据集各四种子，Adam/AdamW；保留 EPNet/PPNet，分别以 gate-neutral 和全模型重训的对照检验贡献。
- **HAMUR**：按原论文多域定义在任务0与任务1各训练一套，同样×两优化器×四种子；优先复用公开代码的模型语义，不将混合新 task heads 的迁移版本误称为原方法。
- **MMoE、PLE**：两数据集×两个优化器×四种子完整训练，记录共享专家功能贡献、是否存在同样的早期衰退；即便出现也需明确不是 STAR 同一参数化。
- 如 E2 显示可复现的广义调制弱化，再对 STAR/HAMUR 补充公平的**联合双任务头迁移版**，以回答多任务冲突的增量作用；不能将人为迁移结果混入原模型论文复现结论。

### E3：机制因果隔离——只因 RQ 所需而干预
**主实验：M3oE 与 STAR，两个数据集、四种子、完整训练。**
1. **优化器×衰减**：Adam / AdamW × WD=0 / WD=1e−5；相同数据、参数初始化、batch、LR、shuffle、完整训练预算。说明同名 WD 数值不代表相同正则化动力学。
2. **仅改变调制分支**：分别只改变 W_shared、W_slot 的 WD 或衰减规则，其余参数使用固定优化器组；不将全模型 Adam→AdamW 的变化冒称对调制层的局部因果干预。
3. **局部单步反事实**：在同一 checkpoint、同一梯度上，用不同分支更新公式只更新分支、固定其他参数，测即时路径强度/风险变化，以帮助隔离更新公式本身；与长期重训练结果分别报告。
4. **旁路与参数化**：Skip/aux 原生 vs 同协议去旁路；Hadamard 乘性 vs 等容量加性残差；完整从头训练且记录容量、训练 FLOPs。避免只临时消融导致 OOD 预测。
5. **训练过程混杂**：按更新数与样本暴露分别对齐；在同一物理域中做受控的规模子采样、固定验证人口，适当交叉标签率/分布；不可从 KR/ML 三个自然域大小排序推导因果作用。
6. 若 PEPNet/HAMUR 出现模块弱化，对每类模块只施加其本身合法的中性干预及最有解释力的一项对应机制实验；若没有同类现象，作为阴性边界保留，而非强制让它们复现 STAR 因子范数结果。

### E4：有害性与实际收益——完整端到端的决定性比较
在相同目标函数/数据/选模/成本参考下至少比较：
- 原模型及其最强自然训练基线；
- 无调制从头训练（参数量和计算可比时另设匹配容量回填）；
- 乘性不变、但局部衰减修正/更稳定因子参数化的候选；
- 原生 AdamW、Adam WD=0、普通模型正则/early stopping 等**最接近且足够强的竞争解释**。
所有具有可训练科学动机的候选都做正式、完整的多种子端到端训练；不得只因 E1/E2 局部 proxy 低于阈值而一律提前终止。

区分三类结果：**路径恢复**（参数/输出）、**选中 checkpoint 的泛化提升**（AUC/LogLoss/cell）、**最终阶段延缓过拟合**。允许 ① 不等于 ②，③ 不能冒称 ②。若路径失活后泛化不降甚至更优，应诚实支持“良性冗余/隐式结构选择”解释，不人为寻找一定要恢复路径的方案。

### E5：外部性、文献新颖性与成果收束
- 主要证据必须覆盖 KR、ML 两人口和模型 Tier A/B；对真实泛化或特定共同机制的强主张，若结果值得发展，预注册额外独立人口/公开数据（优先 Ali-CCP 的许可可得版本）或不重用的时间/用户划分。第三数据不可获得时明确降低结论等级，不伪造跨总体保证。
- 在选定机制后检索及核对已有权重衰减、冗余/梯度饥饿、乘性分解、Skip 竞争理论和 STAR/PEPNet/HAMUR 修复方法；理论贡献必须超出“AdamW 能保持权重较大”。
- 形成 GO（真正新问题/算法+效益）、CONDITIONAL（机制明确但泛化待证）、NO-GO（一般冗余或旧理论充分解释）、DATA/IMPLEMENTATION-BLOCKED。不得把“所有实验已运行”写成“证明所有模型有同一失活机制”。

## 5. 数据、评价、统计与判定口径

- **主任务**：KR 的 click/longview；ML 的 rating>3、rating>4。STAR/HAMUR 官方风格运行是“每任务单独跨域”，其性能不能与单个多任务模型在相同参数预算下直接公平排名；只比较机制边界，再以额外合适对照作受控 MDMT 迁移。
- **分组结果**：每个 domain×task cell 的样本数、正例率、AUC、LogLoss、技能相对常数基线、路径 Δp/Δlogit、正负种子数、宏平均/训练人口加权 cell 指标；必要时最差 cell 与公平性约束。加权 cell AUC 不等于 pooled AUC。
- **训练选点**：统一预先固定的 validation-only 选择规则；分离 development 与 selection；保留 final epoch 作为诊断而非替代选中模型。若新模型失配同一模型选点规则，先明确定义公平的通用选择方式，不读取 test 作调参。
- **随机性**：基础随机种子 2022–2025；如果跨架构或不同训练协议出现有意义的优势或矛盾，新增种子、分割和数据总体用于确认。四个种子只是固定总体下的优化随机性，不能当独立数据集，也不能以 correlated cells 增加显著性样本数。
- **测试纪律**：本研究已经重复使用 N19 历史 test；新算法先用开发/验证决策，锁定设计后一次测试。对论文级新颖性和泛化确认须使用未参与方法探索的新总体；不能把原历史 test 称为全新独立确认。
- **训练范围**：遵守现有可访问的两张 RTX3090、数据/显存约束；既有组完整训练，真实 GPU 并发按本地 start.md。计算资源不是强制缩成“最小验证”的理由，也不是增加无目的 LR/种子/WD 网格的理由。
- **路径贡献数值不能比较的情况**：STAR 乘性主路、PEPNet gate 中性化、HAMUR adapter、MMoE/PLE expert removal 不是同一估计量；结果按各自定义标准化、分模型呈现，不做无意义统一阈值排行榜。

## 6. 必须形成的分析结论（不受积极结果数量限制）

- 严格原始 M3oE 与 N19 fixed 分别是否失活？从哪个 optimizer **step** 出现？仅 KR 还是 ML 也触发？具体在哪些 cell？
- 独立 STAR 复现与否？STAR 的 PN/aux/主调制哪一部分起决定性作用？PEPNet/HAMUR 是否出现可比的**自身模块弱化**？MMoE/PLE 共享专家是否有其自己的失活？
- 当乘性主路消失时，其他路径是否补偿？是训练历史造成，还是特定数据统计、标签或参数化造成？哪些实验排除/保留了其他解释？
- 改变衰减、换优化器、改变参数化分别**恢复多少功能贡献、改变多少 AUC/LogLoss、付出多少参数/FLOPs/峰值显存**？
- 失活/恢复是否真实影响最佳可部署模型？仅最终 epoch 下降减轻是否仍有价值？
- 最终科学问题是否早被已有论文覆盖？哪些是可推广机制、哪些只是单数据集反例？发现新的未解决问题全部完整列出，不强制限制剩余问题数量。
