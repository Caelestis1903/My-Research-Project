# Model fidelity and boundaries (pre-training)

All models use frozen N19 features, split, batch, normal budget, LR and validation-only selection. These are controlled public-data adaptations, not reproduction of private industrial experiments or every paper hyperparameter. No strict published performance claim is made. Single-task labels: KR click/longview; ML rating>3/rating>4. Domains are KR tab0/tab1/tab4 and the historical ML age partitions.

M3oE forward agrees with pinned N19 to5.96e-8; MMoE/PLE agreement exact on check inputs. Raw check includes branch gradients and interventions. The HAMUR reference class is preserved in cm19_hamur_reference.py; import only is adapted to equivalent local embeddings; Apache-2.0 license included in cm19_sources/HAMUR_LICENSE. Repository N19 source lineage hashes are in SOURCE_LINEAGE.json. STAR/PEPNet are project implementations from equations, not advertised as official ports.

From-scratch neutral structures freeze unused module parameters, retain serialization for initialization pairing and distinguish nominal/trainable counts; actual measured costs determine any efficiency claim. Private expert alternatives use one expert/cell, widths256 (unmatched) or170 MMoE /426 PLE (approximate capacity), not exact equal-capacity matching. Additive matrices have exactly the same trainable factor count as multiplicative matrices. Removing modulation preserves biases and all legal remaining pathways, separately from full-main-off diagnostics.

Primary sources: [M3oE](https://github.com/Applied-Machine-Learning-Lab/M3oE), [STAR paper](https://arxiv.org/abs/2101.11427), [third-party STAR reference](https://github.com/QunBB/RecSys/blob/main/recsys/multidomain/star.py), [PEPNet paper](https://arxiv.org/abs/2302.01115), [HAMUR paper](https://arxiv.org/abs/2309.06217), [HAMUR author source](https://github.com/Applied-Machine-Learning-Lab/HAMUR).

Raw strength-field semantics: product norms in structural additive/off controls describe the stored latent factor tensors; those products are not the applied additive matrix or a forced-off pathway. Natural spontaneous inactivity analyses use native conditions and actual functional interventions. Explicit neutral structures are forced interventions, not evidence of spontaneous collapse. No inference-efficiency claim follows merely from frozen serialized parameters. HAMUR public-style backbone batch normalization also processes the whole mixed batch in each domain backbone before output routing; this source behavior is retained.
