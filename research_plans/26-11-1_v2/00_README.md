## 研究主线

限定为多域多任务推荐中的梯度、数据增强、动量式优化和参数轨迹平均；不回到差异化共享、多原型或跨域读取。目标是找到能够提高selected macro AUC、且能明确归因于更新规则而非仅靠调参的结合方法。

当前最值得推进的两个问题：
1. **增强梯度的有效增量如何进入优化历史。** 普通增强在KuaiRand有条件性收益，但增强差分长记忆βδ=.99未超过普通增强Adam；需要判断差分中的信息应以固定注入、可信度调节还是创新量驱动的历史更新进入优化器。
2. **参数轨迹平均的收益如何与在线训练配置及时间尺度分离。** 当前EMA的AUC排序收益已复现，但MovieLens有明确LogLoss代价；ρ=.995是历史锚点，不代表两个数据集上等价的时间尺度。

建议优先实现一个主候选：增强创新量调节的差分历史注入（AIG-M）；保留一个结构不同的替代候选：增强状态调节的参数轨迹平均（AIG-SWA）。先做有限搜索与开发seed筛选，只让一个候选进入完整五seed确认。候选名称和机制假设均不是已验证收益。

## 关键现有证据

- GAM01完成40/40条轨迹：2数据集×4训练臂×5seed、每臂50epoch。A0 shadow EMA相对A0 online：MovieLens selected test macro AUC +.004399（5/5正），LogLoss +.007800（4/5恶化）；KuaiRand AUC +.004616（4/5正），通过当轮预设推进门。
- A3 βδ=.99相对A1普通增强Adam：MovieLens AUC −.000336、KuaiRand −.001554；validation分别0/5、2/5正向。KuaiRand增强目标域d2两任务均5/5下降。当前长差分记忆不晋级。
- A1普通增强相对A0：KuaiRand macro AUC +.002584、4/5正且LogLoss −.006201、5/5改善，但pooled/traffic反向且收益集中于任务/目标域，属于条件性收益；MovieLens没有建立稳定增量。
- A2 βδ=.9是与A1在实数代数上的等价实现控制；长期FP32轨迹分离不能自动解释为机制收益。
- P2未触发、未训练，不能写成阴性实验。
- 旧Polyak结果只作为当前自然数据协议下重验的先验依据，不能跨协议直接当作当前效应量。
