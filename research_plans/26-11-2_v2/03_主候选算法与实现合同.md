## 2. 共同精确损失与原预算

令 `ℓ_it=BCE(pθ,it,y_it)`，BCE 实现保持来源概率版，不擅自换成另一种 clipping 或 logits loss；raw logits 仅用于 F1 输入探测。

\[
L_{real}=\frac{1}{BT}\sum_{i=1}^{B}\sum_{t=0}^{T-1}\ell_{it}.
\]

J/F 单视图两任务：
\[
L=L_{real}+\frac{\lambda}{BT}\sum_{i\in S,t}(\tilde\ell_{it}-\ell_{it}),\qquad\lambda=0.5.
\]

因此目标域 clean 权重是 `(1−λ)/(BT)`，aug 权重是 `λ/(BT)`；非目标域仍为 `1/(BT)`。不以 n、供体数、有效投影行数或正例数重新归一化；不按域/任务再除一次。辅助损失为零。这里是原监督风险的视图混合，不是独立样本重加权研究。

TG：
\[
L=L_{real}+\frac{\lambda}{BT}\sum_{i\in S}\sum_t
[\ell_t(f_\theta(h_i+\delta_{it}),y_{it})-\ell_{it}].
\]
每视图只使用对应任务损失；不能每个视图同时累加两个任务后不除视图数。AG 两任务方向相同可共享一次增强 forward，数学目标相同，实际计算减少要照实记账。

当前数据标签完整。若 Stage0 发现缺标签：不伪造负标签；记录缺失掩码，原 `BT` 分母保持，缺失项为0，J 只对两个标签均观测的行构造供体；F/TG 梯度只用观测任务，F 约束也仅保留这些任务行。该变化必须单列协议差异；不能与旧完整标签结果声称逐位相同。若与数据来源不符先排查加载错误。

`n=0`、`λ=0`、`κ=0` 时直接调用原 A0 标量路径，不抽增强 RNG、不进行 probe/教师 forward。某些行没有有效扰动时该行 `δ=0`，增强差分应为0，不重分配它的预算。若整个 S 都无扰动，直接 A0。

## 3. 输入探测路径：必须修复的实际断图问题

实际 source `reference.py` 中 gate 接收 `emb.detach()`。这不会改变前向数值，却使原自动微分的输入导数遗漏 gate 的数值响应。因此本轮需要两个明确不同的路径：

- **训练路径**：完整保留原参数梯度图，gate 的 detach 不变。最后的监督 backward 只沿这一条路径。
- **只读输入 probe**：用相同参数数值、embedding、STAR/expert/gate/tower 计算相同 raw logits，但 gate 输入不 detach；参数全部视作常量，只有指定 embedding leaf 或字段增益 leaf 求导。该路径不更新模型、不写 `param.grad`、不改变 gate 学习规则。

新增 `input_probe.py` 的纯函数接口建议：

```python
probe_logits(params_detached, buffers, x_target, embedding_leaf,
             gate_input_detach=False) -> Tensor[n, 2]
```

可复制固定 reference 的前向到新包实现纯函数/专用 probe module，参数通过 detached 映射传入。`functional_call` 只负责替换参数，不会自动消除原 forward 的 detach；不能把原 module 直接 functional_call 后当成完整输入导数。

raw logit 取 tower 最后 Linear 的输出，按 `t*D+d` 路由，与源 sigmoid 前数值一致；不对可能饱和的概率做 `logit(clamp(p))` 替代。已有网络没有跨样本 BatchNorm/Dropout，因此 `autograd.grad(loss_t.sum(), embedding_leaf)` 一次即可获得每行梯度。若未来模型引入跨样本层，本合同不可直接沿用。

必要 Stage0：probe 与 source 概率最大绝对误差≤2e−6；FP64 小模型有限差分相对误差≤1e−4（避开 ReLU 恰好零点）；真实 FP32 batch 做方向差分容差1e−2，记录步长1e−3/1e−4的稳定区间。检查 probe 前后 θ、optimizer、φ、training RNG hash 不变；`param.grad` 始终 None。检查正常训练 forward/backward 仍等于 source。若有限差分失败先定位断图/数值问题，不静默接受偏导近似。

## 4. 主一 J1：供体集合、共同半径与任务选择

### 4.1 供体与随机流

对每个 i∈S，候选池
\[
\mathcal P_i=\{j\in S:j\ne i,\ d_j=d_i,\ (y_{j0},y_{j1})=(y_{i0},y_{i1})\}.
\]
在当前训练 batch 内，按 keyed donor RNG 无放回抽最多两个不同供体。不做全样本近邻索引、跨域 donor、验证 donor 或无限重抽；剔除 sparse embedding 差范数≤1e−12 的候选。用 joint-label 分桶和排序后的原 row_id 保证确定性。ML 的 (0,1) 不应出现，检查计数；KR 保留实际出现的全部四种组合，不预设嵌套。

若有两个有效供体，记 `d_ic=stopgrad(h_j,s−h_i,s)`，c=0,1。共同半径
\[
r_i=\min\{\kappa\|h_{i,s}\|_F,\ \alpha_{max}\min_c\|d_{ic}\|_F\},\quad\alpha_{max}=0.2.
\]
\[
\delta_{ic}=r_i d_{ic}/\|d_{ic}\|_F.
\]
κ 默认 ML.05/KR.1。每行两个候选严格相同 L2 能量，且前向位置在线段上、插值系数≤.2。只有一个供体时用同一公式单候选；没有供体或 r=0 时 δ=0。这个半径通常不等于 A1 的实际 Gaussian 能量，不能把相同 κ 说成所有方法精确同能量。

### 4.2 任务响应选择

目标子批 probe 计算 `g_it=∂ℓ_it/∂h_i,s`，t=0,1；它不含 weight decay。对范数>1e−12 的观测任务定义
\[
s_{ict}=\left\langle\frac{g_{it}}{\|g_{it}\|_F},\frac{\delta_{ic}}{r_i}\right\rangle,
\quad c_i^*=\arg\max_c\min_t s_{ict}.
\]
任务梯度归一化只用于挑方向，不改变训练损失权重。若某任务零梯度，忽略该任务的选择分数并记日志；全部任务零梯度时均匀随机。并列最大值用独立 keyed tie RNG。**不要求最终分数正**，否则会引入未登记的样本覆盖门。

J0：同样的两供体、共同半径、单候选/无候体处理，但均匀随机选择；不计算任务 probe。

J_SUM：保留 J1 的所有操作，把 `min_t s` 换成观测任务的算术均值，用来判断 max-min 是否多余。

### 4.3 梯度语义与边界

最终训练输入是
\[
\tilde h_{i,s}=h_{i,s}(\theta)+\operatorname{stopgrad}(\delta_{i,c_i^*}).
\]
整个 δ detach，包括 donor、recipient 尺度、半径和选择；无高阶梯度、无 donor 反传路径、recipient 的该局部导数为恒等映射。前向是小段插值，但反向**不是**经典 mixup 对两端按 α 分配梯度，不能宣称精确复现 mixup。dense/route 留 recipient 原值，所以也不声称整条输入位于真实数据流形。

EMA 对 J1/J0/J_SUM 都是非反馈 shadow，只有最后模型评价收益。J1 的机制贡献是联合标签限制和任务梯度择向；若 J0 足够好则采用 J0。

## 5. 主二 F1：联合响应约束与字段增益

### 5.1 无量纲增益与两个参数状态

定义对任一模型 ω∈{θ,φ} 的增益输入
\[
h_{\omega,if}(a)=h_{\omega,if}(0)(1+a_{if}),\quad f=1,\ldots,F.
\]
两个模型使用自己的 embedding，共享的只是字段增益 a 的语义；不相减两个时刻的 embedding 坐标。非允许字段不动。

在 a=0 的只读 probe 上计算
\[
J_{itf}=\partial z_{\phi,it}/\partial a_{if},\qquad
 g_{if}=\partial[\tfrac12\sum_t\ell_{\theta,it}]/\partial a_{if}.
\]
对 J 的非零行做 L2 归一化；行范数≤1e−12 的任务约束置零并记日志。J、g 均 detach。教师参数用 **本次更新前** φ，学生用 θ；同一原 batch、无新采样。老师 forward 不能放在 `torch.no_grad()` 内阻断 a 的梯度；正确做法是参数 requires_grad=False、a leaf requires_grad=True。

### 5.2 联合投影与退化处理

\[
\Pi_i=I-J_i^\top(J_iJ_i^\top)^\dagger J_i,\qquad v_i=\Pi_i g_i.
\]
实现用 FP64 的 `[n,2,F]` 小矩阵 SVD：仅保留 `s_j>1e−6*s_max` 的奇异方向；若 s_max≤1e−12，Π=I。用 `v=g−V_rᵀ(V_rg)`，不用显式保存 `[n,F,F]`，无 O(F²) 大状态。

如果 `||g||≤1e−12` 或 `||Πg||/||g||<1e−3`，改用 `v=Πξ`，ξ 为独立 keyed 标准 Gaussian 字段向量。若其范数仍≤1e−12，δ=0，不反复抽样。记录 SVD rank、保留比、fallback率，不能把零投影伪报为非零梯度机制。

**代数事实：** 当 φ=θ 且使用相同完整输入导数，`g=J_rawᵀ(p−y)/2`，因此在精确秩计算下 Πg=0。初始化时必然依赖回退；后续参数分离可能产生非零分量，但是否有益属于待测假设。用在线 J 代替教师 J 会系统性触发该退化，因此本轮优先 F_PR 随机子空间消融，而不把在线 J 控制误称单纯去掉历史、其他完全不变。

### 5.3 能量与统一限幅

令 `w_if=||hθ,if||²`、`W_i=Σ_f w_if`，均 detach。
\[
a_i^0=\kappa\sqrt{W_i}\,v_i/\sqrt{\sum_f w_{if}v_{if}^2},\qquad
 a_i=a_i^0\min\{1,\,0.25/\max_f|a_{if}^0|\}.
\]
W 或加权分母≤1e−24 时 a=0。**统一乘一个系数**，不能逐坐标 clip 破坏零空间关系。该设计的增益限制保证各字段缩放介于.75与1.25；它不是标签保持证明。

最终训练扰动：`δ_if=stopgrad(a_if*hθ,if)`，训练输入 `hθ+δ`。必须 detach 整个乘积，不能写成 `hθ*(1+detach(a))` 后把额外 embedding 梯度缩放混入方法。教师没有接受监督 backward；其梯度只用于生成视图。

在保留秩的数值精度内 `Ja≈0`；有限真实教师 logit 响应仍包含高阶项，必须记录实际响应，不能以投影残差小代替 AUC。

### 5.4 简单控制

- **F0**：v=g，不计算 J/Π/教师 probe，按相同 κ、能量公式、统一 .25 cap 构造方向；g=0 时使用 keyed Gaussian v。保留固定评价 EMA。
- **FR**：在该控制自身当前 θ/φ 上先构造 F1 的反事实 δ*，取得 `E_i=||δ*_i||²`；生成独立 Rademacher 符号 ε_if，`a_if=sqrt(E_i/W_i)*ε_if`，W=0 时0。因 E≤.25²W，仍满足 .25 cap。它精确匹配**当前状态的 F1 反事实行能量**，不声称两条分离训练轨迹逐步能量相同。FR 的教师/probe 开销照计。
- **F_PR**：始终 v=Πξ，省掉学生 g probe；其余 J、预算、cap、监督目标、EMA 顺序相同。用于判断“教师约束随机增强”是否已经足够。

F1 不胜 F_PR 时选择 F_PR，不再声称学生梯度择向有独立价值；F1 不胜 F0/FR 时停止对应复杂主张。F_PR 的增量不能单独证明 EMA 比任意其他模型参照更好，后者留作边界，不无限补模型控制。

## 6. 备选 TG 的完整合同

沿 J1 的目标 sparse embedding probe 得到两个真实任务输入梯度 g_it；不用 donor。
\[
r_i=\kappa\|h_{i,s}\|_F,\quad
\delta_{it}=r_i g_{it}/\|g_{it}\|_F.
\]
零梯度时用同半径标准 Gaussian 向量归一化，零 embedding 时 δ=0。所有半径/方向最终 detach，路由/dense 不动，EMA 非反馈。该半径是 global sparse L2，不等于 A1 的 per-field Gaussian 分布。

TG 两个视图分别贡献任务0/1，如 §2。RG 用两个独立归一化 Gaussian 方向，各与 TG 对应半径完全一致；AG 用 `g_i0+g_i1` 的单一归一化方向服务两个任务。AG 聚合梯度为零时随机，RG/TG/AG RNG 独立且有明确 role。TG 无高阶梯度、无新参数/历史状态。κ 默认 ML.05/KR.1，λ=.5；备选不另开超参网格。

## 7. 一步训练顺序与伪代码

```text
读取训练 batch、row_id；核对 θ_k、φ_k、Adam 状态身份
optimizer.zero_grad(set_to_none=True)
若无增强有效条件：直接 source A0 forward/backward → Adam.step → EMA.update
否则：
    读取目标子批、detached embedding 和独立 RNG keys
    J1/J_SUM/TG：target probe → 两个输入梯度 → 释放 probe 图
    F1/FR：student target probe+一个输入梯度；teacher target probe+两个输入梯度
    F0：仅 student probe；F_PR：仅 teacher probe；J0：无需 probe
    构造所有 detached δ；释放所有 probe 图
    source training clean forward 全 B（保留原 gate detach）
    source training augmented forward 目标 S（通过 hook 加 detached δ）
    按 §2 合成一个精确 scalar；检查 finite；一次监督 backward
    记录 optimizer 输入梯度必要统计（不含 coupled decay）
    标准 Adam.step() 一次
    φ ← ρφ+(1−ρ)θ_new；buffers 按来源 copy
    写标量日志与 hash；不把训练状态写磁盘
每 epoch：online 与 EMA 分别完整 validation、独立选 earliest best；保存 selected/E50 RAM 快照
```

θ0 与 φ0 完全相同；EMA 每个真实 optimizer step 后更新，不按目标域出现与否跳步，不用偏差修正、不引入延迟启动。rho 固定 ML.9828205985452511/KR.995。教师只读本次 step 前的 φ，不用未来或刚更新的 θ 再回填视图。

F1/FR/F_PR 的同一个 φ 同时是教师和可评价平均模型，不再维护第二个伪“非反馈基线”影子。同一条反馈轨迹的 EMA 不等于 A0 的非反馈轨迹；A0 是独立训练对照。禁用 `ema_eval` 只禁验证/输出，不关掉教师；禁用整个 EMA 状态在 F1/FR/F_PR 中属于非法配置，须显式改为 F0，而非悄悄换教师。

## 8. Adam、稀疏活跃与空组语义

`param.grad is None` 保留 None，标准 Adam 跳过该参数更新/计数/衰减；图中显式零梯度保持为零，不能改为 None。不要为 probe 的所有参数创建零 grad。coupled decay 只在 Adam 中加入真实梯度，同时影响 m/v；不进入 donor/J/投影参考。

embedding 参数当前是 dense tensor；某 ID 本步没出现，不等于整个 tensor 的 grad=None，历史矩和衰减仍可能作用于行。不能自动改成 SparseAdam、按 ID 活跃平均或改变原稀疏语义。EMA 按全局真实 step 平均所有模型参数，不依据各参数 k_p 改时钟。

没有新 q_delta，没有递归 v，没有额外 βδ，更不把 F1 的输入梯度先做一次动量平滑再交 Adam。空域/单行/同标签单例/缺任务依 §2、§4 的确定分支处理。

## 9. 开关与退化关系

| 开关/条件 | 结果 | 等价层次 |
|---|---|---|
| augmentation=false，或 λ=0/κ=0/n=0 | 直接调用 A0，关闭额外 RNG/probe | 相同源实现，应逐步一致 |
| family=gaussian | 直接调用源 A1 | 同有效配置，应逐步一致 |
| J selector=random | J0 | 定义上精确相同，不算第二种理论 |
| J selector=mean | J_SUM | 另一个真实干预，不是等价 |
| F projection=false | F0；不执行 teacher probe | 定义上精确退化 |
| F direction=random_in_null | F_PR | 真实消融，不等于一般 F1 |
| F direction=random_energy_matched | FR | 反事实能量匹配控制，不是 F1 replay |
| J donor仅一条 / 任务梯度全零 | J1与J0该行选择相同或随机 | 行级退化，不保证全轨迹相同 |
| EMA rho=0 | φ在更新后等于θ；下步F1趋向随机回退 | 只用于CPU语义测试，不新增GPU臂 |
| 关闭教师但仍指定F1 | 抛配置错误 | 不允许静默改变方法 |

数学等价不保证不同浮点求和路径的长期参数逐位相同；关闭分支通过直接源函数调用尽量避免此混淆。不能将数值分离解释成新增机制收益。

## 10. 随机流、接口与文件建议

## 11. 默认值、有限搜索与最小验收

默认 λ=.5；κ ML.05/KR.1；J 供体最多2、αmax=.2；F gain cap=.25、SVD相对阈值1e−6、投影保留回退阈值1e−3；数值零阈值依各节。只允许 04 中一次 κ减半的条件校准，J 的 αmax、F 的阈值/cap/EMA rho 均不搜索。

最小语义测试：原A0/A1开关等价；原BT分母与尾批/空域；供体同域同联合标签且不含自身；候选等能量与α≤.2；probe数值导数完整；δ整块detach且donor/teacher无grad；Π幂等/联合残差与rank0/1/2；φ=θ时投影梯度退化；统一cap不破坏子空间；FR反事实能量；TG任务视图不重复计权；None/显式零及coupled decay；step顺序；RNG隔离；RAM恢复下一步一致。
