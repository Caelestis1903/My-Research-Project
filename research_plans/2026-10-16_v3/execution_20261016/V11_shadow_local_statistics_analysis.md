# V11 完整影子状态：四种子局部反事实统计

本报告只关闭已实际完成的局部性能统计部分。四个种子的原始影子回放、统计汇总、主代理实际核验均完成，`independent_review=false`；更新方向余弦补充回放已审查入队，完整训练状态消融仍在按冻结预算延长，不能将本报告称为 V11 全部完成。没有读取新的 v3 test 性能。

固定 native SN 的 theta 路径，用生产 SB batch 在相同 theta 重算梯度并维护影子 m/v；在1/10/40轮，同一独立当前梯度分别使用 native、swap-m、swap-v、full-shadow、beta1=0/v-only、beta2=0、m-only。所有条件同时保留原始步长及匹配同 q 的 native 全局更新范数版本。当前 q 的两种梯度各有一个冻结 draw/阶段/训练种子。四种子才是统计单位；不能把不同阶段、任务、cell 或条件当成新的独立种子。

四个原始回放各87汇总行、1044cell行；1/10/40轮参数、m、v 对原生检查点的实际回放误差全部为0，模型文件物理哈希已核对。统计产物19,836行绝对指标、71,820行差值、17,955组四种子汇总；主代理从原始六cell重构全部绝对指标、全部对比代数，再用同一冻结随机索引独立向量化重算全部均值、种子bootstrap区间和符号随机化，最大误差4.10e−16。详细凭据见 `V11_shadow_statistics_actual_primary_verification.json`。

## 更新幅度与性能地板

原始 m-only 的全参数位移范数在第1/10/40轮平均仅 .000034/.000032/.000055；native 为 .462602/.389192/.416404。前者几乎保持 BASE 的性能，因此其原始 q gap 接近零并不构成状态必要性证据。匹配范数后，m-only 的 AUC gap 变大且随阶段反号，第40轮+.0015093，四种子正，CI [.0004415,.0033208]；绝对平均 diagnostic AUC .645927低于 native .655724，训练目标 .549072高于 .456912。必须同时报告绝对性能。

原始 beta2=0 位移范数平均23.36/14.48/23.25，是 native 的数十倍；beta1=0/v-only 为1.63/2.43/2.32。这些是实际同梯度的一步反事实，不是把已长期训练的各消融模型拿来互换。长期共同50轮的 beta2=0 近随机 AUC/高训练损失（Q40）及 m-only 学习不足，不能由“gap 缩小”包装成有益机制。长期 v-only 的两臂平均 selection AUC 高于 native 是相反的有利证据，必须保留，等待其完整 matched-budget readout。

训练数据目标使用生产 float32 BCE、样本平均及任务半和；评估使用 macro cell logloss、float64 clip(1e−12)。数据人群、加权与数值截断均有差别，不能把训练 J 与评估 logloss 数值直接等同。没有修改损失、学习率或 eps 来挽救消融。

## 域、任务、大小与难度

范数匹配 full-shadow 的 AUC gap 交互在第1/10/40轮：d0为−.000039/−.000026/+.000237，最大 d1为+.000013/+.000095/−.000010，最小 d2为−.000016/+.000071/+.000089。task0 为+.000083/−.000123/+.000027，task1为−.000110/+.000217/+.000184。每个 cell 的两臂绝对指标、AUC/损失、各种加权 cell 均值以及所有反事实差值均保留。加权 cell AUC 不称作 pooled AUC。

这些局部交互的阶段、域和任务模式不一致，没有稳定“小域改善、大域受损”权衡，也不能把自然域的规模当成主因：三个物理域的规模、特征、正例率、难度共同变化，最小域不自动最难。这里未操作域大小，规模因果归因证据 WEAK；V8 已规定的 corruption 和别名 duplication 必须分别合成。

## 证据边界与接续

稳定重复的事实包括：精确原生回放；第10轮 m/full-shadow 的两臂局部绝对 AUC 改善；第10轮范数匹配 full-shadow 对训练/诊断损失 gap 的减小；原始 m-only 极小步长与 beta2=0 过大步长。矛盾证据包括仍然四负的第10轮局部 AUC gap、其他阶段反号、swap-v 原始/匹配范数的目标方向反转，以及域和任务不一致。局部状态反事实证据 MEDIUM，唯一长期 mediator 或通用救援的证据 WEAK，当前不能成立。

所有区间均为四训练种子的点状区间，未声称17,955组同时检验的FWER保证，n=4的符号随机化最小p=.125。未把区间跨零当成等效零；这些描述性不确定项不用于核心零效应关闭，因此没有以此触发或回避关键零效应追加种子的判据。所有原始种子值仍可复核。

竞争解释为历史方向、预条件幅度、局部梯度和阶段依赖，以及完整训练中不同学习进度/饱和地板。最有判别力的已安排证据是补齐 CPRE/ALL 的真实方向余弦，再结合完整预算的三种状态消融和 V7 块干预。即使局部范数控制有影响，也只能识别相同 theta 和当前梯度条件下的直接效应，无法单独确定长期 q→历史→泛化的自然间接效应。必须保持这一边界，无需为证明预设历史叙事另加未规定的调参矩阵。
