# 多机制全候选联合诊断：Codex 夜间长程执行方案

**本版取代此前的候选优先级方案。**

## 研究目标

将第一阶段研究报告中的 M1–M8 **全部作为本轮正式候选机制**，扩展为可执行的多变体诊断矩阵。目标不是先选出一个“最值得做”的机制，而是在统一数据、模型、种子、训练状态和评价协议下，尽可能全面地比较不同机制的信号、动作、局部排序效果、阶段变化和短程累积效果。

本版明确取消：
- M1 主候选、M2 次候选等人为优先级；
- M3 依赖 M2 阳性结果才执行的触发规则；
- M4/M5 仅审计、不进行机制干预的限制；
- 排除 M8 通用任务冲突控制器的决定；
- 只确认 Top-K 候选的限制。

**八个机制家族全部进入实验；每个家族均拆分多个预注册变体。** 所有机制独立运行、独立对照、独立记录。一个机制的 NO_GO 不得停止其他机制。

## 八个完整候选家族

| 家族 | 机制内容 | 本轮变体 |
|---|---|---|
| M1 | 共享更新诱导的专有梯度一致性塑形 | 方向一致性、幅度感知一致性、成对冲突能量 |
| M2 | 样本×任务条件影响 | row-task 边际影响加权、影响排序调度、负向影响抑制、任务条件权重 |
| M3 | 阶段性与组合式训练影响 | 阶段归因、组交互、阶段×组交互；不设触发门 |
| M4 | 域任务条件有害特征依赖 | 条件依赖测量、条件置换干预、任务条件残差化、HSIC约束 |
| M5 | 语义约束的多标签保持增强 | 字段遮蔽、嵌入扰动、条件类别替换、连续字段扰动、多视图一致性 |
| M6 | 输出敏感度条件化控制 | 敏感度缩放、最差 cell 信任域、参数组响应门控 |
| M7 | 跨 seed 分布影响归因 | 影响分布、均值—方差稳健分数、留一 seed 外推 |
| M8 | 多任务冲突控制 | PCGrad 对照、冲突感知权重、共同下降投影、cell/task 选择门控 |

此外，预注册五组机制交互：M1×M2、M2×M3、M4×M5、M6×M8、M1×M8。它们不是全排列，但每组都实际执行，不依赖某个家族先胜出。

## 统一实验协议

- 数据集：MovieLens、KuaiRand。
- 模型：M3oE fixed1。
- seeds：2022–2026。
- 基线：每数据集×seed 一条 50 epoch 完整轨迹；优先尝试复用 D2 完整状态，只有 live readback 通过才允许复用。
- 机制锚点：E10、E25、E40，共 2×5×3=30 个 anchor。
- 所有局部机制使用同一 anchor 的独立 fork。
- S1 筛选面板 V_A 与 S2 确认面板 V_B 均预先冻结；所有机制、所有变体均评价两者，不只评价筛选胜者。
- 所有可训练变体均进入 5 epoch 短程轨迹，不以 S1/S2 排名或 Top-K 作为短程准入条件。
- 所有通过各自预注册机制门和短程门的变体均可进入 50 epoch 完整训练，不设候选数量上限。
- Test 在方法、超参数、checkpoint 规则冻结后才开放。

## 实验规模

预注册局部诊断矩阵为 **最多 2,190 个 fork slots**，覆盖八个机制家族与五组交互。另有最多 930 条五 epoch 短程轨迹（31 个训练动作变体 × 3 个设置 × 10 个 dataset-seed 组合），以及最多 310 条五十 epoch 完整轨迹（全部 31 个变体通过时）。该数字不含 10 条基线轨迹、S3 短程轨迹及 S4 完整训练。M5 某个具体字段变换若在真实数据上不适用，必须留下 NOT_APPLICABLE 记录；不得因此跳过整个 M5 家族或其他变换。

本任务按长程可恢复作业设计：不设人为“只跑一夜”的硬截止，不因单个机制失败提前结束。所有预注册任务进入队列，按资源情况持续执行；中断后从原子 checkpoint 恢复。

## Codex 执行边界

本方案授权 Codex 自动执行 S0–S3 全部注册任务，不需要人工逐个批准机制。某一变体技术阻塞时，隔离该变体并继续其他任务。科学 NO_GO 只记录结果，不改变其他机制的执行队列。

S4 对所有通过机制门与短程门的候选逐一执行，不设 Top-K、不按研究者主观偏好排序。Codex 不得自行发明未登记机制；若运行中发现新机制，只能登记为 EXTENSION_PROPOSAL，完成独立规格审查后追加到任务清单。
