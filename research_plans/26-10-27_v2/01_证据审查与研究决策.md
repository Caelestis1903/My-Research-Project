# 证据审查与研究决策

## 1. 决策摘要

当前证据足以支持继续研究差异化读取和共享增量的可辨识性，但不足以认定多原型、低秩矩阵或动态分裂能提高性能。下一步应先测试端到端的有向关系模型及其强简单对照，避免将局部单元、显式收益估计和结构增长一次性捆绑。

## 3. 两个关键假设的判断

### H1：目标请求中存在可利用的共享需求差异

判断：**有动机，尚未被当前证据稳定确认**。ML 的需求读取有有限线索，但形成和整体增量未晋级；KR 当前版本没有同方向线索。下一轮可以直接用端到端请求条件关系检验，不需要先把“需求是否存在”当作独立大型前置项目。

### H2：显式收益反馈比最终预测损失学出的关系更有效

判断：**尚无证据支持其必要性**。普通可微关系由最终 BCE 学习，优化的是当前组合风险而非独立边际因果收益；这足以作为首轮机制。只有当关系模型有整体收益但不能区分稳定局部需求，或明确出现错误关系分配时，才追加训练范围内的反事实风险探针。

### H3：低秩关系参数化能优于完整关系矩阵

判断：**结构性效率假设，尚待实测**。低秩只约束关系张量的组合自由度，不自动节省来源函数执行成本；若参数规模极小，完整矩阵可能更稳且更简单。首轮以秩 2 为主，完整关系作为容量对照，不扩展成秩网格。

## 4. 旧版组件的取舍

| 旧版组件 | 决策 | 理由 |
|---|---|---|
| DIRECT、B_REFERENCE | 复用并重新核对实现身份 | 旧版结果显示直接预测器是强对手 |
| 固定来源读取 READ | 作为低复杂度基线 | 分离是否需要请求条件关系 |
| target-only 适配 | 作为归因对照 | 控制目标标签、可训练容量与优化机会 |
| 小 K 功能库/后继函数 | 概念复用，简化为来源基底；首轮不硬分裂 | 避免将硬原型聚类正确性设为主假设 |
| 来源教师保持/风险预算 | 仅对来源增量启用可审计轻量约束；不强迫每个局部函数在全来源全样本同样好 | 全局约束可能抑制局部专门化 |
| F1 需求回归、二叉分裂、KEEP/SPLIT 事务 | 延期 | 先证明连续条件关系的价值 |
| 显式 gain predictor、逐边因果收益网络 | 首轮不做 | 反馈估计对象依赖当前组合、归一化和重新适配 |
| full unfreeze | 不作为主线 | 共享前缀变化会改变函数坐标和来源锚 |
| 低秩关系矩阵 | 主线 | 测试跨来源关系是否存在低维结构 |
| 动态分裂 | 仅在连续模型显示稳定局部互补、但固定容量不足时触发 | 不把容量增长预设为必需 |

## 5. 研究决策

下一阶段进入核心共享机制实验，不必先完整执行旧版 F1。第一阶段回答：端到端关系是否超过固定读取与直接预测；增益是否来自来源函数而非仅目标残差头；低秩关系是否节省有效成本。若主模型没有胜过 READ/DIRECT/TARGET_ONLY，则停止当前容量扩展，不追加动态分裂或收益预测器。
