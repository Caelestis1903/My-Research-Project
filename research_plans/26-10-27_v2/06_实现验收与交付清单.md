## 2. 数学与接口验收

| 测试 | 输入/动作 | 预期输出/容差 |
|---|---|---|
| 教师身份 | 在 T0 固定样本上比较转换前后来源函数 logit | max abs diff ≤1e-6；若不使用旧教师转换，则记录实际新函数而不伪称等价 |
| 基底初始化 | 同一批输入，U=0、V 独立非零初始化 | f_sj 与 φ_s 最大差 ≤1e-7 |
| 梯度路径 | 运行小批次 BCE backward | LOWRANK_RELATION 中关系参数、w、g_dt 均有梯度张量；U 梯度允许首个 warmup 为 None/0，但联合训练时须可达 |
| 本域屏蔽 | 对每个 d 构建关系候选 | α 不含本域来源；NULL 与 foreign 权重之和在 1±1e-6 |
| mask | 人工构造含缺失任务标签的 batch | 缺失标签不贡献 loss；分母等于有效标签数 |
| 单基底退化 | 配置 J=1 | 输出形状不变，基底间局部关系消失 |
| NULL 退化 | 人工设 α_NULL=1 | 共享来源项为零，logit 等于 z0+g_dt |
| 参数分解 | 计算低秩关系参数量与 FULL_RELATION 参数量 | 数量与实际 state_dict 一致；不得把函数 U/V 参数算入关系低秩节省 |
| checkpoint 恢复 | 保存后恢复模型、优化器、RNG、row-plan/config/data hash | 同一后续 batch 的 logits 与原运行一致，FP32 deterministic 条件下容差 1e-6 |
| 数据权限 | 断言训练 dataloader 角色 | E/test 不得出现在任何 optimizer step 或超参数选择调用栈 |
| 指标 | 人工已知标签/预测 | LL 与稳定 softplus BCE 一致；AUC 以 logit 排序计算；单类返回 NA |
| 安全 audit | 无训练调用 audit/plan | 不创建模型 checkpoint、不触发训练、不修改原始文件 |

## 3. 科学诊断验收

必须输出每个域×任务的 AUC、LL、样本数、正负样本数、selected epoch、final epoch、seed、训练秒、推理 P50/P95、峰值显存、参数数、关系熵、各来源质量、NULL 质量、基底函数差异与来源约束状态。

基底差异不能仅报告 U 范数；至少报告同一固定诊断 panel 上 f_sj 的输出距离。若输出差异接近零，标记 FUNCTION_COLLAPSE；若关系变化但替换基底不改变预测风险，标记 ROUTING_WITHOUT_FUNCTIONAL_VALUE。它们是机制诊断，不自动构成方法失败之外的因果解释。

## 4. 实验完成定义

- IMPLEMENTED：接口、数据权限、训练状态和恢复测试全部通过。
- DEVELOPMENT_COMPLETE：所有预注册开发臂均完成，或逐一记录阻塞/未触发原因。
- PROMOTED：满足 05 的实用门槛且方法身份冻结。
- FORMAL_COMPLETE：所有预注册正式轨迹完成并统一评估。
- DESIGN_ONLY：只有规划，未训练。
- BLOCKED：有具体资源/数据/权限阻塞，附可复核日志。

禁止把设计审查通过写成 IMPLEMENTED；禁止把未触发 F1 split 写成 split 阴性实验；禁止删除失败/偏差记录。
