# MDMT 下一阶段研究规划 v2

**日期：2026-10-27｜状态：DESIGN_ONLY｜用途：Codex 实现与分阶段实验合同**

## 当前结论

主线选择**任务条件的来源功能基底 + 低秩关系参数化 + 预测损失端到端适配**。第一阶段固定小容量，不启用动态分裂，不训练额外的显式收益预测器。每个来源域保留一个小型功能基底，目标域/任务/输入请求通过有向关系系数读取其贡献；低秩只约束关系张量，不约束来源函数本身。该路线检验局部知识是否有条件地值得读取，不把硬原型分组正确性设为前置假设。

**备选路线：不显式建来源原型的连续共享低秩适配器。** 它以来源函数增量为基底、对目标域和任务生成连续系数，取消离散局部单元；当硬分组/多原型没有额外价值或发生坍缩时，可保留相同高层目标。

此决定不代表主方案已有效，也不代表低秩必然优于完整关系矩阵。它是成本可控、能被强对照直接证伪的首轮选择。

## 研究目标

1. 检验共享知识是否提供超过强直接预测器、固定读取与 target-only 适配的真实增量。
2. 区分来源知识内容、请求条件读取、目标任务适配、参数/正则/训练机会等替代解释。
3. 允许同一来源对不同目标域、任务和请求群体产生不同甚至相反的贡献。
4. 让关系与读取器由最终预测目标端到端学习；低频诊断只用于决策，不把门控概率称作因果收益。
5. 以实际 AUC、LogLoss、最差域任务损害和执行成本决定是否继续，而非以原型数量、非零路由或梯度差异作为成功标准。
