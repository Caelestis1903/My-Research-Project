# Agent Handoff Protocol

Parent→Astra: exact main HEAD, cycle/report paths, raw result paths/hashes, paired summaries/endpoints, diagnostics/costs, latest context files, stopped-method list, output directory. Do not paste parent transcript as research basis.

Astra→Parent: six output paths, commit SHA, chosen mechanism, full recurrence, assumption audit, alternatives, seed/epoch/batch/Test rules, budget, self-review and blockers.

Recovery: read AUTONOMOUS_STATE.json, verify main HEAD and referenced commits, resume only recorded next action. Never infer completion from a directory or partial log.
