## 5. Mathematical/algorithmic definition

### 5.1 Exact objective and gradient identities

Inputs x:[F,B] and binary y:[B,2], B>0; d=x[-1] in {0,1,2}. Ordinary probability p=model(x):[B,2]. Runtime p/y and loss arithmetic are FP32. Define source C=`F.binary_cross_entropy(p,y,reduction='mean')` over2B entries; per-entry b uses identical probability-BCE with reduction none. No logits loss, new clamp, epsilon, temperature or logit normalization.

For c=(domain d, task t), let n_a count label a, n=n_0+n_1, pi_a=n_a/n, w_c=n/(2B). For each present class a, mu_a=mean(p), v_a=mean((p-mu_a)^2), bbar_a=mean(b). Variance is centered, population divisor n_a, with differentiable mu, no detach/unbiased correction/running mean. Singleton variance is exactly0. Define S_c=pi_1^2*bbar_1+pi_0^2*bbar_0, omitting absent terms.

For two-class cells:

- Q_R=.5*((1-mu_1+mu_0)^2+v_1+v_0).
- Q_B=(1-mu_1)^2+mu_0^2+v_1+v_0.
- Q_M=.5*(1-mu_1+mu_0)^2.
- A_a,c=S_c+2*pi_1*pi_0*Q_a; A_a=sum_c w_c*A_a,c.
- L_a=(1-lambda)*C+lambda*A_a, lambda=.25.

R and B equal literal averages over all n^2 uniformly weighted ordered within-domain row pairs, including self-pairs. Equal-label pairs use (b_i+b_j)/2. Unequal-label pairs orient positive first and use q_R=.5*(1-p_pos+p_neg)^2 or q_B=(1-p_pos)^2+p_neg^2. Equal-label ordered mass pi_a^2 produces exactly S; both unequal orientations produce2*pi_1*pi_0. Expanding the independent class product gives the moments above. No n^2 tensor or sampled pair is built. M is a batch-mean objective, not the same literal per-pair loss; its independent check subtracts the variance term from literal R.

Identities at the same predictions, for values AND probability derivatives:

`Q_R-Q_M=.5*(v_1+v_0)`;

`Q_B-Q_R=.5*((1-mu_1-mu_0)^2+v_1+v_0)`;

`q_B-q_R=.5*(1-p_pos-p_neg)^2`.

B versus R changes both common-score and variance penalties; it is not a pure offset ablation. R versus M is the exact variance removal. At all p_it=.5, each arm has `dL/dp_it=(1-2*y_it)/B`, identical to source CLEAN at arbitrary class proportions: its same-label-plus-clean contribution is `(.75+.25*pi_class)*(1-2*y)/B`, its opposite-label contribution `.25*pi_other*(1-2*y)/B`. This holds for unequal class counts and one-class cells, and does not imply equal losses or general-state gradients. At .5 the R/B pair values are .5 and their pair derivatives(-1,+1).

### 5.2 Coefficient accounting and branches

For n>0, pi_1^2+pi_0^2+2*pi_1*pi_0=1. Sum_c w_c=1 and each task sums to.5. Every final row-class explicit BCE coefficient is `(1-lambda+lambda*pi_a)/(2B)`. Cell BCE mass is `w_c*(1-lambda+lambda*(pi_1^2+pi_0^2))`; opposite-component mass is `w_c*lambda*2*pi_1*pi_0`. They sum to w_c. At balanced classes and lambda=.25 these masses are .875w_c/.125w_c; at one class w_c/0. Unit mass describes mixture coefficients, not equal gradient norms/effective weight decay or class balance. Use actual tail B everywhere. The .5 in R/M and two unaveraged squared errors in B are fixed definitions.

Empty domain: contribution0, no empty mean; counts0, weight/masses0, priors/score statistics/Q/risk null. Missing class in a nonempty cell: pi_missing=0, no missing mean/variance calculation, Q_R/Q_B/Q_M null, cell risk is its observed mean BCE. Observed singleton has variance0; missing-class variance is null. Partially one-class batches retain every row and use ordinary formulas for all two-class cells. Absent class's row BCE coefficient is null since no row exists.
