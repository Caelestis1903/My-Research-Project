# 04｜下一轮实验矩阵与结果驱动决策

**新研究 ID：GA31-R3。本次交付仅规划，不启动 GPU 训练。** 本轮不执行上轮 SAGU 阶段二，不做三模块全排列。

## 1. 最小关键问题与预算

优先次序是：建立强普通 Adam 对照 → 同参数多视图识别 → 一个新视图构造的正式检验 → 有明确统计干预时才检验配对估计。动量联合算法在下一份合同中冻结。

| 阶段 | 内容 | 正式训练数 | 用途 |
|---|---|---:|---|
| A | ML/P1、KR/P0 工作基线重建，各5 seeds；ML 额外 L2-only 控制5 seeds | 15 | RAM 状态重建、简单正则化控制 |
| A-probe | 最终普通基线的同 θ/B 多视图与实际 Adam 反事实 | 0 | 最多60个锚点-batch，840次梯度计算、300次反事实 step |
| B-M | FieldMask-1，两个数据集各5 seeds | 10 | 不预设有效的独立简单视图检验 |
| B-G | 每个触发的数据集，G-IID2 与 G-ANTI2 各5 seeds | 0、10或20 | 相同边际/视图数下检验配对估计 |
| C | 条件性自适应 MASK、差分滤波或二阶矩研究 | 不在本轮授权 | 只能根据本轮结果冻结后续合同 |

**必要正式训练 25 次，上限 45 次；不自动追加 seeds 或超参数。** 对应原始 optimizer 更新数为必要39500、上限74000（不同视图计算成本另报）。不是45次全都运行：B-G 必须按各数据集的训练探针门触发。

重建不是重新挑战已接受的 GA31 阴性结论，而是因为其 RAM checkpoint 已释放，且新方法需要同一执行谱系的强基线。若未来证实有完整、可核对的源状态可用，可以替代对应重建，不把复用算作新训练；当前不能假定存在。

## 3. 阶段 A：缩放与普通正则化

| 臂 | 数据 | c | ω | ε | 增强 | 数量 |
|---|---|---:|---:|---:|---|---:|
| B-ML | ML | .1 | 1e-5 | 1e-8 | 无 | 5 |
| B-KR | KR | 1 | 1e-5 | 1e-8 | 无 | 5 |
| L2-ML | ML | 1 | 1e-4 | 1e-8 | 无 | 5 |

B-ML 对应历史 P1，B-KR 对应 P0。L2-ML 与 B-ML 的代数等价对象 c=1/ω=1e-4/ε=1e-7 仅差 ε；因此不需要再正式训练完整匹配臂。

**被区分的解释：** 普通相对 L2 增强是否足够提供 ML 的工作基线，还是 ε/预条件化差异对 selected 性能有实质作用。日志增加 ω||θ||/(c||g||)、ε/(sqrt(v_hat)+ε) 分布及按实际更新能量加权的摘要；不能仅以大量近零坐标数量宣称 ε 主导性能。

若 L2-ML 与 B-ML 的配对 selected AUC 均差绝对值≤.0005、至少4/5 seed差绝对值≤.001，且保护指标无实质恶化，记“普通 L2 在当前研究精度下可替代工作缩放”，不是总体等效检验。不要求追加数据追求绝对机制证明。

若差异明显，接受此正则化水平下 epsilon 有决策价值；首轮不追加完整 L2×epsilon 网格。是否研究该优化器细节，与增强路线是否值得继续分开。

**后续统一基线选择：** ML 在 B-ML/L2-ML 中按五种子 selected validation macro AUC 均值最大选择；差≤1e-6视为平局，取L2-ML。KR固定B-KR。选择写入 `baseline_frozen.json`；同数据集所有 B 阶段臂使用同一 optimizer 参数，从同一初始模型重新训练，不从 selected checkpoint 继续训练。测试不得参与选择。

KR 的 L2-only 跨数据集归因、ε-only、AdamW、学习率网格均可后置。已经知道 KR 不适合无条件沿用 .1 缩放，没有必要为了凑对称表先多跑一轮。

## 4. A-probe：同参数的视图随机性分解

### 4.1 来源、样本与上限

在最终普通基线的 E1、E10、selected 状态做只读诊断，重复epoch去重。2数据×5seed×最多3锚×2batch=最多60个锚点-batch。每个batch1024个真实训练样本，使用原314159确定的2048行，不按效果重选。

每个锚点固定 θ、model buffers、Adam m/v/per-parameter step。采四个独立 Gaussian 视图 ξ1…ξ4，再计算对应负视图 −ξ1…−ξ4；采四个独立 FieldMask-1 视图。真实 full-batch梯度一次、真实 target梯度一次、12个增强target梯度，共最多14次梯度计算，合计≤840。目标loss统一除以真实 |B|T；差分直接用目标增强梯度减目标真实梯度，避免非目标共同项的混淆。

所有独立视图、反向配对、字段顺序和 row_id 都有哈希。梯度统计可在 CPU FP64 计算，训练图仍为FP32；临时向量按batch释放，不保存逐步全参数数组。

### 4.2 必报统计和能回答什么

对 Gaussian 的四个正向独立视图、MASK 的四个独立视图分别报告 δ_mean、V帽、S帽、半组一致性、目标样本数、各任务 clean/aug BCE 和预测变化。反向配对单独估计交叉协方差及配对均值方差，不能把相关视图当独立样本。

报告 full-parameter δ；按 task 做诊断但不制造任务专属控制。稀有目标域导致的整体小系数如实保留，不能将 δ 重新除以目标域比例来改变实际更新。

这些统计区分稳定差分与随机波动，但不独立判断“有用”。若差分均值稳定、方差降低而 AUC 不改善，优先接受均值缺乏泛化增量，而不是再增加滤波模块。

### 4.3 实际 Adam 反事实

每个锚点-batch最多5个独立联合副本：real、G-single(ξ1)、G-IID2(ξ1,ξ2)、G-ANTI2(ξ1,−ξ1)、M-single。从相同 model+optimizer 状态各执行一次实际 Adam.step，不用裸梯度点积替代更新。raw不含 c/decay，提交 optimizer 的梯度包含 c，保留原 wd 和 None 语义。

使用两组不相交真实 validation panel。每个域打乱固定索引后取前 n_d 和下一 n_d，n_d=min(1024,floor(N_val,d/2))；每panel≤3072样本。索引种子 `271828+100*d`，全臂固定。分别报告六格 macro BCE、按完整validation域比例加权的BCE及逐格差。不在这些小panel上决定主AUC结论。

验证panel的单步效用只作机制记录；**不训练选择器、不决定 MASK 开关、不作为 B-G 的硬门**。两个panel方向不一致时报告不稳定，不再无限加panel。

### 4.4 B-G 的唯一触发规则

固定θ下令 δ_k^+、δ_k^- 为4对视图。使用样本方差/交叉协方差估计
\[
V_{anti}=\tfrac14(V_++V_-+2C),\qquad
V_{iid}=\tfrac14(V_++V_-),
\]
其中 C 为向量协方差 trace 的对称标量估计，分母K−1；V_iid对应两个独立同边际视图均值。直接对4个配对均值求样本方差应与V_anti相符。

每seed先平均两个batch，并平均 E10 与 selected 两个阶段（相同epoch只记一次），再计算 R=V_anti/V_iid。若任一stage分母近零到无法稳定计算，记录NA，不以除零产生的优势过门。

每个数据集五seed的 R 均值≤.8，且至少4/5 seed R<1，才触发该数据集的 G-IID2/G-ANTI2 各5次训练。这是**方差干预是否确实发生的预算门，不是AUC收益证明**。未过门停止这一配对构造，不扩大κ/λ网格；它不影响独立的MASK最小检验。

## 5. 阶段 B-M：固定随机 MASK 的最小正式检验

两个数据集、五seeds，`M1`相对各自冻结普通基线。每个目标样本均匀选择一个非路由 sparse field，整段Embedding置零，K=1、λ=.5。输入ID/domain/dense/标签不变，无逆保留率缩放，无辅助loss，无自适应，所有参数正常优化。

科学问题是“新输入缺失风险是否提供独立泛化收益”，不是“旧历史MASK是否被完整复现”。必要消融已经是 on/off；固定随机版本本身就是后续自适应MASK必须超越的强对照。

M1阴性：不强制保留MASK，不立即尝试所有字段组合、温度、难度预测器。M1阳性：首先保留普通Adam版本；若改成自适应，下一合同必须加入随机/概率置换对照。M1只改善LogLoss：保留概率质量效应，不称AUC算法成功，也不仅凭LogLoss认定校准机制。

## 6. 阶段 B-G：匹配边际和算力的估计器比较

只对过4.4门的数据集运行两臂。κ=.1、λ=.5、目标域、字段与Gaussian边际保持原定义；K=2。

| 臂 | 两个视图 | 作用 |
|---|---|---|
| G-IID2 | 独立 ξ1、ξ2 | 普通多视图平均，强简单对照 |
| G-ANTI2 | ξ、−ξ | 仅改变两个视图间相关性 |

两臂都以完整 L_K 合成 scalar，普通Adam一次backward/step；不得直接平均输入后只做一次forward，因为非线性模型中两者不等价。

**方法继续条件：** 相对普通基线有稳定selected增益，同时G-ANTI2相对G-IID2有额外增量，才支持“配对设计”值得方法化。若二者均改善但互相无实际差别，只接受多视图平均的价值。若仅相对旧历史单视图更好、对当前强基线无增益，不算GO。若ML换用了L2-ML，不能将跨协议差值解释为单独拯救了旧P3。

## 7. 性能评价和决策门

主端点是各run自己的validation-selected checkpoint上的test六格macro AUC，同时报告对应validation。主效应逐seed配对；mean≥+.001且至少4/5 seed正向为研究继续门，另报样本SD及df=4描述性t区间，不以CI跨0自动判等效，也不把符号多数当普适性证明。

保护指标沿用GA31：最大训练域任一任务、pooled task-mean、worst-cell若mean≤−.002且至少4/5下降，或macro LogLoss mean≥+.002且至少4/5变差，标TRADEOFF。保留实际收益但不能宣布无代价通用优越。报告全部六格、逐域、逐任务、人口加权cell与真正pooled AUC/LogLoss。

selected、共同E10、finalE50分别报告；只改善末期则不通过selected方法门。计算报告原样本曝光、增强视图数、optimizer steps、autograd次数、wall time与显存。K=2相对K=1不算等算力；G-IID2/G-ANTI2才是相同视图成本的主比较。

同一数据集、同一方法的五seed为推断单位。probe batch、task、epoch、参数坐标不是额外独立seed。两个数据集不强行汇成一个统计总体；一个成功即可保留条件性方向。

## 8. 不同结果对应的下一步

| 结果 | 接受的结论 | 研究决策 |
|---|---|---|
| L2-only接近B-ML | 普通正则化足够提供强工作基线 | 冻结简单基线，不继续围绕loss_scale造复杂方法 |
| L2-only明显不同 | 这个L2水平下epsilon有实际作用 | 记为优化条件，不将增强结果全归因动量 |
| 差分均值小、主要视图波动 | 当前视图缺乏可见稳定增量 | 不训练收益预测器，必要时停止该视图 |
| 稳定差分但一/多视图都无selected收益 | 重复性不等于有用信息 | 改构造或停止，不自动继续滤波 |
| IID2有效，ANTI2不更好 | 低成本多视图平均已足够 | 保留简单平均，不宣称配对独有收益 |
| ANTI2超过IID2及强基线 | 相同边际下估计方式确有方法价值 | 先确认适用条件，再考虑省算力时间滤波 |
| M1有效且普通Adam足够 | 简单字段正则化路线成立 | MASK可以成为方法，但无需动量新模块 |
| M1失败而Gaussian配对成功 | MASK不是必要组成 | 直接放下MASK，不维持历史偏好 |
| M1有效、跨视图均值持续而单视图噪声大 | 视图与历史可能互补 | 下一合同比较M1、M2均值、差分时间滤波 |
| 所有新视图/估计都失败 | 当前有界候选未找到selected增量 | 停止这一组，不以增加状态维度续命 |
| 某数据集单独成功 | 条件效果成立 | 描述字段数、训练阶段、正则化条件，不自动推翻 |

## 9. 第三轮：只保留有证据价值的联合实验

第三轮不是已授权运行清单。若C1或C2提供可用增强，而希望以历史替代多视图成本，先在少量连续训练步记录同支持δ的均值漂移和自相关，区分参数漂移与视图噪声，再冻结C4；最低比较普通Adam、同预算多视图平均、统一EMA/统一beta、差分滤波。β_delta、缺失梯度、warmup、窗口和预算须在该合同确定，不由本轮Codex自行选择。

若二阶预条件化才是有决策价值的差别，比较C5的ρ=0/1及一个简单ε或beta2对照，不同时堆C4。若MASK收益可能主要来自前向删除而不是梯度变化，才考虑02中的前向相同ST机制对照。MASK+Gaussian组合也仅在二者分别给出互补证据时加入，不能因存在两个模块就自动组合。

本轮完成25至45次有界训练和报告后停止；不强行追求完整三因素算法。
