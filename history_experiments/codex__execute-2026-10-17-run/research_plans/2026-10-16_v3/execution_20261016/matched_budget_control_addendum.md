# Budget matching across control factors — before V2/V4 diagnostic results

The frozen extension criterion (train objective and selection validation only) applies to an SN/SB pair; no diagnostic endpoint chooses its duration. A causal comparison must additionally compare the same completed examples/epochs across its other factors. Therefore V4 B0/2B0 comparisons use common completed epochs, and if an operational extension is needed for either batch, all four arms of that seed are carried to the common larger budget. Optimizer step counts are intentionally different across physical batch sizes and always reported.

V5 WR/PERM/ORDER controls inherit the finalized matching baseline duration per optimizer/seed. Matrix files initially list50; before their RUN, replace that duration with the completed approved baseline duration where it is greater than50, document the exact manifest delta and review it. If later evidence requires another training extension to close a control question, extend the entire compared factor set to the same budget. This does not authorize selecting the duration from diagnostic/test outcomes. All original50epoch readouts remain archived and reported; extending training cannot erase an inconvenient fixed50 result.

Corruption controls follow the same common-example rule for clean/mild/strong, with natural/balanced paired. MovieLens uses its own matched SN/SB duration and the same objective/selection stopping criterion. AdaTask and Adam comparisons retain both fixed-common-budget readouts and fully observed selected readouts, explicitly reporting any adaptive-duration difference; optimizer-state necessity is never inferred solely from unequal-budget selected values.

The primary readout rules are unchanged. These bookkeeping constraints enforce the original plan's equal-examples requirement across each compared factor. Initial manifests for unlaunched phases are preparations, not completed experiments or unconditional authorization to skip their predecessor analysis gates.
