# DESIGN SUPPLEMENT — P2-B repetition/coverage controls

Primary, before control output readout. Activated if P1 supports Adam independence; minimum diagnostic otherwise if evidence is ambiguous rather than pretending no exposure mechanism exists.

N/B are existing IID SN/SB. BX=Balanced q with uniform random permutation cycles separately within every domain; RX=Natural q with the same cyclic construction. All rows remain in support; alpha=p, importance alpha/q, optimizer/learning rate/steps/batch/split/selection/50epochs match the P1 key optimizer. Initial permutation and each renewed permutation drawn from independent seed stream. At fixed theta each position is marginally uniform within its domain. Given adaptive theta and previous draws, these dependent samples need not be conditionally unbiased. Thus BX/RX are **partial repetition/coverage controls**, not independent causal isolation of repetition, exposure and temporal dependence. Save per-domain exposure/unique/repeat quantiles and actual lag1 gradients. Fourseeds×2cyclic arms=8runs. Use SGD if P1-B; otherwise Adam for the ambiguous minimum, no test-driven optimizer choice.

UX: it is impossible to keep N updates, batch size, each row's repeat histogram AND per-domain exposure identical while q differs. Exposure_d=N*q_d and repeat totals determine exposure. An exactly matched unique-coverage intervention is also not generally possible at equal budget under two different IID q distributions. The initial overall design's capped-pool UX would alter the empirical objective and is therefore not used as a causal control. Instead perform explicit **partial matched-coverage readout**: find the first completed epoch in each existing trajectory reaching each preregistered domain coverage fraction .5/.9/.99; compare validation metrics and actual step budgets. Do not equate unequal epochs/budgets or interpolation with equal-budget causal identification. If a fraction is reached in the first epoch, mark resolution insufficient; do not invent step-level AUC.

Scientific closure: if cyclic controls reduce the B−N gap, repetition/coverage/temporal structure becomes a mediator candidate, but one must not claim exposure fully explains the effect. Stop C (exposure fully explains) requires equal-budget exposure isolation that these partial controls alone cannot establish. If all full-data coverage eventually reaches1 and a gap persists, final coverage alone is insufficient; this does not exclude early coverage. Preserve open questions for unmatched factors rather than adding an unidentifiable capped-support experiment merely to fill a table.

Implementation already exists in frozen base worker Sampler.variant=cyclic (not yet executed); review: q sampled from same common uniforms as IID; per-domain permutations exhaust every row before restart; randomized cycles; alpha/q unchanged; run config distinguishes sampler. No training file edits or algorithm additions required. Validate an isolated small-domain artificial-pool traversal before launch. This supplement narrows the initially proposed UX to an explicitly achievable partial control, with reasons recorded before any control result. It does not remove the preexisting unique-coverage question.
