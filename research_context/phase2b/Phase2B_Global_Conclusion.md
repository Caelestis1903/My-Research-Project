# Phase2B Global Conclusion（综合结论）

**Phase 2B 最终交付物**。基于 115 篇论文（推荐系统 MDL/MTL/MDMT/MoE）的全覆盖独立分析，回答本阶段的最终问题：在现有方法已取得一定效果的情况下，哪些不足真实存在、哪些能支持非平凡算法设计、哪些方向最有机会在合理的 M3OE/MDMT baseline 上提高 AUC。

**流程声明**：5 个文献分析 Agent 全覆盖提取（100% 覆盖，21 篇关键判断回查原文）→ 3 个能力图谱 Agent + 1 个限制台账 Agent 综合（13 机制族、30 条限制台账：A=20/B=10）→ 2 个谱系 Agent 独立分析增量创新关系（11 链、35 条候选边、10 个可复用模式）→ 1 个机会 Agent 生成 10 个候选 → 1 个 Prior-Work Skeptic（语料内核验）+ 1 个外部检索 Agent（与语料分离记录）→ 1 个 Red Team（10 攻击点）→ 1 个 Synthesis Agent（9 维加权排序）。全程严格信息隔离（未读取 Phase1_Preliminary_Structure、原 Phase 2、Phase 2.5、Phase 3、S0–S8 实验报告及其派生物）；P018/P024 计为同一研究。

## 一、对八项成功标准问题的回答

### 1. 哪些已有方法已经相当成熟？

- **共享-专属专家分解结构**（MMoE→PLE/CGC→M3oE 谱系，F1）：平均指标意义上的粗粒度 seesaw 控制已成熟，参数效率大幅改善（P009 掩码专家 0.64–7.38MB、P076 稀疏路由 0.6B 扩参延迟仅 +4ms），工业有效性多篇在线 A/B 互证（P058/P043/P076）。
- **场景条件化门控**（PEPNet/APG/M2M 谱系，F2）：工业 CTR 在线有效性已反复验证（P031 eCPM +3.69%、P064 +10.33%、P068 CTR +9.2%）。
- **梯度级损失权重自动化**（F4 的损失加权支线）：闭式/动态权重可得（P096/P105/P081），但绝对增益 <1%。
- **免干扰负载均衡**（F3）：P093 梯度外偏置控制在 LLM 预训练尺度机制层面解决（PPL/MaxVio 双优，DeepSeek-V3 工业放大）——但**推荐 MDMT 上未验证**。

### 2. 哪些方法仍然存在有根据的实际不足？

A 级（已验证）最扎实的五条（详见 Limitation Ledger）：
1. **LIM-04 大域牺牲**：P112 在承载 89% 样本的 KuaiRand d2 上两任务均输单域 MLP（66.03 vs 69.28，原文 Table 2 回查确认），语料内无任何"域级保护约束"机制。
2. **LIM-03 平均指标掩盖逐格退化**：30 篇有实测单格败绩且普遍不讨论，"逐格不退化"从未被写成可优化约束。
3. **LIM-02 负载均衡与专家专化冲突**：P040 实测均衡损失轻微负效果、P071 实测 aux loss 为净负担，"何时均衡、何时保护偏斜"的决定变量无人刻画。
4. **LIM-08 核心组件消融缺失/错位**：25 篇，增益归因未闭环（如 P002 主对照从未实验、P051 唯一创新无消融），向 M3OE 移植时可能搬运无效组件。
5. **LIM-16 评估协议缺陷**：P022 测试集选模型、P044/P105 数字矛盾等 20 篇，系统性高估报告增益。

### 3. 哪些不足已经被后续工作解决？

台账附 A 列出 7 项"已解决"（解决程度逐项标注），最典型的：负载均衡干扰梯度→P093（机制层面，推荐侧未验证）；激活并集爆炸→P076（工程层面）；两阶段原型冻结→P040 端到端 STE；新任务全量重训→P056（部分，仍损失 0.3–4.5%）。**注意**：所有"已解决"都带未解决的尾巴，无一完全闭环。

### 4. 过去成功发表的增量算法工作究竟创新在哪里？

谱系分析（35 条候选边核验，约半数为平行分支而非继承——已如实标注）抽象出 10 个可复用模式（见 Incremental Innovation Map）。被引用最广的改进满足三特征：(a) 指认前代机制的**具体可核验失效条件**；(b) 改动集中于**一个核心算法操作**；(c) 配备**排除容量/调参解释的对照**。反例同样明确：无"原作用点失效"实证的作用点迁移（P096 方向+幅值扩展）说服力最弱；硬切断式解耦的收益随架构成熟度递减（P069 组件最弱、P091 消融噪声级）。

### 5. 哪些剩余不足能够支持新的非平凡算法设计？

Red Team 结论：10 个候选中 **2 个 SUPPORTED + 8 个 PROMISING BUT UNVERIFIED，0 淘汰**（零淘汰是证据结论：无候选触发"已被完全解决/失败条件不成立/实质等价/无法连接 AUC/需引入额外任务/简单方案已足够"任何一条淘汰规则）。

### 6. 哪些研究方向最有机会在合理的 M3OE/MDMT baseline 上提高 AUC？

最终排序（9 维加权，权重偏向问题真实性、算法实质贡献、性能机会）：

| 名次 | 方向 | 总分 | 判定 |
|---|---|---|---|
| 1 | **AO-01 逐 (d,t) 格 AUC 下限约束的 MDMT 训练目标** | 4.40 | SUPPORTED |
| 2 | **AO-05 三族可分解掩码的参数高效 M3OE** | 4.25 | SUPPORTED |
| 3 | AO-02 偏斜流量下双维路由的均衡目标重定义与梯度外控制 | 3.65 | PROMISING |
| 4 | AO-03 梯度干预必要性测量与条件化触发 | 3.55 | PROMISING |
| 5 | AO-09 稀疏部署形态下的训练-推理一致性学习 | 3.50 | PROMISING |

入选先导实验的即前五名。落选者（AO-06/04/07/10/08）的主要原因：防御性定位不承诺 AUC、外部占位压力（CESAA）+公开数据域数不足、危害假设全链 B 级、先导成本不再便宜、存在性前提未测。

### 7. 哪些方向只需要小规模验证，哪些需要较大投入？

- **小规模验证即可启动**：AO-01（MVQ 只改训练目标）、AO-03（仪表化成本极低，结果双向有价值）、AO-02（MVQ 为纯测量且自带终止闸门）、AO-09（推理期 k-sweep 损失矩阵，判据可预注册）。
- **需要较大工程/理论投入**：AO-05（需先定稿同预算三方对照协议）、AO-08（增量协议+遗忘度量体系本身是贡献但也是工作量）、AO-10（LLM 缓存使先导不便宜）。

### 8. 证据具体不足在哪里？（如实声明）

- 全部 8 个 PROMISING 方向的存续都依赖一个尚未验证的前提（如 AO-02 依赖"M3OE 双维路由真存在塌缩/错配"、AO-03 依赖"冲突量-逐格退化单调关系"），这些前提的测量就是各自的 MVQ。
- 外部核验显示 8/10 方向存在相近工作（OVERLAP），仅 AO-07、AO-10 在检索范围内 CLEAR；所有外部判定仅覆盖检索范围，不构成全球新颖性声明。
- 语料以 2024–2026 论文为主，经典工作（MMoE/PLE/PCGrad 等）经转述了解；约 20 篇 venue/year 不明；工业私有数据结论（含多个 SUPPORTED 依据的线上数字）外部不可核验。

## 二、最值得验证的研究问题（主 Agent 综合）

**首要推荐：AO-01（逐格 AUC 下限约束）与 AO-05（三族可分解掩码）并行推进，共享一个前置实验**——在公平协议（验证集选模、多种子、统一调参预算，吸取 P022 教训）下复现 P112 的 d2 失效格。Synthesis Agent 的敏感性分析显示：若公平协议下 d2 退化收窄至噪声，AO-01 的 Performance Opportunity 从 4 降为 3，第 1/2 名顺序反转。这个前置实验同时裁决两个 SUPPORTED 方向的立项依据，是全部后续工作性价比最高的一步。

**AO-01 的直接动机**：M3OE 的双层 α/β 学习以平均损失为目标，框架内无任何机制阻止其牺牲大域（P112 d2 实测）——将约束式优化（CPO 式逐格下限，与 GroupDRO/tDRO 的重加权路线切割）转写到 M3OE 融合权重学习，干预点单一、失效条件可核验、与骨架直接兼容。

**AO-05 的直接动机**：P040 全 DNN 专家在线 OOM（作者自述降级 LoRA）、P072 参数 2.85×，而 P009 已证"单基网络+掩码=专家"可行——把掩码分解扩展为共享⊙域⊙任务三族结构（与 P005 三路解耦、P092 域+共享专家同构结构的划界已补齐），贡献定位为"同性能更低成本/同成本更高性能"，自带同预算判别对照。

## 三、尚存争议与分歧（如实保留）

1. **AO-01 vs AO-05 的第 1/2 名顺序**对 AO-01 的 Performance Opportunity 单分敏感（见上），Synthesis Agent 已标记，主 Agent 判断该分歧应由前置实验裁决而非再讨论。
2. **梯度族方法的真实价值**（AO-03）：CM 分析指出 P091 的噪声级 detach 消融暗示"结构软隔离已存在时梯度硬隔离边际很小"；Red Team 则认可其仪表化价值（双向结论均有意义）。分歧点在于：否定性结果是否足以支撑算法论文——本团队按"算法贡献落空风险"处理，列为 PROMISING 而非 SUPPORTED。
3. **均衡目标的重新定义**（AO-02）：P040 与 P071 的实测证据方向一致（均衡损失有害），但两者均非 MDMT 双维路由设定；该方向 50% 的价值取决于一个纯测量先导实验的结果。
4. **P069 的 Beibei +49.91%** 数字经原文核实无误但幅度异常，文献分析 Agent 建议下游引用保留疑虑——凡依赖该证据的推论在候选中均未作为关键支柱。

## 四、下一阶段建议（进入先导实验前）

1. **共同前置**：公平协议复现 d2 失效格（裁决 AO-01/AO-05 排序）+ M3OE 双维路由的负载/塌缩测量（AO-02 闸门）+ 冲突量-逐格退化相关性测量（AO-03 闸门）。三者均为纯测量实验，可同一批 runs 完成。
2. **协议纪律**：所有先导实验采用验证集选模、多种子、逐 (d,t) 格全指标报告（含 LogLoss），并预注册终止判据——直接回应 LIM-16/LIM-03 两条 A 级方法学缺陷，本身即可作为论文的可信度贡献点。
3. **写作纪律**：各方向的 Closest-Work 划界已在候选文档第 9 节落实（含外部工作），投稿前需对 AO-02（Loss-Free 移植线）、AO-04（CESAA）再做一次检索更新。
