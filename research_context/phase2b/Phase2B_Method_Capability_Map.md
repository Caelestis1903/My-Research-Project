# Phase2B Method Capability Map（方法能力图谱）

**Phase 2B 阶段一交付物**。本文档独立重建（不继承 Phase 1 的 RP/M/G/RS 分类体系）115 篇论文的机制族划分，并按族回答 11 个问题：试图解决的问题、谱系、核心机制、自适应信号、改变变量、有效条件、已达性能、可靠负面结果、未解决限制（A/B/C 证据分级）、后续改进程度、以及在 MDMT/M3oE 场景下的潜在算法空间。

**分析方法**：5 个文献分析 Agent 分批全覆盖提取全部 115 篇论文（P018/P024 计为同一研究），3 个能力图谱 Agent 按族综合，主 Agent 统筹与一致性审查。证据等级口径：**A**=已验证不足（原论文、独立对照或后续研究直接展示）；**B**=机制推导不足（设计可推导但无直接实验确认）；**C**=探索性假设。

**跨族全局发现**（主 Agent 综合，详见各族章节与 Limitation Ledger）：

1. **"平均指标最优掩盖逐（域,任务）退化"是全语料最普遍的方法学缺陷**（30 篇有实测单格败绩），且语料内没有任何方法把"逐格不退化"做成可优化约束——这直接打在 M3oE 骨架的已知软肋上（P112 在承载 89% 样本的大域 d2 上两任务均输单域 MLP）。
2. **基准证据系统性削弱结构族的性能声称**：公平调参协议下 SharedBottom 与 MMoE/PLE 差距 <0.3%（P022）、无单一赢家（P006）、朴素多域联合训练崩溃 −60~75%（P038）。任何 M3oE 上的新算法声称必须先过统一协议强基线关。
3. **"代理指标=机制"的因果验证全线缺失**：熵=难度、路由一致性=性能、专化指标=下游收益、HSIC 下降=干扰消除等关键等价声称全部止步于相关性证据。
4. **两条最干净的"路由-任务优化解耦"路线（P093 梯度外偏置、P090 分布后验路由）全部停留在 LLM/VLM 侧**，在推荐稀疏 ID 特征与 AUC 目标下零验证——这是跨社区迁移的明确空位，而非"已有方法已解决"。
5. **结构与优化的交互是空白**：梯度级干预族全部只作用于共享参数，而 P091 的 detach 消融增益仅噪声量级（0.0003），暗示门控软隔离存在时梯度硬隔离边际很小——两类方法在同一 MDMT 骨架上的交互曲线无人测量。

## F1 共享-专属专家分解结构族（MMoE/PLE/CGC/M3oE 谱系）

**Q1 族问题**：多任务/多域共享参数引发梯度冲突与负迁移/seesaw——MMoE 全共享专家缺差异化（P009/P021），PLE/CGC 固定绑定致表示同质（P043 的批评）与工业三异常（塌缩/退化/欠拟合，P058），MDMT 下纯 MDR 与纯 MTR 互不泛化（P112 Fig.1 实证）。

**Q2 谱系**：语料以 MMoE/PLE/CGC 为被改基座；族内最早一批为 2024 年的 P009（掩码专家）、P058（HoME 工业三件套）、P112（M3oE，SIGIR'24 MDMT 骨架）；后续代表为 P081（场景×任务双层 CGC）、P072（嵌入表级专属化）、P043（细粒度 omni-specific 池，2026）、P076（两段式稀疏路由）。

**Q3 核心机制**：显式划分共享/专属参数组+门控加权融合；沿四个方向演化——实现方式（独立子网→二值掩码 P009）、粒度（专家层→嵌入表 P072）、绑定（固定→共享池 Top-K P043、两段路由 P076）、结构（单层→双层 CGC P081、三类专家+两级融合+双层优化 P112、零共享硬专家 P086）。

**Q4 自适应信号**：主体是实例级输入门控（全部）；训练动态信号稀少——仅 P112 用 mini-batch 损失双层优化 α/β、P050 按交互频次阈值；人工先验信号占比高（P058 任务分组、P076 K_s/K_a）。

**Q5 改变变量**：参数共享拓扑与边界（P112/P081/P086）、专家实现与存储（P009 模型 0.64–7.38MB vs MoE 类约 39MB）、嵌入表归属（P072）、路由集合构造（P076 去重并集上界 K_s+T·K_a）、梯度路径（P072 前向全通反向断）。

**Q6 有效条件**：域/任务间确有可分解的共享与特异知识（P112）；过参数化冗余存在（P009）；专家输出分布对齐使门控可比（P058 BN+Swish）；稀疏单元数据量足以支撑专属专家（否则欠拟合，P058/P112 d2 反例）。

**Q7 性能**：相对 MMoE/PLE 的平均 AUC/GAUC 典型幅度 +0.3%~0.8%（P058 +0.52% GAUC；P043 工业 GAUC +0.61%；P076 0.6B 扩参 +0.84%；P112 总体 77.02 vs 76.35）；线上 +0.2%~2.5%（P043 VV +2.47%、P058 稀疏任务 Comment +2.12%）。证据：P043/P058/P076 有在线 A/B 但单平台私有数据不可复现；P112 5 seed+t 检验但仅 3 域×2 任务；P052 无消融无显著性，最弱。

**Q8 可靠负面结果**：P112 大域 d2（89% 流量）两任务低于单域单任务 MLP（66.03 vs 69.28）——平均最优牺牲大域；P058 承认朴素 MMoE 在流式数据 fragile；P021 Census 增益仅 0.001 且作者承认专家冗余无最优解；P086 JData 分项输 MULE；P062 Browse Ads 一格联合建模不如单模型；P043 is_forward 输 PLE。

**Q9 未解决限制**：
- [A] 大域/主导单元保护缺失：P112 框架内无任何约束阻止 α/β 学习牺牲大域；P086 零共享划分的数据集相关失败说明划分准则无普适性。
- [A] 结构超参全面人工且无选择原则：专家数与共享比例（P058 分组、P076 K_s/K_a/w_t、P050 K=18/10/14、P009 E=8）。
- [B] 「解耦」无量化度量：无互信息/独立性指标（P112 仅 t-SNE 示意、P050 因子语义未验证、P021 过滤因果未分离）。
- [B] 平均指标报告掩盖单格退化：P043/P062/P112 均有未讨论败绩格子。
- [C] 扩展成本：P112 门数随 D×T 增长、P072 参数 2.85×；P076 稀疏化部分缓解但引入新人工旋钮。

**Q10 后续改进程度**：PLE 固定绑定→P043 omni-specific 池（FLOPs 降至 57%，但公开集消融缺失）；塌缩三异常→P058 三件套（工业验证但零复现）；参数冗余→P009→P076（0.6B 扩参、延迟仅 +4ms）；专属化下沉嵌入→P072 首次让 Like 任务正迁移（代价参数翻倍）；M3oE 骨架→P044 复用其塔（真实 +0.43%，摘要夸大 10 倍需核表）。**已解决**：平均指标意义上的粗粒度 seesaw 可控、参数效率大幅改善；**有缺陷解法**：人工分组/比例（解法本身引入新先验且敏感）；**未解决**：大域保护、结构超参自动化、解耦度量。

**Q11 MDMT/M3oE 潜在空间**：逐 (d,t) 格子 AUC floor 约束嵌入双层优化（直接针对 P112 d2 退化）；三类专家细粒度化+Top-K 路由（P043 路线入 M3oE）；单基网络+共享/域/任务三族可分解掩码（P009 扩展）；结构超参可学习化（稀疏诱导或 NAS）；域嵌入表×任务嵌入表二维专属化的预算分配（P072 扩展）。

## F2 条件化门控与动态参数生成族（PEPNet/APG/M2M 谱系）

**Q1 族问题**：域/任务只有 ID 指示缺语义，门控区分力受限致 seesaw（P031 Finding 1/3：MDMT 基线在华为数据不如单域多任务）；静态统一参数无法逐样本逐场景适配（P064/P068）；跨场景迁移需条件化通道（P114/P077）。

**Q2 谱系**：语料外前驱 PEPNet/APG/M2M 被反复引用为基线；族内代表 P064（显式+隐式场景动态权重）、P063（触发器 Dynamic Weight）、P068（行为级缩放）、P031（对比增广三级门控）、P015（LLM 知识经 meta 网络生成层参数）、P054（生成式权重注入+DBO 加权）、P113（场景动态权重+DSBN）、P114（域条件注意力 gate+MMD+MAML）、P077（VQ codebook+GLU）。

**Q3 核心机制**：条件信号经 meta/超网络生成权重、偏置、缩放向量或门控输入。两支：(a) 生成参数——P054 DSFS+DF 注入 backbone 变换层、P064 场景嵌入 reshape 为层权重、P015 LLM 隐状态 reshape 为 meta 层；(b) 生成调制——LHUC 式逐单元缩放（P068/P113）、域感知偏置门改激活（P031）、逐层 GLU（P077）。

**Q4 自适应信号**：场景/域嵌入（P064 实为域级——同场景全样本条件相同）、实例特征+序列（P068/P037）、对比增广表示+可学锚点（P031）、LLM 隐状态（P015）、用户×场景序列 VQ 匹配（P077）、域 embedding+MMD 统计（P114）。

**Q5 改变变量**：前向权重来源（静态→生成）、门控输入（ID→语义表示）、归一化统计量（P113 逐场景 DSBN）、损失构成（+对比 P031/P063、+MMD P114）、标签空间（P063 全局标签条件概率分解）。

**Q6 有效条件**：场景语义可从行为对比或文本提取（P031/P015）；场景特征足以编码差异（P068）；数据分布复杂度高时收益大（P064：Ali-CCP RelaImpr 6.18% >> KuaiRand 1.14%）；稀疏/低频场景收益最大（P015 Amazon 稀疏场景 +40%、P077 K4、P113 S-6/7/8）。

**Q7 性能**：P031 全部域×任务格最优+控制信号消融直接验证假设+线上 eCPM +3.69%（族内最强证据）；P064 Ali-CCP RelaImpr 6.18%+在线 eCPM +10.33%；P068 在线 CTR +9.2%；P114 在线 CTR +3.56%；P063 24 格全提升。弱端：P054 绝对提升仅 0.001–0.005 AUC 且无线上；P037 三模块各约 0.004 AUC；P015 提升极不均匀（Rec#1 +40% vs Rec#2 +0.7%）。

**Q8 可靠负面结果**：P113 Scenario-3 上完整模型差于自身三个消融变体（0.7785 vs 0.7828/0.7811/0.7836）——模块净效应为负的直接证据；P064 KuaiRand 增益大幅缩小（作者归因数据复杂度）；P114 域内 finetune 反降性能（0.7221 vs 0.7241）；P015 Rec#2 增益微弱；P031 基线侧 MDMT 负迁移实证（Finding 1/3）。

**Q9 未解决限制**：
- [A] 条件信号的「语义性/必要性」未分离：P031 缺「无对比损失的同结构增广」对照；P015 +40% 巨升无机制归因；P064 隐式场景实为域级固定掩码而非逐样本自适应（叙事-机制落差）。
- [A] 模块有效性场景条件化：P113 三模块在 S-3 净效应为负，且无逐场景机制开关。
- [B] 生成参数稳定性无分析：P064 多头无防冗余正则、P054「注意力熵=域复杂度」是定义而非测量、P114 MMD 对齐无前后分布证据（且术语与对比学习混用）。
- [B] 超参群手调：P063 λ1–4 手工、P031 λ1/λ2 量纲不同需分调、P054 DBO 需手工延迟至 50%–75% 训练后启用。
- [C] 新鲜度与扩展：P015 新用户/新场景需重跑 LLM（每用户 2–4s）；P064/P054 仅 2–3 场景；P114 MAML 二阶开销在 D×T 规模未量化。

**Q10 后续改进程度**：PEPNet/DTRN→P031 层级化+增广信号（控制信号消融是族内最干净因果检验）；M2M/APG→P063/P064（触发器+stop-grad、显式隐式层级）；P068 把粒度细化至行为级（在线 CTR +9.2%）；P015 把条件来源换成 LLM 语义（稀疏域巨升但不均匀）。**已解决**：场景条件化在工业 CTR 的在线有效性（多篇 A/B 互证）；**有缺陷解法**：增广必要性未分离、模块逐场景开关缺失；**未解决**：条件信号质量的可计算判据、域×任务二维联合条件化（族内多单任务）。

**Q11 MDMT/M3oE 潜在空间**：两级门控条件从 ID/原始特征升级为语义增广表示，且对比增广（P031）与 LLM 增广（P015）的正面对照是语料空白；可学域/任务锚点同时作门控条件与正则目标；逐 (d,t) 机制开关（P113 教训）；显式域层+隐式簇层叠加域专家（P064 路线）；「语义增广何时有价值」的价值预测器。

## F3 MoE 路由信号、负载均衡与专家专化族

**Q1 族问题**：路由信号退化（近均匀分配、gate degeneration，P057）、专家塌缩/冗余（P061/P071）、负载均衡与专化两难（P090 富者愈富梯度分析；P093 的 α 两难）、辅助均衡损失污染主损失（P071：w/o all 优于 only aux）、路由与任务梯度耦合（P090/P108）。

**Q2 谱系**：语料外前驱 Switch/GShard/LBL；推荐侧代表 P057（主题 codebook 路由）、P040（原型硬路由+STE+防塌缩双损失）、P042（熵驱动动态 top-k+低门控专家回收）、P028（频率条件路由）、P007（类目误差信号）、P016（时间条件）、P001（簇标签硬绑定 router）；LLM/VLM 侧 P061（路由 Gram 正交）、P071（输出正交+路由方差）、P093（梯度外偏置控制）、P090（GMM 分布路由+sg 解耦）、P108（梯度冲突改派）。

**Q3 核心机制**：三条机制线——(a) 路由信号升级：内容→簇标签/主题 codebook/频率成分/类目误差/时间嵌入/GMM 后验/梯度夹角；(b) 均衡机制：辅助损失→梯度外偏置（P093）、分布拟合涌现（P090）、路由几何正交（P061）、熵目标（P033）；(c) 专化约束：专家输出正交+路由方差最大化（P071）、簇内紧致+簇间分离（P040）。

**Q4 自适应信号**：token/样本表示（全部）、vMF 簇后验（P001）、FFT 频率成分（P028）、逐模态类目预测误差（P007）、时间 embedding（P016）、预测熵+门控熵 EMA（P042）、历史负载计数（P093）、专家内梯度夹角（P108）、GMM 后验（P090）。

**Q5 改变变量**：路由概率的输入与参数化形式、路由参数的梯度来源（P090 sg 切断任务梯度）、均衡注入位置（损失内→梯度外）、每任务 top-k 大小（P042 动态）、专家实际所见输入（P028 滤波成分、P057 主题子序列）。

**Q6 有效条件**：路由信号真实可分（P016 Games 时间分布均匀→增益缩至 +2.53%）；K/主题数与真实结构匹配（P057 错配即失效）；sg 后重构保留路由所需结构（P090）；天然偏斜分布不应被均衡（P040 实测负载均衡损失轻微负效果）。

**Q7 性能**：P042 5 数据集 Avg AUC 全最优（75.20 vs HoME 74.76）；P057 平均 +0.68% AUC、FLOPs 仅 53%；P040 三组场景全最优+线上长尾订单 +6.3%、原型利用率 75% vs 40%；P061 收敛快约 36%；P071 92.42% 任务超所有基线；P093 MaxVio 0.04 vs 0.72；P028 平均 +8%；P007 +4.5%~21%。证据强弱：P040/P042 有工业线上；P061/P071/P090/P093/P108 均为 LLM/VLM 侧 PPL/准确率，向推荐 AUC 的迁移未验证；P052 无消融，最弱。

**Q8 可靠负面结果**（族内最丰富）：P040 负载均衡损失轻微负效果；P071 无辅助损失反优于有；P090 GQA 明确回退（58.3 vs Dense 60.6）；P042 Share 任务输 MMoE；P057 SDIM+Ebnerd 负增益；P108 部分子指标回退；P033 训练-测试负采样失配跌至 0.3694；P001 簇数 G 过大 BLEU-1 22.66→14.96 崩塌。

**Q9 未解决限制**：
- [A] 「代理指标=机制」因果链全线缺失：路由一致性→性能（P057）、熵=难度（P042）、专化指标→下游（P071）、PES↓→PPL↓（P061）均止步相关性，5 篇独立同病、无一干预实验。

- [B] 均衡目标形式未统一甚至错误：KL-to-uniform 与「按内容强调」结构性矛盾（P079）；偏斜分布上均衡有害（P040）。
- [B] 训练-推理不一致：P028 训练全专家激活 vs 推理 top-1 的差距未量化。
- [B] LLM→推荐迁移未验证：稀疏 ID 特征的 GMM 可建模性、AUC 目标下 decisive 路由收益、偏置控制 vs P076 聚合正则孰优，全部开放。
- [C] 开销未报价：P108 每 batch 额外全专家反传；P042 503s/epoch；P028 O(K²M) 对比成本。

**Q10 后续改进程度**：LBL→P093 偏置控制（MaxVio 0.72→0.04）→P090 分布后验 / P061 几何正交（收敛 +36%）→P071 专化恢复——LLM 侧形成互相引用的完整改进链；推荐侧 P057 治 gate 退化（路由一致性实证）、P040 治原型塌缩（定量利用率证据）、P042 回收低门控专家（MVKR 消融贡献最大）。**已解决**：免干扰均衡（LLM 预训练尺度）、塌缩定量防护（推荐单域）；**有缺陷解法**：熵目标/阈值仍需手扫（P033 H*、P042 κ/θ）、P093 偏置无收敛理论；**未解决**：两条 LLM 解耦路线在推荐 MDMT 零验证、K 自适应、因果干预实验范式。

**Q11 MDMT/M3oE 潜在空间**：「域×任务×专家」三维负载统计接入梯度外偏置控制（P093 移植）；任务梯度+分布后验双通道路由（P090 GQA 教训的正面回应）；两级门控 Gram 约束防跨域混洗（P061）；三类专家组内正交+门控方差正则（P071）；专家内梯度一致性作共享专家诊断与正则（P108）；EMA codebook 域簇心锚定（P057）；簇内紧致+簇间分离替代负载均衡的 MDMT 门控训练（P040 警示）。

## F4 多任务梯度与更新级优化族

**Q1 族问题**：共享参数上多任务梯度方向冲突与量级悬殊（P096/P085/P101 共同动机）；动量优化器下最优联合梯度≠最优参数更新（P105 RQ）；联邦隐私约束下梯度不可得（P005）；顺序/混合目标的依赖与干扰（P017/P085）；跨任务反向梯度污染（P091）；辅助任务噪声抽血主任务（P101）。

**Q2 谱系**：语料内最早为 P017（2024 WSDM 两页，静态损失衰减）；代表方法 P096 GradCraft（KDD'24，幅值+方向闭式）、P085 HTLNet（核心锚定）、P105 PUB（更新空间 Nash）、P101 DRGrad（方向条件化增量路由）、P094 STGU（在线亲和分组顺序更新）、P091 OneRank（KDD'26，跨任务 detach）、P005（联邦参数代理 CAGrad）。

**Q3 核心机制**：三类——(a) 梯度整形：幅值向最大范数拉近+全局闭式投影（P096）、核心任务锚定投影+量级截断（P085）、按梯度余弦符号分四情形的增量叠加（P101）、按静态任务距离指数衰减损失（P017）；(b) 更新空间：优化器态变换+Nash bargaining 合成（P105）、在线亲和分组 Gauss-Seidel 顺序更新（P094）、参数差代理+CAGrad（P005）；(c) 路径隔离：跨任务注意力对角 detach（P091）、stop_gradient（P085）。

**Q4 自适应信号**：每 batch 实时梯度方向/范数（P096/P085/P101）、经优化器动量态变换的更新（P105）、同 batch 损失变化亲和度（P094）、相邻轮聚合参数差（P005）；仅 P017 用静态任务距离（无动态信号）。

**Q5 改变变量**：进入优化器的聚合更新向量（方向+幅值）、更新顺序（P094）、反向传播图（P091/P085）、优化器状态本身（P105 动量按 α 加权）、损失有效权重（P017）。

**Q6 有效条件**：梯度余弦符号可靠指示冲突/协作（全族共享假设）；核心任务适合作锚（P085）；任务更新在非 Pareto 点线性独立（P105）；任务关系变化足够慢（P094）；客户端结构同构且数量少（P005，2–4 个）。

**Q7 性能**：幅度普遍小但真实——P105 平均 AUC 显著超 backbone（80 个基线组合仅 2 个超）+线上 eCPM +4.06%，144 组统计+卡方检验（族内最强证据）；P101 工业 click AUC +0.0027+线上 CTR +1.79%；P096 RI-A<1%+在线 WT +0.505%（无显著性检验）；P085 在线 CTR +0.54%/CVR +1.4%；P091 C-AUC 0.7910 vs 0.7773+在线 GMV +1.01%；P017 仅 +0.01 量级且零消融；P094 Δm 最优但仍为负。

**Q8 可靠负面结果**：P094 所有 MTL 方法 Δm<0（未超单任务，领域级强证据）；P096 逐任务回退（Forward 0.9001<EW 0.9012）；P105 US-CTCVR 回退且效率数字矛盾（正文称快 52.94% vs 表格仅 7.3%）；P101 真实系统 14 任务仅 11 提升；P091 detach 消融差 0.0003 为噪声量级；P005 多个格子输集中式 PEPNet 且专家数稍增即个别格子崩塌。

**Q9 未解决限制**：
- [A] 核心机制的消融证据薄弱：P091 detach 增益噪声级、P096/P101 全程无冲突量测量曲线（梯度证据为观察性）、P017 零消融、P105「梯度-更新偏离→seesaw」仅 67.36% 统计相关。
- [A] 平均指标掩盖逐格子回退（P096/P101/P105 同病）——逐 (d,t) 最差性能目标下现有结论大半需重审。
- [B] 只操纵共享参数：任务私有/域专属通道冲突无干预（P096/P105），而 P091 提示私有通道可能更重要。
- [B] 成本随任务数线性：P105 每步 n 次反传、P094 每步 M 次前向——D×T 规模下不可行。
- [B] 不对称路由无回馈：P101 辅助任务只被抽血，长期退化风险未量化；ξ≈0 处硬切换稳定性未讨论。
- [C] 域外外推：P094 仅视觉、P017 骨干不明；AUC 为在线指标，batch 级亲和度估计信噪比未知。

**Q10 后续改进程度**：PCGrad→P096 全局闭式+幅值前置（含 ε=0 退化等价证明）；NashMTL→P105 更新空间（同枱对照胜出）；静态亲和→P094 在线化；CAGrad→P005 代理空间（联邦化）；MetaBalance→P085 锚定扩展。**已解决**：共享参数上的方向+幅值联合整形有闭式解、更新空间视角确立；**有缺陷解法**：锚定核心任务引入单锚点脆弱性（P085）、不对称抽血（P101）；**未解决**：冲突直接度量仪表化、私有参数通道干预、任务数 >6 的数值稳定性、显著性报告规范。关键互证：P091 的微弱 detach 消融提示——结构软隔离（门控）已存在时，梯度硬隔离边际很小；F4 与结构族的交互是空白。

**Q11 MDMT/M3oE 潜在空间**：按参数组（共享/域/任务专家）分层梯度处理协议（P105 逐组求解 α）；把业务优先级编码为 (d,t) 格子优先级矩阵驱动的双向有预算梯度路由（P101 改造）；冲突量/幅值比/梯度-更新偏离 Diff 的在线监控仪表化（P096/P105 信号复用，补证据链）；低频 α 重解与 M3oE 双层优化节奏统一；「detach 收益 × 门控隔离强度」交互曲线——决定梯度族方法在 M3oE 上的真实边际。

## F7 参数高效适配、增量与持续学习族（P010, P013, P019, P020, P046, P056, P075, P095, P103）

**6. 有效条件**：文本语义可得且质量好（P051 因 Ali-CCP 匿名化弃用该集）；跨域用户重叠（P099/P103）；域均值初始化有效（P092）；CF embedding 质量构成上限（P060）；簇结构稳定（P001 稀疏高维下 GMM 退化是其动机）。

**7. 已达到性能**：稀疏/新域提升巨大——P015 Amazon 稀疏域 0.6156→0.8720；P051 零样本域 >+6 点；P092 Toys NDCG +51.89%；P104 新域 NDCG@1 +8.7%–18.1%；P103 +4.28%–11.12%；P111 线上 GMV +7.84%。但证据普遍偏弱：单种子、缺显著性（P023/P099/P104），P001 的 BERT-F 异常跳升被标记；有 AUC 证据的仅 P015/P051/P023-ranking，其余全为生成/检索指标。

**8. 可靠负面结果**：P099 规模 >100M 域内饱和、LoRA 在小模型显著劣于全量微调；P104 零样本 Arts 上预训练有害、Sports/Movies 输 UniSRec；P060 Movie-Lens U-AUC 输 SASRec、换 load-balancing 无收益；P023 最大域被 ID 基线反超、与强 ranking 骨干组合收益下降；P015 提升极不均匀（Rec#2 仅 +0.7%）；P001 router 数过大崩塌；P092 Games 仅 +1.49%；P103 跨平台零样本明显弱于同平台。

**9. 未解决限制**：(a) "世界知识 vs 数据增量"贡献不可分离 [B]（P099/P103 均无打乱标题反事实）；(b) 单一 LLM+人工 prompt 敏感性未系统评估 [A]（P015 仅 GPT-2 失败单例）；(c) 新用户/新场景需重跑 LLM 推理 [B]（P015 每用户 2–4s，只能离线缓存）；(d) 域集合动态扩展未闭环 [B]（P092 新域专家机制未讨论；P051 仅 3+1 域）；(e) 多任务实为数据混合、无平衡机制 [B]（P111 未测 7 任务干扰）；(f) 关键组件消融缺失 [B]（P051 masked loss 无消融；P023 MoE adapter 未分离）；(g) 指标口径风险 [C]（P001 BERT-F；P111 SID 级 HR 高估物品级命中）。

**10. 后续改进程度**：P103 以 CPT+WSA 回应 P099 的模态鸿沟与单域 SFT 坍缩；P104 系统化文本构造（Books 加属性 NDCG@1 24.08→39.35）；P092 统一 tokenizer 参数降 9.63 倍且零样本有效；P060 补 CF 融合与多任务解耦；P111 指令化统一 7 业务任务。改进集中在工程与数据组织；核心混淆（知识 vs 数据）与公平协议下 AUC 验证无任何后续补做。

**11. MDMT/M3oE 潜在空间**：域/任务语义描述→LLM→M3oE 门控偏置与专家初始化（P015/P051，新域零样本参数生成）；LLM 语义表征作共享专家初始化（P099）；MI 方差惩罚移植为域专家信息量均衡正则（P092）；q/kvo 式专家内分组共享（P060）；先域内后跨域混合的课程训练（P103 WSA）缓解 M3oE 早期域冲突；最关键空白：对比增广（P031 路线）vs LLM 语义增广在 M3oE+AUC 下的正面对照，语料内完全缺失。

## F11 特征/嵌入选择与稀疏化族（P009, P036, P039, P065）

**1. 要解决的问题**：多场景/多任务下冗余被放大——场景级粗粒度选择忽视实例差异（P036），MoE 独立专家造成参数/存储冗余（P009），模态重要性随场景与用户双重变化（P039），全量特征引入噪声（P065）。

**2. 代表方法**：同团队机制线 P065（场景级共享+特定掩码分解）→P036（实例级特征×维度外积掩码）→P039（场景×模态调度）；另有 P009（单基网络+层级掩码实现掩码专家）。

**3. 核心学习机制**：可微二值掩码——P065 连续门+温度退火+STE，搜索空间 2^{Kn}→2^n+2^{K(n−n_sh)}；P036 外积分解 g_f⊗g_e（2^{Nmd}→2^{Nm}+2^{Nd}）+迁移损失 L^sh；P039 超网络专属头+KL 拉向全激活+独立 optimizer；P009 近似 Bernoulli 的 L0 松弛（低方差掩码学习）+两阶段剪枝。

**4. 自适应信号**：backbone 损失回传（P065/P036）；实例 embedding+场景身份（P036/P039）；任务损失对掩码参数的梯度（P009）；训练进度（退火/warm-up）。

**5. 改变的变量**：embedding 表的样本-域贡献（P065）；逐实例输入子集（P036）；逐样本模态集合（P039）；专家实现方式与存储（P009：0.64–7.38MB vs MoE 类约 39MB）。

**6. 有效条件**：冗余存在且可被所选粒度识别；外积分解不丢关键结构（P036）；ID 模态恒可靠（P039 先验）；过参数化基网络存在冗余（P009）。

**7. 已达到性能**：P009 AliExpress 四国 AUC 全胜 7 基线；P065 三数据集×三骨干几乎全部显著最优且 DNN+MultiFS 超 STAR/HMoE 架构；P036 +0.1–0.5 AUC 点（p≤0.05）且选择结果跨骨干复用；P039 WAUC 全面最优+线上 CVR +1.47%，自适应掩码显著优于随机掩码（调度价值的直接证据）。证据中等偏强（有显著性、有随机对照），但绝对幅度小。

**8. 可靠负面结果**：P009 ES 的 Logloss 反而差于多数基线（AUC-Logloss 背离未解释）；P065 去重训练 AUC 崩至 0.57–0.66（搜索期损伤须重训修复）、去稀疏反而略升；P036 AliCCP 部分列差距在噪声量级；P039 S3 未达显著、全零输入下 Transformer 融合不稳。

**9. 未解决限制**：(a) 实例级粒度本身的贡献未隔离 [B]（P036 无中间粒度对照）；(b) 两阶段 search→retrain 成本翻倍且无公平成本对比 [A]（P065/P036）；(c) 掩码推理期静态 [A]（P065）；(d) "场景特定特征互斥"正交先验未验证，语义重叠场景可能受害 [B]（P065）；(e) 仅调度两个非 ID 模态，模态数增加时组合膨胀未验证 [B]（P039）；(f) 场景级与用户级双层偏好贡献未分解 [B]（P039）；(g) 剪枝不可逆、λ 逐数据集调 [B]（P009）；(h) "掩码重叠缓解负迁移/低梯度方差"机理声明无直接测量 [B]（P009）。

**10. 后续改进程度**：P036 把 P065 粒度细化到实例×维度并证明选择结果可跨骨干复用；P039 验证与 STAR/MMoE/AdaptDHM 的组合兼容（部分回应 P036 未与 MSR 架构组合的疑问）并给出一个月线上证据；P095（PackNet 式剪枝-恢复-冻结分阶段）回应 P009 的不可逆性；P074 以可微 NAS 回应手工掩码设计。改进集中在粒度、兼容性与可恢复性三处，但均为同团队内部迭代，外部独立复现缺失；AUC/Logloss 背离机理、推理期动态实例级选择、正交先验可学习化仍无人触及。

**11. MDMT/M3oE 潜在空间**：M3oE=单基网络+三族可分解掩码（共享⊙域⊙任务，P009 的直接映射，参数高效实现三类专家）；"特征×域×任务"三维掩码分解（P065 扩展）；输入侧实例掩码与专家路由的双稀疏框架（P036）；掩码重叠度作为域×任务相关性的可测代理（P009）；激活率演变曲线作 M3oE 训练诊断（P039）；Logloss 须纳入一等监控（P009 教训）。

## F12 下游目标与系统目标族（P008, P025, P032, P053, P066, P106, P115）

**1. 要解决的问题**：排序训练目标与下游系统目标脱节——检索召回与相关性 trade-off（P008）、延迟转化失真出价约束（P025）、上线后偏好权重突变需重训（P032）、多任务预测融合为排序分最大化长期满意度（P066）、组合奖励的不确定性探索（P106）、预算约束投放（P053）、非平稳信息被标准化抹掉（P115）。

**2. 代表方法**：P008（头-损失绑定+服务期配额）；P025（删失标签估计+CPO 约束求解）；P032（扩散生成 adapter 参数）；P053（离线 RL 双解码器+DPO）；P066（Sprecher 单调融合+RL 外层）；P106（多任务 Bayesian linear bandit）；P115（去平稳注意力）。

**3. 核心学习机制**：冲突目标的空间分离（P008 头-损失一一绑定）；改反馈信号本身（P025 ĉpc 替换 cpc）；参数获取从训练变推理（P032 条件扩散采样）；融合函数学习化（P066 内外层分解）；仅改 serving（P106 拼接末层上 Thompson Sampling）；注意力 logits 重注入尺度/平移（P115 τ/Δ）。

**4. 自适应信号**：服务期 α 旋钮（P008）；点击特征→延迟分布参数（P025）；外部偏好权重向量（P032）；用户状态+长期回报（P066）；逐样本协方差不确定性（P106）；序列原始统计量（P115）。

**5. 改变的变量**：输出头与候选合并比例（P008）；标签估计与约束代价（P025）；参数生成方式（P032）；RL 动作空间与融合函数形式（P066）；serving 动作规则与在线协方差（P106）；注意力分数（P115）。

**6. 有效条件**：trade-off 真实存在（P008 先实证后设计）；延迟显著且非极稀疏（P025 自述失效边界）；权重→参数存在平滑映射（P032）；组合奖励在拼接特征上线性（P106 Assumption 3，作者承认可能被违反）；融合函数逐分量单调（P066）；非平稳含信号（P115）。

**7. 已达到性能**：P008 唯一同时提升两目标（recall@500 +4.2%–14.4%、L2 +6.7%–56.5%）+在线六指标全正但幅度小（0.05%–0.33%）；P025 收入最高且零补偿、线上 +10%；P032 与重训练相关性 r>0.97、响应 −94.6%；P066 在线时长 +0.833%；P106 Satisfied Time +2.59%、语料覆盖 +48%–75%；P115 AUC 0.7986 vs 0.7921、RL 奖励大幅提升但 std 重叠。证据分化：P008/P025/P106 有线上 A/B（较强），P066 依赖自建模拟器，P115 无显著性（弱）。

**8. 可靠负面结果**：P008 单空间变体 recall −21.6%（自证 trade-off）；P025 稀疏转化广告主提升小、逐步约束版存在安全-收益权衡；P032 两组合败给 CMR；P053 主辅任务此消彼长只能手工 μ 控制；P066 like/follow 未超置信区间；P106 expert 拼接表示协方差奇异、效果最差；P115 DDPG 差距在 std 内。

**9. 未解决限制**：(a) 目标数 >2 的多头+配额可扩展性 [B]（P008）；(b) 专有数据不可复现 [A]（P008/P106）；(c) 指数分布假设对长尾延迟失真 [B]（P025 未与 Weibull 对照）；(d) 每广告独立 CMDP 无跨广告共享 [B]（P025）；(e) 训练对准备成本前置，"省训练"账本只算测试端 [B]（P032）；(f) adapter 容量上限决定可控性边界未量化 [B]（P032）；(g) 离线评估绑定单一模拟器 [A]（P066）；(h) 线性假设与表示选择敏感性无先验原则 [B]（P106）；(i) 机制归因无证据 [B]（P115 无 τ/Δ 取值分析）；(j) 与上游 MTL 的联合优化均未涉及 [B]（P008/P066/P106）。

**10. 后续改进程度**：P032 把 P008 的离散配额旋钮泛化为连续偏好向量的测试时参数生成（2.5s vs 重训 47–304s）；P066 把公式系数 RL 推广为个性化单调函数；P106 补上探索环节；P083 以多任务结构处理延迟反馈。但"训练-服务联合优化"这一根本问题全族未触及——上游模型都被当黑盒。

**11. MDMT/M3oE 潜在空间**：域×任务双头的服务期配额融合（P008→M3oE 输出层）；逐 (d,t)"不劣于单域基线"的约束式训练（P025 CPO 转写，直接回应 M3oE 大域退化）；以（域,任务）嵌入为条件的专家参数低秩生成（P032）；M3oE 预测接可学习融合并与两级门控端到端联训（P066，全族空白）；塔末层表示的探索不确定性逐 (d,t) 分解（P106）；域/任务条件+序列统计双重条件化注意力（P115）。

## F13 基准、数据集与理论族（P006, P022, P038, P067, P084, P107）

**1. 要解决的问题**：缺统一数据处理与评估协议导致无法公平比较（P006/P022）；学术数据集无法反映工业规模与跨域一致 ID（P038/P107）；多任务何时涌现解耦表示缺理论刻画（P067）；迁移性可否低成本估计（P084）。

**2. 代表方法**：P006（MSR 单任务深度基准，12 模型×7 数据集）；P022（MTL/MSL/MTMSL 广度基准，20+ 方法）；P038（T-ECD，135B 交互跨域数据集）；P107（AntM²C 多场景多模态 CTR 数据集）；P067（解耦涌现的存在性定理）；P084（迁移性估计综述）。

**3. 核心机制**：不改训练过程，控制评估混杂（统一超参搜索、多种子、按场景分解）；协议设计分离"跨域信号价值"与"朴素联合害处"（P038 的 SD/MD→SD/MD）；理论刻画（P067 Theorem 3.1：N_task≥D、边界满秩、σ>0 时最优分类器隐状态必然编码潜变量）；方法分类定性比较（P084）。

**4. 自适应信号**：不适用；P022 以任务 Pearson 相关与场景 CKA 做事后关联分析。

**5. 改变的变量**：评估协议（数据处理/超参/种子）与训练配置；理论篇不改任何变量。

**6. 有效条件**：场景划分语义有效（P006）；阈值构造任务的代表性（P022）；匿名化保留原始分布（P038 RQ1 间接验证）；分类器近似贝叶斯最优且噪声存在（P067）。

**7. 主要发现**：P006——12 模型无跨数据集单一赢家，层次结论"专家结构>直接建模、动态>静态"；P022——公平调参下方法间平均 AUC 差异多 <0.3–0.4%，SharedBottom≈MMoE/PLE 且更快，复现值多数高于原论文；P038——朴素多域联合训练灾难性崩溃（Small 上 MD −60%–75%）且结论对规模敏感（Full 上方向反转）；P107——无单一方法全场景最优，文本模态桥接跨场景 ID 不一致；P067——N_task≥D 时 OOD r² 中位约 0.96；P084——OT 类估计可靠性高、泛化界类低。

**8. 可靠负面结果**：本族自身即负面结果载体——P022"复杂结构增益收窄"是结构性负面证据；P038 MD 崩溃可复现；P006 场景数 3→7 时稀疏场景 seesaw 先降后升；P067 无噪声时定理失效（实验证实）。

**9. 未解决限制**：(a) P006 仅 CTR 单任务，复现多任务模型却不评估多任务 [A]；(b) P022 用测试集最佳 AUC 选模型（乐观偏差）且未覆盖优化类方法 [A]；(c) P038 负迁移机制只是推测（"大域主导梯度"无测量）、135B 中 100.8B 为非推荐的 payments [A]；(d) P107 场景匿名化削弱外部复现指导性 [A]；(e) P067 依赖理想化最优分类器假设 [B]；(f) P084 无统一测试床、估计分数与 MTL 结构选择脱节 [B]；(g) 相关性-增益关系仅 5/2+2 个数据点 [B]（P022）。

**10. 后续改进程度**：P022 补齐 P006 的单任务限制；P107/P038 提供工业规模数据；P098 把 P084 落地为域选择原则。但存在"基准-方法"实证断层：P038 列出的开放方向（gating/自适应共享/域均衡）无一在 T-ECD 上验证；优化类方法始终未被任何基准纳入。

**11. 基准对各族声称的约束/反证（本族额外问题）**：
- **结构族（MMoE/PLE/M3oE 谱系）受削弱最重**：P022 证明公平协议下复杂共享结构相对 SharedBottom 增益收窄至 0.3–0.4 点量级，任何"M3oE 类创新显著更优"的声称须先过统一搜索+多种子关；P006/P107 的"无单一赢家"否定跨场景一致性声称；P112 自身 d2 大域退化（输单域单任务 MLP 约 3 个 AUC 点）与 P006/P107 互证"平均最优掩盖逐格子退化"。
- **朴素多域联合训练被直接反证**：P038 MD 崩溃 −60%–75%。
- **LLM/语义族（F10）**：P107 的文本模态结论支持其输入侧价值，但 F10 的 AUC 声称几乎全部未经公平协议检验——未被削弱也未被证实，属证据真空。
- **优化类方法（梯度/更新级）**：未被基准覆盖（P022 明示），声称不受约束也不被背书。
- **理论约束**：P067 表明"多任务→解耦"仅在近最优训练+噪声下成立，削弱"任务越多表示越好"的朴素声称。

**MDMT 潜在空间**：把 M3oE 变体纳入 P006/P022 协议复测真实增益；以 T-ECD MD→SD 配置作"跨域增益"标配评测；以线性探针建立域×任务数-解耦度的实证定律（P067 延伸）；迁移性分数→门控初始化的闭环（P084→P098 路线）。
