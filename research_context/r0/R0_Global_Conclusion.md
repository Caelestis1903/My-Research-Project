# R0 全局结论（Global Conclusion）

**Stage R0 最终交付物**。目标：在不增加任何模型训练的前提下，判断 Phase 2B 的 AO-01～AO-10 哪些已被旧实验回答、哪些受到反证、哪些仍有独立的、值得验证的 AUC 算法机会。本阶段未进行任何训练，未修改任何训练代码与 Phase2B 源文件。

**工作方式记录**：三个独立分析角色并行完成——文献机会审查员（重建 AO-01～AO-10，`research_R0/work/lit_opportunity_review.md`）、实验证据审查员（重建 32 条实验索引/12 条稳定结论/22 条修订链，`research_R0/work/exp_evidence_review.md`）、独立怀疑者（跨语料映射核查，`research_R0/work/skeptic_review.md`）；主 Agent 对 M3OE 原文做了三处关键事实的直接抽验（复杂度结构、门控形式、训练目标口径），并完成综合判决。

## 一、对任务书五个决策问题的回答

### 1. 哪些候选已不值得继续？

- **AO-02（NOT-CURRENTLY-FEASIBLE，当前形态）**：M3OE 没有 top-k 路由、没有负载概念，负载均衡类比跨架构族挪用（证据 P040/P071/P093 全部来自稀疏 MoE），实施路径在声明的 backbone 上无作用对象。关闭当前形态；其"融合分布测量"内核并入 AO-04 先导，不单列方向。
- **AO-07（NOT-CURRENTLY-FEASIBLE）**：KuaiRand/MovieLens 无跨场景标签复用结构，团队管线不做标签迁移——数据与任务均不匹配，无标定对象。
- **AO-06（WEAKENED，事实性降格）**：自定位防御性、不承诺 AUC 增益；诊断组件已被 SF010 报告纪律吸收；外部校准方法成熟。不再是独立 AUC 研究方向，可作为实验报告纪律的附属工具。

### 2. 哪些候选仍有独立的算法研究价值？

- **AO-04（OPEN-TESTABLE）**：证据核对后地位上升最大——结构前提（均匀回收）经原文核实为真，旧实验零覆盖，先导近零成本，与 Sample-M3OE 完全兼容。
- **AO-09（OPEN-TESTABLE）**：MVQ 修正后是全候选最便宜的闸门，前提是团队考虑稀疏部署。
- **AO-01（WEAKENED，重构后保留）**：重构为"Equal 型目标/极端比例下的大域保护保险"；Sample 自然比例主线上问题不存在（S1/S2 0/96），不再是主攻方向。
- **AO-08（OPEN-TESTABLE）**：存在性闸门便宜，但优先级受贡献配比与网格单薄限制。
- **AO-03（WEAKENED）**：仅在能证明新度量携带 U_k 之外信息时保留。
- **AO-10（OPEN-TESTABLE，条件性）**：以团队采用语义增广路线为前提。
- **AO-05（WEAKENED，须重写）**：核心复杂度叙事被原文证伪；重写（作用对象改为 D×T 塔）并重新划界 P005 后方可再评。

### 3. 目前最值得开展的第一个先导实验是什么？

**AO-04 的推理期通道置零掩码实验**（与 AO-09 的共享门 k-sweep 合并为一次纯评估运行，复用现有 4-seed Sample-M3OE checkpoints，零训练，天数级成本）。它是"结构前提已证实 + 实验零覆盖 + 验证最便宜 + AUC 路径最直接"四者唯一同时成立的方向。

### 4. 最小实验阳性或阴性分别意味着什么？

- **AO-04 阳性**（置零退化 >0.003、4/4 同向、且伤害跨格非均匀集中）：均匀回收确实丢失格间差异显著的亲和信息，非均匀共享存在真实 AUC 空间。**阴性**（<0.003 或均摊）：均匀回收在当前数据上近似无害，AO-04 关闭或转为效率方向，同时阴性本身回答了"均匀回收何时够用"。
- **AO-09 阳性**（k=2 退化 >0.2%、4/4 同向）：稀疏部署存在可直接回收的 AUC 失配。**阴性**（<0.2%）：按预注册闸门直接终止。

### 5. 如果阳性，是否可以立即开发算法？

**不可以**。AO-04 阳性后须先排除更简单替代——可学习逐通道标量 softmax（一行级改动）小规模训练对照；只有标量加权不足时，在线亲和矩阵才有必要性。AO-09 阳性后须先排除 dense 部署与训练后校准两个平凡解。这是本阶段判决纪律的一部分（区分 C：是否存在简单方法无法充分解决的 AUC 改善机会）。

## 二、综合判断

1. **Phase2B 的"两 SUPPORTED"均不成立，但性质不同**：AO-01 是立项证据的 objective 偶然性未声明（Equal 现象被默认到 Sample 主线）；AO-05 是核心复杂度主张的事实错误（专家 N+D+T 加法，非 O(D·T·P)）。两者都不是被实验"否定"，而是被证据核对"降格"。
2. **旧实验对十个候选的覆盖比预想集中**：全部历史干预集中在 objective（Equal/Sample）、shared-access 二态、optimizer 状态三个维度；对融合拓扑、部署形态、掩码效率、标签复用、增量到达、语义增广六个维度零覆盖。因此多数候选既无支持也无反证——R0 的区分度主要来自**结构事实核实**与**objective 兼容性**而非实验反证。
3. **唯一被旧实验实质削弱收益假设的是 AO-03**（S7-A/S7-B/S8 + D010 闭合链），但也未达 CONTRADICTED。
4. **没有任何候选被判 CONTRADICTED**——这与"零淘汰"的 Phase2B 结论方向一致，但理由完全不同：Phase2B 是文献侧无反证，R0 是确认了旧实验的适用边界不覆盖这些假设。
5. **反向纪律同样重要**：Sample 0/96 不能用来判 AO-01 CONTRADICTED（Equal 现象真实、极端比例未测）； absence 不能判 AO-04 无价值。本结论拒绝双向的过度外推。

## 三、进入下一阶段的明确建议

1. **立即执行**（纯评估，零训练）：AO-04 通道置零掩码 + AO-09 共享门 k-sweep 合并先导，按 R0_Minimum_Pilot_Questions.md 的预注册口径执行；执行前一句话确认团队是否考虑稀疏部署（决定 AO-09 是否保留）。
2. **先导后重评**：AO-04/AO-09 出结果后，连同 AO-01 重构版（Equal/极端比例保险）与 AO-08（遗忘闸门）重新排序；AO-05 须先完成复杂度叙事重写才进入评估。
3. **勘误落实**：R0_Contradictions_and_Corrections.md 的 A/C 类修正（C-1/C-2/C-3/C-4、C-9/C-10/C-11）应回写 Phase2B 源文件或加勘误注记，防止下游继续引用失实主张。
4. **纪律沿用**：后续先导一律采用 SF010 报告口径（target/non-target × AUC/LogLoss × checkpoint、4 seeds、±0.003 practical 阈值）与预注册终止闸门；S6-R2 的隔离口径维持到任务书更新为止。
