# Archived evidence used to interpret this reproduction

This note records provenance and comparison limits before the new results are available. It is not a new experimental result.

- `PROJECT_ARCHITECTURE.md`, §2.1, describes a historical mask branch with VUG, staged training, adaptive masks and specificity weighting. Its MovieLens seed2022 table includes pooled AUC 0.7688 for its reference and 0.7771 for a DBO-labelled variant. Those figures are archival descriptions: complete corresponding source/launch identity has not been established, and the supplied static Gaussian-noise code is not that full branch. Neither figure is a numerical target or an interchangeable control for this experiment.
- The same architecture document records different original learned fusion and fixed-fusion conditions. A change from raw learned parameter 1 (effective sigmoid about 0.731) to fixed coefficient 1 is a protocol change, even before considering the optimizer path.
- `experiments/reports/history_report/P3_kuairand.md` describes reconstructing the processed KuaiRand file using chronological sorting before exporting 36 columns without interaction timestamps. The present experiment preserves that exported file and records its SHA and row order. Chronological provenance is supported by the archived reconstruction report, but cannot be independently rechecked from the processed CSV alone. Its one-epoch performance is a pipeline check, not evidence of method effectiveness.
- `experiments/Experimental_Stable_Findings.md`, SF002–SF008, records objective-, model- and checkpoint-dependent behavior in previous interventions. Those studies use different objectives, interventions and often sampled MovieLens domain sizes. Their numerical contrasts must not be pooled with the current natural-data, legacy six-cell group-sum experiment.
- SF009 says previous work had not identified an independent causal effect of domain size. The present two natural datasets also confound size with domain identity, labels, diversity and difficulty. Size-specific causal claims therefore require additional controlled evidence.
- SF010–SF011 record aggregate/per-cell, validation/test and selected/late-checkpoint disagreements. The current report will retain these views separately and will not treat pooled AUC as macro AUC or infer effectiveness from the final epoch alone.

Any comparison to these archived observations will distinguish compatibility, contradiction within a matching protocol, and differences between protocols. No archived score replaces one of the 32 newly required formal runs.
