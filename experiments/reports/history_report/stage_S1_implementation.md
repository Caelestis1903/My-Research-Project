## Design-to-code mapping

| Design requirement | Implementation |
|---|---|
| Immutable factors, thresholds, keys, and 192-run matrix | `stage_S1_protocol.py` and `stage_S1_orchestrator.py`; 48 joint + 144 single-domain MTL references with explicit collision-free keys and references emitted before each joint block. |
| MovieLens rotations | Split-first preprocessing and `RandomState(10*seed+physical_domain)` role reversal with exact L/M/S counts 150000/34500/3000. |
| KuaiRand natural split/domain/task contract | Bounded two-pass loader, global row-order 80/10/10 split before filtering, raw tab 0/1/4 mapped to local d0/d1/d2, exact natural train counts checked. |
| Leakage-free preprocessing/OOV | Vocabularies and MovieLens scaling fit on the global base training prefix only; deterministic OOV index 0; encoder/scaler, split, base, row-ID, and physical-view fingerprints persisted. |
| Joint/reference pairing | References filter the joint bundle and remap only routing IDs; physical-domain identity and pairing fingerprints are persisted and independently block-audited. |
| M3OE/MMoE/PLE | M3OE adapter reuses repository MDMTRec math; MMoE/PLE reuse P7 FuxiCTR-compatible layers with expert `[256,64]`, gate `[64]`, and `[64 → LayerNorm/ReLU → 1]` towers; no dummy architecture parameter, Momentum, Curriculum, or Safe-MTL path. |
| D=1,T=2 references/semantic initialization | All references retain both tasks and map cell gates/towers/task-specific tensors from `t*D+d`; M3OE domain tensors and routing embedding rows use physical-domain mapping; unmapped tensors receive deterministic name-derived sub-seeds. |
| Direct sample-target BCE | One `direct_per_example_bce` implementation is used for main and M3OE architecture updates; normalized cell BCE is an equivalence oracle only. |
| Fixed 50-epoch/checkpoint protocol | No early termination; shadow patience is diagnostic only. Selection is validation macro-AUC with earliest tie, followed by deferred selected/final/common test evaluation. Only selected plus required common/final CPU states are retained in memory. |
| Metrics and raw transfer fields | Shared tie-aware AUC/fixed-`LOGLOSS_EPS=1e-12` LogLoss, task-major `t*D+d` indexing, raw-prediction recomputation, selected/final/common paired deltas, and raw/practical/strong/concordant AUC/LogLoss indicators. Dataset contradiction strata retain matched size role. |
| Resume/fail-fast | Strict canonical write protection, append-only failed-attempt archive, exact formal launcher lock, child-runtime/file preflight, reference-before-joint admission, exact validator, and block audit. |
| Mechanical report | Formal-only collection and structural tables: selected/final/common paired cells, per-task pooled and assembled-reference pooled metrics, role/difficulty/dataset-stage summaries, baseline/stable/contradiction inventories, and no scientific interpretation or Stage 2 action. |

## Known limitations / hand-off

1. The repaired post-exit hash-closure and Windows resume/archive paths were exercised with synthetic fixtures and EDDAenv smoke; the preserved first-task failure remains read-only. A successful formal retry remains the runner/orchestrator stage's responsibility. Use `--rerun_failed` only after the stage lock is acquired; the transactional archiver will preserve `attempt_002` and any later evidence rather than editing it in place.
2. KuaiRand uses two bounded CSV passes to control Windows memory; this is deterministic but slower than a fully resident frame.
3. The report intentionally emits descriptive pooled/assembled-reference, role/difficulty/dataset-stage, stable/contradiction, and baseline inventories only; scientific interpretation, evidence labels, GO/STOP, and any Stage 2 design remain outside this implementation.

The implementation does not run formal experiments and does not analyze scientific results.
